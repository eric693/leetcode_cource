#133 Clone Graph

Medium
Graph DFS BFS Hash Table

題目描述

給你無向連通圖中一個節點的參考，請你返回該圖的深拷貝（複製）。

圖中的每個節點都包含它的值 val 和其鄰居的列表 neighbors：

class Node {
    public int val;
    public List<Node> neighbors;
}

範例

範例 1：
輸入：adjList = [[2,4],[1,3],[2,4],[1,3]]
輸出：[[2,4],[1,3],[2,4],[1,3]]

    1 --- 2
    |     |
    4 --- 3

節點 1 的鄰居是 2 和 4
節點 2 的鄰居是 1 和 3
節點 3 的鄰居是 2 和 4
節點 4 的鄰居是 1 和 3
範例 2：
輸入：adjList = [[]]
輸出：[[]]
解釋：只有一個節點，沒有任何鄰居。
範例 3：
輸入：adjList = []
輸出：[]（空圖）

解題思路

難點：圖有環，會無限遞迴！

1 → 2 → 1 → 2 → ... 如果單純遞迴複製鄰居，會永遠停不下來。解法是用 HashMap 記錄「已複製過的節點」，遇到已複製的就直接回傳，不再往下遞迴。

核心：visited 對照表既防重複也防無限迴圈

一石二鳥
visited[原節點] = 對應的新節點

★ 關鍵順序：【先建節點並登記，再遞迴處理鄰居】

dfs(node):
    if node in visited:
        return visited[node]        # 已複製過，直接回傳

    copy = new Node(node.val)
    visited[node] = copy            # ← 必須在遞迴【之前】登記！

    for nb in node.neighbors:
        copy.neighbors.append(dfs(nb))

    return copy

【為什麼登記要在遞迴之前？】
1 --- 2

dfs(1)：建立 1'，登記 visited[1] = 1'
        遞迴 dfs(2)
          建立 2'，登記 visited[2] = 2'
          遞迴 dfs(1) → visited 中有！直接回傳 1' ✓
          （若登記在遞迴之後，這裡會再建一個新的 1'，
            然後又遞迴 dfs(2)…… 無限迴圈 ✗）

DFS vs BFS

兩種寫法都要會
【DFS】遞迴，程式碼短
  優點：直覺、好寫
  缺點：圖很深時可能 stack overflow

【BFS】用佇列，迭代
  1. 先複製起點，放入 visited 和佇列
  2. 每次取出一個原節點，走訪它的鄰居：
     - 鄰居沒複製過 → 複製並入隊
     - 把對應的新鄰居加進當前新節點的 neighbors
  優點：沒有堆疊深度限制
  缺點：程式碼稍長

兩者的核心都是同一件事：visited 對照表。

程式碼實現

# 方法一：DFS 遞迴（推薦，簡潔）
class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        visited = {}     # 原節點 -> 新節點

        def dfs(cur):
            if not cur:
                return None
            if cur in visited:
                return visited[cur]      # 已複製過，直接回傳

            copy = Node(cur.val)
            visited[cur] = copy          # 關鍵：先登記，再遞迴

            for nb in cur.neighbors:
                copy.neighbors.append(dfs(nb))
            return copy

        return dfs(node)


# 方法二：BFS 迭代
class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if not node:
            return None
        from collections import deque

        visited = {node: Node(node.val)}
        queue = deque([node])

        while queue:
            cur = queue.popleft()
            for nb in cur.neighbors:
                if nb not in visited:
                    visited[nb] = Node(nb.val)   # 複製新節點
                    queue.append(nb)
                # 把新鄰居接上
                visited[cur].neighbors.append(visited[nb])

        return visited[node]

class Solution {
    unordered_map<Node*, Node*> visited;    // 原節點 -> 新節點

public:
    Node* cloneGraph(Node* node) {
        if (!node) return nullptr;
        if (visited.count(node)) return visited[node];   // 已複製過

        Node* copy = new Node(node->val);
        visited[node] = copy;               // 關鍵：先登記，再遞迴

        for (Node* nb : node->neighbors) {
            copy->neighbors.push_back(cloneGraph(nb));
        }
        return copy;
    }
};

// 方法二：BFS 迭代
class Solution {
public:
    Node* cloneGraph(Node* node) {
        if (!node) return nullptr;

        unordered_map<Node*, Node*> visited;
        visited[node] = new Node(node->val);
        queue<Node*> q;
        q.push(node);

        while (!q.empty()) {
            Node* cur = q.front(); q.pop();
            for (Node* nb : cur->neighbors) {
                if (!visited.count(nb)) {
                    visited[nb] = new Node(nb->val);
                    q.push(nb);
                }
                visited[cur]->neighbors.push_back(visited[nb]);
            }
        }
        return visited[node];
    }
};
// 方法一：DFS 遞迴（推薦）
class Solution {
    private Map<Node, Node> visited = new HashMap<>();

    public Node cloneGraph(Node node) {
        if (node == null) return null;
        if (visited.containsKey(node)) return visited.get(node);

        Node copy = new Node(node.val, new ArrayList<>());
        visited.put(node, copy);            // 關鍵：先登記，再遞迴

            copy.neighbors.add(cloneGraph(nb));
        }
        return copy;

// 方法二：BFS 迭代
class Solution {
    public Node cloneGraph(Node node) {
        if (node == null) return null;

        Map<Node, Node> visited = new HashMap<>();
        visited.put(node, new Node(node.val, new ArrayList<>()));
        Deque<Node> queue = new ArrayDeque<>();
        queue.offer(node);

        while (!queue.isEmpty()) {
            Node cur = queue.poll();
            for (Node nb : cur.neighbors) {
                if (!visited.containsKey(nb)) {
                    visited.put(nb, new Node(nb.val, new ArrayList<>()));
                    queue.offer(nb);
                }
                visited.get(cur).neighbors.add(visited.get(nb));
            }
        }
        return visited.get(node);
    }
}
/**
 * Definition for _Node.
 * class _Node {
 *     val: number
 *     neighbors: _Node[]
 * }
 */
// DFS + 雜湊表記錄「原節點 → 複製節點」，避免重複複製與無限迴圈
// 時間複雜度: O(V + E)，空間複雜度: O(V)
function cloneGraph(node: _Node | null): _Node | null {
    const visited = new Map<_Node, _Node>();

    const clone = (n: _Node): _Node => {
        if (visited.has(n)) return visited.get(n)!;
        const copy = new _Node(n.val);
        visited.set(n, copy);                   // 先登記再遞迴，處理環
        for (const nb of n.neighbors) {
            copy.neighbors.push(clone(nb));
        }
        return copy;
    };

    return node ? clone(node) : null;
}
/**
 * Definition for a Node.
 * struct Node {
 *     int val;
 *     int numNeighbors;
 *     struct Node** neighbors;
 * };
 */
// DFS + 以節點值（1~100）為索引記錄已複製的節點
// 時間複雜度: O(V + E)，空間複雜度: O(V)
static struct Node* clone(struct Node* n, struct Node** visited) {
    if (visited[n->val]) return visited[n->val];

    struct Node* copy = malloc(sizeof(struct Node));
    copy->val = n->val;
    copy->numNeighbors = n->numNeighbors;
    copy->neighbors = malloc(sizeof(struct Node*) * (n->numNeighbors ? n->numNeighbors : 1));
    visited[n->val] = copy;                     // 先登記再遞迴，處理環

    for (int i = 0; i < n->numNeighbors; i++) {
        copy->neighbors[i] = clone(n->neighbors[i], visited);
    }
    return copy;
}

struct Node* cloneGraph(struct Node* s) {
    if (!s) return NULL;
    struct Node* visited[101] = {0};
    return clone(s, visited);
}

複雜度分析

時間複雜度：O(V + E)
  • 每個節點複製一次，每條邊處理一次（無向圖每條邊看兩次）
空間複雜度：O(V)
  • visited 對照表 O(V)
  • DFS 遞迴堆疊最壞 O(V)；BFS 佇列最壞 O(V)

重點提示

關鍵技巧 1：先登記，再遞迴

visited[cur] = copy 必須寫在遞迴呼叫之前。這一行的位置決定了程式會不會無限迴圈，是本題唯一但最關鍵的細節。

關鍵技巧 2：這是「圖走訪 + 記憶化」的通用模式

凡是在有環的結構上做遞迴（複製、序列化、計算），都需要一個 visited 集合來打破循環。#138 複製隨機指標串列、#297 序列化二元樹（含環的變形）都是同一個模式。

常見錯誤：
  • 登記寫在遞迴之後 → 無限遞迴 stack overflow
  • 沒有處理 node == null（空圖）
  • 用「值」當 HashMap 的 key（若題目允許重複值就會出錯，應該用節點參考）
  • BFS 版本忘記在建立新節點時初始化空的 neighbors 列表（Java）

補充說明

圖的兩種表示法

鄰接表 vs 鄰接矩陣
                鄰接表                鄰接矩陣
                vector<vector<int>>   bool[V][V]
-------------------------------------------------------------
空間            O(V + E)              O(V²)
查詢是否有邊    O(deg(v))             O(1) ★
走訪某點的鄰居  O(deg(v)) ★           O(V)
適用            稀疏圖（實務多數）     稠密圖、需頻繁查邊

LeetCode 大多數圖題是稀疏圖，用鄰接表。
本題的 Node 結構本身就是鄰接表的物件版本。

圖走訪模板（背下來受用無窮）

【DFS 遞迴】
void dfs(int u) {
    visited[u] = true;
    process(u);
    for (int v : graph[u])
        if (!visited[v]) dfs(v);
}

【BFS 佇列】
void bfs(int start) {
    queue<int> q;  q.push(start);  visited[start] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        process(u);
        for (int v : graph[u]) {
            if (!visited[v]) { visited[v] = true; q.push(v); }
        }
    }
}

★ 重點：BFS 要在【入隊時】標記 visited，
   不是出隊時 —— 否則同一個節點會被重複入隊。

DFS 與 BFS 各自的長處

  • BFS：無權圖的最短路徑、層級走訪、最少步數問題（#127 單詞接龍、#994 腐爛橘子）
  • DFS：連通性、環偵測、拓撲排序、回溯搜尋所有路徑、樹的遞迴結構
  • 本題兩者皆可，因為只是要「走遍所有節點」，沒有距離或順序的要求
