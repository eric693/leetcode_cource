#39 Combination Sum

Medium
Backtracking Array Recursion

題目描述

給你一個無重複元素的整數陣列 candidates 和一個目標整數 target，找出 candidates 中可以使數字和為 target 的所有不同組合，並以列表形式返回。

candidates 中的同一個數字可以無限制重複被選取。如果至少一個數字的被選數量不同，則兩種組合是不同的。

題目保證：對於給定的輸入，保證和為 target 的不同組合數少於 150 個。

範例

範例 1：
輸入：candidates = [2,3,6,7], target = 7
輸出：[[2,2,3],[7]]
解釋：2+2+3 = 7，且 2 可以重複使用；7 本身也等於 7。
範例 2：
輸入：candidates = [2,3,5], target = 8
輸出：[[2,2,2,2],[2,3,3],[3,5]]
範例 3：
輸入：candidates = [2], target = 1
輸出：[]

解題思路

💡 核心：回溯 + 「可重複選」的關鍵一行
和一般組合題唯一的差別：

  一般組合（元素只能用一次）→ backtrack(i + 1)
  本題（元素可重複使用）    → backtrack(i)   ★

因為傳 i 而不是 i+1，下一層還能再選同一個元素。
但仍然「不能往回選」（不從 0 開始），
這樣才能避免產生 [2,3] 和 [3,2] 這種重複組合。

決策樹：candidates = [2,3,6,7], target = 7

🌲 剩餘量遞減的搜尋樹
每個節點標示「還差多少」

                   remain=7
        /        /       \       \
      選2       選3      選6      選7
    remain=5  remain=4 remain=1  remain=0 ✓ [7]
    /   |  \    |  \
  選2  選3 選6 選3  選6
 rem=3 rem=2 ✗ rem=1 ✗
  / \
選2  選3
rem=1 rem=0 ✓ [2,2,3]
 ✗

剪枝條件：
  remain == 0 → 找到答案，記錄並返回
  remain < 0  → 超過目標，直接返回（剪枝）

優化：排序後可以提早跳出

⚡ 從 continue 升級成 break
先把 candidates 排序（升序），
迴圈中一旦發現 candidates[i] > remain，
表示後面的元素只會更大，可以直接 break 而不是 continue。

sort(candidates);
for (int i = start; i < n; i++) {
    if (candidates[i] > remain) break;   // ← 排序後才能這樣剪枝
    ...
}

雖然最壞複雜度不變，但實測能減少大量無效搜尋。

為什麼用 start 就能避免重複組合？

若每層都從 0 開始，會產生：
  [2,2,3]、[2,3,2]、[3,2,2] —— 三個相同的組合

用 start 限制「只能選索引 >= start 的元素」後，
路徑中的元素索引必定非遞減，
所以每個組合只會以「一種特定順序」被產生一次 ✓

程式碼實現

class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        result = []
        path = []
        candidates.sort()          # 排序後可以用 break 剪枝

        def backtrack(start, remain):
            if remain == 0:
                result.append(path[:])       # 找到一組解（記得複製）
                return

            for i in range(start, len(candidates)):
                if candidates[i] > remain:   # 排序後，後面只會更大
                    break                    # 直接跳出，不用 continue

                path.append(candidates[i])           # 做選擇
                backtrack(i, remain - candidates[i]) # 關鍵：傳 i 不是 i+1
                path.pop()                           # 撤銷選擇

        backtrack(0, target)
        return result
class Solution {
    vector<vector<int>> result;
    vector<int> path;

    void backtrack(vector<int>& candidates, int start, int remain) {
        if (remain == 0) {
            result.push_back(path);        // 找到一組解
            return;
        }

        for (int i = start; i < candidates.size(); i++) {
            if (candidates[i] > remain) break;   // 排序後可提早跳出

            path.push_back(candidates[i]);              // 做選擇
            backtrack(candidates, i, remain - candidates[i]);  // 傳 i！
            path.pop_back();                            // 撤銷選擇
        }
    }

public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());     // 排序以便剪枝
        backtrack(candidates, 0, target);
        return result;
    }
};
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);           // 排序以便剪枝
        backtrack(candidates, 0, target);
        return result;
    }

    private void backtrack(int[] candidates, int start, int remain) {
        if (remain == 0) {
            result.add(new ArrayList<>(path));    // 找到一組解
            return;
        }

        for (int i = start; i < candidates.length; i++) {
            if (candidates[i] > remain) break;    // 提早跳出

            path.add(candidates[i]);                        // 做選擇
            backtrack(candidates, i, remain - candidates[i]); // 傳 i！
            path.remove(path.size() - 1);                   // 撤銷選擇
        }
    }
}

複雜度分析

時間複雜度：O(ntarget/min)
  • 搜尋樹的深度最多為 target / min(candidates)
  • 每層最多 n 個分支
  • 這是回溯類問題的鬆散上界，實際因剪枝而快很多
空間複雜度：O(target / min)
  • 遞迴堆疊深度 + path 的長度
  • 不計儲存結果的空間

重點提示

💡 關鍵技巧 1：傳 i 還是 i+1？

這一個字的差別決定了題目類型：

  • backtrack(i) → 元素可重複使用（本題 #39）
  • backtrack(i + 1) → 每個元素只能用一次（#40、#78）
  • 從 0 開始 → 排列問題（#46）
💡 關鍵技巧 2：用「剩餘量」而非「累積和」

傳 remain = target - 已選總和 比傳 currentSum 更簡潔：終止條件變成 remain == 0，剪枝變成 remain < 0，也不需要額外傳 target。

💡 延伸 #40：候選數含重複且每個只能用一次

需要兩個改動：① 遞迴傳 i + 1；② 加上同層去重 if (i > start && c[i] == c[i-1]) continue;。這兩題常一起出現，務必分清楚。

⚠️ 常見錯誤：
  • 傳 i + 1（變成每個元素只能用一次，答案會漏掉 [2,2,3]）
  • 從 0 開始遞迴（產生 [2,3] 和 [3,2] 等重複組合）
  • 沒排序卻用 break 剪枝（會漏解，必須用 continue）
  • 記錄結果忘記複製 path

   [1,2] 和 [2,1] 算兩種。數量可能極大，
   不可能列舉出來，必須用 DP：
     dp[i] = Σ dp[i - num] for num in nums
   這是完全背包的「排列數」版本（外層遍歷容量）。

#40 的完整實作

void backtrack(vector<int>& c, int start, int remain) {
    if (remain == 0) { result.push_back(path); return; }

    for (int i = start; i < c.size(); i++) {
        if (c[i] > remain) break;
        // ★ 同層去重：跳過同一層中重複的候選數
        if (i > start && c[i] == c[i-1]) continue;

        path.push_back(c[i]);
        backtrack(c, i + 1, remain - c[i]);   // ★ i+1：每個只能用一次
        path.pop_back();
    }
}

輸入 [10,1,2,7,6,1,5], target=8
排序後 [1,1,2,5,6,7,10]
輸出 [[1,1,6],[1,2,5],[1,7],[2,6]]
   不會出現兩個 [1,7]（來自兩個不同的 1）✓

回溯 vs 動態規劃：什麼時候用哪個？

  • 要列出「所有具體方案」 → 回溯（本題）。因為答案本身就是指數量級的，DP 也省不了
  • 只要「方案的數量」或「最優值」 → DP。例如 #322 最少硬幣、#518 組合數、#377 排列數
  • 判斷關鍵：看題目問的是「返回所有…」還是「返回幾種/最少幾個」

這個判斷在面試中很重要 —— 用回溯去解「求數量」的題目通常會超時，而用 DP 去解「列舉所有方案」則根本做不到。
