#232 Implement Queue using Stacks

Easy
Design Stack Queue

題目描述

請你僅使用兩個堆疊實現先入先出佇列。佇列應當支援一般佇列支援的所有操作（push、pop、peek、empty）。

  • push(x)：將元素 x 推到佇列的末尾
  • pop()：從佇列的開頭移除並返回元素
  • peek()：返回佇列開頭的元素
  • empty()：如果佇列為空返回 true

進階：你能否實現每個操作攤銷（amortized）O(1) 時間複雜度？

範例

範例：
MyQueue q = new MyQueue();
q.push(1);      // 佇列: [1]
q.push(2);      // 佇列: [1, 2]
q.peek();       // 返回 1
q.pop();        // 返回 1，佇列: [2]
q.empty();      // 返回 false

解題思路

💡 核心：兩個堆疊「倒一次」就變成 FIFO
堆疊是 LIFO（後進先出），佇列是 FIFO（先進先出）
把一個堆疊的元素倒進另一個堆疊，順序剛好會反過來 → 變成 FIFO

in  堆疊：專門負責 push
out 堆疊：專門負責 pop / peek

push(1), push(2), push(3)
  in  = [1, 2, 3]（3 在頂端）
  out = []

pop() → out 空了，把 in 全部倒過來：
  in  = []
  out = [3, 2, 1]（1 在頂端）✓
  彈出 out 頂端 = 1 ✓ 正是最先進來的

再 push(4)：只丟進 in，不動 out
  in  = [4]
  out = [3, 2]

pop() → out 不空，直接彈出 2 ✓

攤銷 O(1) 的關鍵規則

🎯 只有在 out 為空時才搬運
❌ 錯誤做法：每次 pop 都把 in 倒到 out、pop 完再倒回 in
   → 每次操作 O(n)

✓ 正確做法：out 空了才一次倒完，out 沒空就直接用
   → 每個元素一生只會被「搬運」一次
     （進 in 一次、搬到 out 一次、離開 out 一次）
   → n 次操作總成本 O(n)，攤銷每次 O(1)

這就是「攤銷分析（amortized analysis）」的經典範例。
最壞單次是 O(n)，但平均下來是 O(1)。

程式碼實現

class MyQueue:

    def __init__(self):
        self.in_stack = []      # 專門負責 push
        self.out_stack = []     # 專門負責 pop / peek

    def push(self, x: int) -> None:
        self.in_stack.append(x)

    def pop(self) -> int:
        self._transfer()
        return self.out_stack.pop()

    def peek(self) -> int:
        self._transfer()
        return self.out_stack[-1]

    def empty(self) -> bool:
        return not self.in_stack and not self.out_stack

    def _transfer(self):
        # 關鍵：只有 out 空的時候才搬，保證攤銷 O(1)
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
class MyQueue {
private:
    stack<int> inStk;    // 專門負責 push
    stack<int> outStk;   // 專門負責 pop / peek

    // 關鍵：只有 out 空的時候才搬運
    void transfer() {
        if (outStk.empty()) {
            while (!inStk.empty()) {
                outStk.push(inStk.top());
                inStk.pop();
            }
        }
    }

public:
    MyQueue() {}

    void push(int x) {
        inStk.push(x);
    }

    int pop() {
        transfer();
        int val = outStk.top();
        outStk.pop();
        return val;
    }

    int peek() {
        transfer();
        return outStk.top();
    }

    bool empty() {
        return inStk.empty() && outStk.empty();
    }
};
class MyQueue {
    private Deque<Integer> inStk = new ArrayDeque<>();   // 負責 push
    private Deque<Integer> outStk = new ArrayDeque<>();  // 負責 pop / peek

    public MyQueue() {}

    public void push(int x) {
        inStk.push(x);
    }

    public int pop() {
        transfer();
        return outStk.pop();
    }

    public int peek() {
        transfer();
        return outStk.peek();
    }

    public boolean empty() {
        return inStk.isEmpty() && outStk.isEmpty();
    }

    // 關鍵：只有 out 空的時候才搬運
    private void transfer() {
        if (outStk.isEmpty()) {
            while (!inStk.isEmpty()) {
                outStk.push(inStk.pop());
            }
        }
    }
}
// 兩個堆疊：inStk 負責 push，outStk 負責 pop / peek（空了才從 inStk 倒過來）
// 均攤時間複雜度: O(1)，空間複雜度: O(n)
class MyQueue {
    private inStk: number[] = [];
    private outStk: number[] = [];

    push(x: number): void {
        this.inStk.push(x);
    }

    pop(): number {
        this.move();
        return this.outStk.pop()!;
    }

    peek(): number {
        this.move();
        return this.outStk[this.outStk.length - 1];
    }

    empty(): boolean {
        return this.inStk.length === 0 && this.outStk.length === 0;
    }

    private move(): void {
        if (this.outStk.length === 0) {
            while (this.inStk.length) this.outStk.push(this.inStk.pop()!);
        }
    }
}
// 兩個堆疊：inStk 負責 push，outStk 負責 pop / peek（空了才從 inStk 倒過來）
// 均攤時間複雜度: O(1)，空間複雜度: O(n)；題目最多呼叫 100 次
#define CAP 100

typedef struct {
    int inStk[CAP], inTop;
    int outStk[CAP], outTop;
} MyQueue;

MyQueue* myQueueCreate() {
    MyQueue* q = malloc(sizeof(MyQueue));
    q->inTop = q->outTop = 0;
    return q;
}

static void move(MyQueue* q) {
    if (q->outTop == 0) {
        while (q->inTop > 0) q->outStk[q->outTop++] = q->inStk[--q->inTop];
    }
}

void myQueuePush(MyQueue* obj, int x) {
    obj->inStk[obj->inTop++] = x;
}

int myQueuePop(MyQueue* obj) {
    move(obj);
    return obj->outStk[--obj->outTop];
}

int myQueuePeek(MyQueue* obj) {
    move(obj);
    return obj->outStk[obj->outTop - 1];
}

bool myQueueEmpty(MyQueue* obj) {
    return obj->inTop == 0 && obj->outTop == 0;
}

void myQueueFree(MyQueue* obj) {
    free(obj);
}

複雜度分析

時間複雜度：
  • push：O(1)
  • pop / peek：攤銷 O(1)，最壞單次 O(n)
  • empty：O(1)
  • 每個元素最多被搬運一次，n 次操作總成本 O(n)
空間複雜度：O(n)，兩個堆疊合計最多存 n 個元素

重點提示

💡 關鍵技巧：out 空了才搬

這是本題唯一的重點。每次都搬來搬去會退化成 O(n)，「只有必要時才搬」才能達到攤銷 O(1)。

💡 什麼是攤銷複雜度？

單次操作可能很貴，但把總成本平均到所有操作上仍是常數。動態陣列（vector）擴容、Union-Find 路徑壓縮都是攤銷分析的經典例子。面試被問到時，記得說明「每個元素只會被搬運一次」這個論證。

⚠️ 常見錯誤：
  • pop 完之後又把元素倒回 in 堆疊（完全沒必要，還破壞攤銷複雜度）
  • out 不為空時又去搬 in，會破壞元素順序
  • empty() 只檢查其中一個堆疊
  • Java 用 Stack 類別（已過時且同步化較慢），建議用 ArrayDeque

補充說明

對照：#225 用佇列實作堆疊

🔄 只需要一個佇列
push 時，把新元素加入後，
把它前面的所有元素依序出隊再入隊，讓新元素轉到最前面。

push(1): [1]
push(2): 先入隊 [1,2]，再把前面 1 個轉到後面 → [2,1]
push(3): 先入隊 [2,1,3]，再把前面 2 個轉到後面 → [3,2,1]

pop() 直接出隊 → 3 ✓ 正是最後進來的

void push(int x) {
    q.push(x);
    for (int i = 0; i < q.size() - 1; i++) {
        q.push(q.front());
        q.pop();
    }
}
push 是 O(n)，pop/top 是 O(1)（和本題剛好相反）

攤銷分析的其他經典案例

  • 動態陣列擴容：容量滿時翻倍複製 O(n)，但攤銷 push_back 為 O(1)
  • Union-Find 路徑壓縮：攤銷接近 O(α(n))，α 為反阿克曼函數
  • 單調堆疊：每個元素最多進出堆疊各一次，總計 O(n)
