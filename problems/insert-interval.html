#57 Insert Interval

Medium
Array Interval Greedy

題目描述

給你一個無重疊、按起點升序排列的區間列表 intervals，以及一個新區間 newInterval。

請你在 intervals 中插入 newInterval，使得插入後仍然有序且不重疊（如果有必要的話，可以合併區間）。返回插入後的區間列表。

注意：你不需要原地修改 intervals，可以建立新陣列返回。

範例

範例 1：
輸入：intervals = [[1,3],[6,9]], newInterval = [2,5]
輸出：[[1,5],[6,9]]
範例 2：
輸入：intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
輸出：[[1,2],[3,10],[12,16]]
解釋：新區間 [4,8] 與 [3,5]、[6,7]、[8,10] 都重疊，合併成 [3,10]。

解題思路

💡 核心：把區間分成三段處理
因為輸入已經有序且不重疊，可以一趟掃描分成三個階段：

【階段 1】完全在 new 左邊的區間 → 直接加入
          條件：interval.end < new.start

【階段 2】與 new 重疊的區間 → 合併成一個大區間
          條件：interval.start <= new.end
          new.start = min(new.start, interval.start)
          new.end   = max(new.end,   interval.end)
          全部合併完後，把 new 加入結果

【階段 3】完全在 new 右邊的區間 → 直接加入

不需要排序！輸入已經有序，所以只要 O(n)。

完整追蹤：[[1,2],[3,5],[6,7],[8,10],[12,16]], new = [4,8]

🔄 三階段掃描
new = [4, 8]

【階段 1】end < 4 的
  [1,2]：2 < 4 ✓ → result = [[1,2]]
  [3,5]：5 >= 4 ✗ → 進入階段 2

【階段 2】start <= 8 的
  [3,5]：3 <= 8 ✓ → new = [min(4,3), max(8,5)] = [3,8]
  [6,7]：6 <= 8 ✓ → new = [min(3,6), max(8,7)] = [3,8]
  [8,10]：8 <= 8 ✓ → new = [min(3,8), max(8,10)] = [3,10]
  [12,16]：12 > 8 ✗ → 結束
  把 new 加入 → result = [[1,2],[3,10]]

【階段 3】剩下的
  [12,16] → result = [[1,2],[3,10],[12,16]] ✓

與 #56 Merge Intervals 的差別

📊 為什麼這題能 O(n)？
#56：輸入無序、可能互相重疊 → 必須先排序 → O(n log n)
#57：輸入已排序且無重疊     → 直接掃描   → O(n) ★

如果偷懶把 newInterval 塞進陣列再套用 #56 的解法，
會變成 O(n log n)，面試官通常不會滿意。

程式碼實現

# 三階段掃描（推薦，O(n)）
class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        result = []
        i, n = 0, len(intervals)
        start, end = newInterval

        # 階段 1：完全在新區間左邊
        while i < n and intervals[i][1] < start:
            result.append(intervals[i])
            i += 1

        # 階段 2：與新區間重疊，全部合併
        while i < n and intervals[i][0] <= end:
            start = min(start, intervals[i][0])
            end = max(end, intervals[i][1])
            i += 1
        result.append([start, end])

        # 階段 3：完全在新區間右邊
        while i < n:
            result.append(intervals[i])
            i += 1

        return result

class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, vector<int>& newInterval) {
        vector<vector<int>> result;
        int i = 0, n = intervals.size();

        // 階段 1：完全在新區間左邊

            i++;

        // 階段 3：完全在新區間右邊

            result.push_back(intervals[i++]);
        }
        return result;
    }
};

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> result = new ArrayList<>();
        int i = 0, n = intervals.length;
        int start = newInterval[0], end = newInterval[1];

        // 階段 1：完全在新區間左邊
        while (i < n && intervals[i][1] < start) {
            result.add(intervals[i++]);
        }

        // 階段 2：重疊區間全部合併
        while (i < n && intervals[i][0] <= end) {
            start = Math.min(start, intervals[i][0]);
            end   = Math.max(end,   intervals[i][1]);
            i++;
        }
        result.add(new int[]{start, end});

        // 階段 3：完全在新區間右邊
        while (i < n) {
            result.add(intervals[i++]);
        }
        return result.toArray(new int[result.size()][]);
    }
}
// 一次掃描：左側不重疊 → 合併重疊部分 → 右側不重疊
// 時間複雜度: O(n)，空間複雜度: O(n)
function insert(intervals: number[][], newInterval: number[]): number[][] {
    const result: number[][] = [];
    let [start, end] = newInterval;
    let i = 0;
    const n = intervals.length;

    while (i < n && intervals[i][1] < start) result.push(intervals[i++]);   // 完全在左邊
    while (i < n && intervals[i][0] <= end) {                               // 與新區間重疊
        start = Math.min(start, intervals[i][0]);
        end = Math.max(end, intervals[i][1]);
        i++;
    }
    result.push([start, end]);
    while (i < n) result.push(intervals[i++]);                              // 完全在右邊
    return result;
}
// 一次掃描：左側不重疊 → 合併重疊部分 → 右側不重疊
// 時間複雜度: O(n)，空間複雜度: O(n)
static int* pair(int a, int b) {
    int* p = malloc(sizeof(int) * 2);
    p[0] = a; p[1] = b;
    return p;
}

int** insert(int** intervals, int intervalsSize, int* intervalsColSize,
             int* newInterval, int newIntervalSize,
             int* returnSize, int** returnColumnSizes) {
    int** result = malloc(sizeof(int*) * (intervalsSize + 1));
    int cnt = 0, i = 0, n = intervalsSize;
    int start = newInterval[0], end = newInterval[1];

    while (i < n && intervals[i][1] < start) {               // 完全在左邊
        result[cnt++] = pair(intervals[i][0], intervals[i][1]);
        i++;
    }
    while (i < n && intervals[i][0] <= end) {                // 與新區間重疊
        if (intervals[i][0] < start) start = intervals[i][0];
        if (intervals[i][1] > end) end = intervals[i][1];
        i++;
    }
    result[cnt++] = pair(start, end);
    while (i < n) {                                          // 完全在右邊
        result[cnt++] = pair(intervals[i][0], intervals[i][1]);
        i++;
    }

    *returnSize = cnt;
    *returnColumnSizes = malloc(sizeof(int) * cnt);
    for (int k = 0; k < cnt; k++) (*returnColumnSizes)[k] = 2;
    return result;
}

複雜度分析

時間複雜度：O(n)
  • 三個階段合計只掃描陣列一次
  • 因為輸入已排序，完全不需要 O(n log n) 的排序
空間複雜度：O(1)（不計輸出陣列）

重點提示

💡 關鍵技巧 1：善用「輸入已排序」的條件

題目給的條件都是有用的。看到「已排序、無重疊」就要意識到可以省掉排序，直接線性掃描。

💡 關鍵技巧 2：合併時 start 也要取 min

雖然大多數情況下新區間的 start 較大，但像 intervals=[[3,5]], new=[4,8] 這種，合併後 start 應該是 3。習慣性寫 min/max 兩邊都取，不會出錯。

⚠️ 常見錯誤：
  • 階段 1 的條件寫成 end <= start，會把「端點接觸」的區間錯誤地當成不重疊（本題端點接觸算重疊）
  • 忘記把合併後的新區間加入結果
  • 階段 2 只更新 end 沒更新 start
  • 沒有處理 intervals 為空的情況（本解法的迴圈自然跳過，會正確返回 [newInterval]）

缺點：O(n log n)，浪費了「已排序」這個條件

面試建議：可以先提這個做法說明思路正確，
          然後主動說「但因為輸入已排序，我可以優化到 O(n)」，
          再寫三階段版本。

用二分搜尋進一步優化？

可以用二分搜尋快速定位階段 1 和階段 2 的分界點，把「找起點」降到 O(log n)。但階段 2 的合併本身就可能掃過 O(n) 個區間（新區間可能跨越所有舊區間），所以最壞情況仍是 O(n)，實務上不划算。面試被問到時可以這樣分析，展現複雜度的敏感度。

邊界情況檢查清單

  • intervals 為空 → 返回 [newInterval]
  • 新區間在最左邊 → 階段 1 不執行
  • 新區間在最右邊 → 階段 2、3 不執行
  • 新區間吞掉所有舊區間 → 階段 1、3 不執行
  • 新區間完全不重疊、夾在中間 → 階段 2 只加入自己
