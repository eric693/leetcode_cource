#207 Course Schedule

Medium
Graph Topological Sort BFS DFS

題目描述

你這個學期必須選修 numCourses 門課程，記為 0 到 numCourses - 1。

在選修某些課程之前需要一些先修課程。先修課程按陣列 prerequisites 給出，其中 prerequisites[i] = [ai, bi] 表示如果要學習課程 ai 則必須先學習課程 bi。

請你判斷是否可能完成所有課程的學習？如果可以返回 true，否則返回 false。

本題的本質是：判斷有向圖是否有環。

範例

範例 1：
輸入：numCourses = 2, prerequisites = [[1,0]]
輸出：true
解釋：總共 2 門課，學習課程 1 之前要先完成課程 0，可能的順序是 [0, 1]。
範例 2：
輸入：numCourses = 2, prerequisites = [[1,0],[0,1]]
輸出：false
解釋：學 1 要先學 0，學 0 又要先學 1 —— 互相依賴，形成環，不可能完成。

解題思路

💡 建模：把課程依賴變成有向圖
prerequisites[i] = [a, b] 表示「學 a 之前要先學 b」

建圖方向：b → a （先修 → 後修）

  numCourses = 4
  prerequisites = [[1,0],[2,0],[3,1],[3,2]]

      0
     / \
    1   2
     \ /
      3

可以完成 ⟺ 圖中【沒有環】
（有環代表 A 要先修 B、B 又要先修 A，永遠無解）

方法一：BFS 拓撲排序（Kahn 演算法，推薦）

🎯 不斷移除「入度為 0」的節點
入度（in-degree）= 有幾個先修課還沒修完

演算法：
1. 計算每個節點的入度
2. 把所有入度為 0 的節點放進佇列（可以立刻修的課）
3. 每次取出一門課，把它的所有後繼課程入度 -1
   若某個後繼課程入度變成 0，加入佇列
4. 最後檢查「修完的課程數」是否等於 numCourses

【完整追蹤】
圖：0→1, 0→2, 1→3, 2→3
入度：[0, 1, 1, 2]

佇列 = [0]（入度為 0）
取出 0，count=1 → 1 和 2 的入度各 -1 → [0,0,0,2]
                                        佇列 = [1, 2]
取出 1，count=2 → 3 的入度 -1 → 3 的入度變 1
取出 2，count=3 → 3 的入度 -1 → 3 的入度變 0，加入佇列
取出 3，count=4

count == 4 == numCourses → true ✓

【有環的情況】
0→1, 1→0，入度都是 1
沒有任何節點入度為 0，佇列一開始就是空的
count = 0 != 2 → false ✓

方法二：DFS 三色標記法

🎨 用三種狀態偵測環
0 = 白色（未訪問）
1 = 灰色（正在遞迴堆疊中，還沒走完）
2 = 黑色（已完成，確認無環）

DFS 過程中：
  遇到【灰色】節點 → 找到環！返回 false
  遇到【黑色】節點 → 已驗證過，直接跳過

⚠️ 為什麼需要三種顏色而不是兩種？
  只用「訪問過/沒訪問過」無法區分：
    - 這個節點在【當前路徑】上（=環）
    - 這個節點在【之前的路徑】上（不是環，只是共用節點）

  例：0→1, 0→2, 1→2
      走 0→1→2 完成後 2 是黑色，
      回到 0 再走 0→2 時遇到黑色 → 不是環 ✓
      若只用兩色會誤判成環 ✗

程式碼實現

# 方法一：BFS 拓撲排序（Kahn，推薦）
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        from collections import deque

        graph = [[] for _ in range(numCourses)]   # 鄰接表
        indegree = [0] * numCourses               # 入度

        for course, pre in prerequisites:
            graph[pre].append(course)             # pre → course
            indegree[course] += 1

        # 所有入度為 0 的課程可以立刻開始
        queue = deque(i for i in range(numCourses) if indegree[i] == 0)

        count = 0
        while queue:
            cur = queue.popleft()
            count += 1
            for nxt in graph[cur]:
                indegree[nxt] -= 1                # 修完一門先修課
                if indegree[nxt] == 0:
                    queue.append(nxt)

        return count == numCourses                # 全部修完才代表無環


# 方法二：DFS 三色標記
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        for course, pre in prerequisites:
            graph[pre].append(course)

        # 0=未訪問, 1=正在遞迴中, 2=已完成
        state = [0] * numCourses

        def dfs(node):
            if state[node] == 1:      # 遇到灰色 → 有環
                return False
            if state[node] == 2:      # 已驗證過
                return True

            state[node] = 1           # 標記為「正在處理」
            for nxt in graph[node]:
                if not dfs(nxt):
                    return False
            state[node] = 2           # 標記為「已完成」
            return True

        return all(dfs(i) for i in range(numCourses))
// 方法一：BFS 拓撲排序（Kahn，推薦）
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> graph(numCourses);
        vector<int> indegree(numCourses, 0);

        for (auto& p : prerequisites) {
            graph[p[1]].push_back(p[0]);      // pre → course
            indegree[p[0]]++;
        }

        queue<int> q;
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) q.push(i);
        }

        int count = 0;
        while (!q.empty()) {
            int cur = q.front(); q.pop();
            count++;
            for (int nxt : graph[cur]) {
                if (--indegree[nxt] == 0) q.push(nxt);
            }
        }
        return count == numCourses;
    }
};

// 方法二：DFS 三色標記
class Solution {
    vector<vector<int>> graph;
    vector<int> state;    // 0=未訪問, 1=遞迴中, 2=已完成

    bool dfs(int node) {
        if (state[node] == 1) return false;   // 灰色 → 有環
        if (state[node] == 2) return true;    // 黑色 → 已驗證

        state[node] = 1;
        for (int nxt : graph[node]) {
            if (!dfs(nxt)) return false;
        }
        state[node] = 2;
        return true;
    }

public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        graph.assign(numCourses, {});
        state.assign(numCourses, 0);
        for (auto& p : prerequisites) graph[p[1]].push_back(p[0]);

        for (int i = 0; i < numCourses; i++) {
            if (!dfs(i)) return false;
        }
        return true;
    }
};
// 方法一：BFS 拓撲排序（Kahn，推薦）
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
        int[] indegree = new int[numCourses];

        for (int[] p : prerequisites) {
            graph.get(p[1]).add(p[0]);        // pre → course
            indegree[p[0]]++;
        }

        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) queue.offer(i);
        }

        int count = 0;
        while (!queue.isEmpty()) {
            int cur = queue.poll();
            count++;
            for (int nxt : graph.get(cur)) {
                if (--indegree[nxt] == 0) queue.offer(nxt);
            }
        }
        return count == numCourses;
    }
}

複雜度分析

時間複雜度：O(V + E)
  • V = numCourses（節點數），E = prerequisites 長度（邊數）
  • 每個節點入隊出隊各一次，每條邊處理一次
空間複雜度：O(V + E)
  • 鄰接表 O(V + E)、入度陣列 O(V)、佇列 O(V)

重點提示

💡 關鍵技巧 1：建圖方向不要弄反

[a, b] 表示「學 a 前要先學 b」，所以邊是 b → a，且 a 的入度 +1。方向弄反答案就完全錯了，這是本題最常見的失分點。

💡 關鍵技巧 2：BFS 版用「計數」判斷有環

如果最後修完的課程數 < numCourses，代表有些課程的入度永遠降不到 0 —— 它們互相依賴形成環。這個判斷法非常簡潔，不需要額外的環偵測邏輯。

💡 BFS vs DFS 怎麼選？
  • BFS（Kahn）：不會 stack overflow，還能順便輸出拓撲序（#210），推薦首選
  • DFS 三色：程式碼較短，但深度大時有堆疊風險；輸出拓撲序時需要把完成順序反轉
⚠️ 常見錯誤：
  • 建圖方向反了
  • DFS 只用兩種狀態（訪問/未訪問），把「共用節點」誤判成環
  • 忘記處理孤立節點（沒有任何先修關係的課程，入度為 0 要一開始就入隊）
  • DFS 版本只從節點 0 開始，沒有對每個節點都嘗試（圖可能不連通）

補充說明

拓撲排序的應用場景

🔧 實務中無處不在
• 建置系統：make / bazel 決定編譯順序（.c → .o → 可執行檔）
• 套件管理：npm / pip / apt 解析依賴，偵測循環依賴
• 任務排程：CI/CD pipeline、Airflow DAG 的執行順序
• 課程規劃：大學必修課的先後順序（本題原型）
• 試算表：Excel 儲存格公式的重算順序（循環參照 = 有環）
• 編譯器：指令排程、資料流分析
• 資料庫：交易的相依關係與死鎖偵測

有環 = 循環依賴 = 系統無解，
所以「偵測環」在這些系統中都是必要的錯誤檢查。

有向圖 vs 無向圖的環偵測

【有向圖】
  方法 1：拓撲排序，看是否所有節點都能排出來（本題）
  方法 2：DFS 三色標記，遇到「灰色」節點即有環

【無向圖】
  方法 1：DFS 時記錄父節點，
          若遇到已訪問且【不是父節點】的節點 → 有環
  方法 2：Union-Find，若一條邊的兩端已在同一集合 → 有環
  方法 3：若 邊數 >= 節點數，必定有環（連通圖）

⚠️ 無向圖不能直接用「遇到已訪問就是環」，
   因為 A→B 走過後，從 B 看回 A 會誤判。

#210 Course Schedule II：輸出順序

只要把 Kahn 演算法中出隊的節點依序記錄下來即可：

vector<int> order;
while (!q.empty()) {
    int cur = q.front(); q.pop();
    order.push_back(cur);              // ← 多這一行
    for (int nxt : graph[cur])
        if (--indegree[nxt] == 0) q.push(nxt);
}
return order.size() == numCourses ? order : vector<int>{};
