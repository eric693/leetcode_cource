#190 Reverse Bits

Easy
Bit Manipulation Divide and Conquer

題目描述

顛倒給定的 32 位元無號整數的二進位位元。

例如輸入 00000010100101000001111010011100，輸出 00111001011110000010100101000000。

進階：如果這個函數被呼叫很多次，你要如何優化？（這是韌體面試最愛的追問）

範例

範例 1：
輸入：n = 00000010100101000001111010011100（十進位 43261596）
輸出：00111001011110000010100101000000（十進位 964176192）
範例 2：
輸入：n = 11111111111111111111111111111101（十進位 4294967293）
輸出：10111111111111111111111111111111（十進位 3221225471）

解題思路

💡 方法一：逐位搬移

把 n 的最低位一個一個取出，塞進 result 的最低位，同時 result 左移。

n = 1011（只看 4 位示範）
result = 0000

第 1 輪：result = (0000 << 1) | (n & 1)=1 → 0001, n = 101
第 2 輪：result = (0001 << 1) | 1        → 0011, n = 10
第 3 輪：result = (0011 << 1) | 0        → 0110, n = 1
第 4 輪：result = (0110 << 1) | 1        → 1101, n = 0

1011 反轉 → 1101 ✓

方法二：分治法（Divide & Conquer）

🎯 只要 5 步，O(log 32)

先交換相鄰的 16 位、再交換 8 位、4 位、2 位、1 位，就完成整體反轉。

原始： ABCDEFGH（每個字母代表 4 位）
換16： EFGHABCD
換8 ： GHEFCDAB
換4 ： HGFEDCBA  （4 位群組已反轉）
換2 ： 群組內每 2 位再交換
換1 ： 最後每 1 位交換 → 完全反轉

遮罩：
0xFFFF0000 / 0x0000FFFF   16 位
0xFF00FF00 / 0x00FF00FF   8 位
0xF0F0F0F0 / 0x0F0F0F0F   4 位
0xCCCCCCCC / 0x33333333   2 位
0xAAAAAAAA / 0x55555555   1 位

方法三：查表 + 快取（回答「呼叫很多次」的進階題）

⚡ 拆成 4 個 byte 查表

建立 256 大小的 byte 反轉表，把 32 位元拆成 4 個 byte，各自查表後再反序組回去。若輸入有重複，還可以用 HashMap 做記憶化快取。

程式碼實現

# 方法一：逐位搬移
class Solution:
    def reverseBits(self, n: int) -> int:
        result = 0
        for _ in range(32):
            result = (result << 1) | (n & 1)
            n >>= 1
        return result


# 方法二：分治法（只要 5 步）
class Solution:
    def reverseBits(self, n: int) -> int:
        n = ((n & 0xFFFF0000) >> 16) | ((n & 0x0000FFFF) << 16)
        n = ((n & 0xFF00FF00) >> 8)  | ((n & 0x00FF00FF) << 8)
        n = ((n & 0xF0F0F0F0) >> 4)  | ((n & 0x0F0F0F0F) << 4)
        n = ((n & 0xCCCCCCCC) >> 2)  | ((n & 0x33333333) << 2)
        n = ((n & 0xAAAAAAAA) >> 1)  | ((n & 0x55555555) << 1)
        return n


# 方法三：查表 + 記憶化（適合被呼叫很多次）
class Solution:
    cache = {}

    def reverseBits(self, n: int) -> int:
        result, power = 0, 24
        while n:
            byte = n & 0xFF
            result |= self.reverseByte(byte) << power
            n >>= 8
            power -= 8
        return result

    def reverseByte(self, byte):
        if byte in self.cache:
            return self.cache[byte]
        value = (byte * 0x0202020202 & 0x010884422010) % 1023
        self.cache[byte] = value
        return value

// 方法三：查表法（被呼叫很多次時最快）
class Solution {
    uint8_t table[256];
public:
    Solution() {
        for (int i = 0; i < 256; i++) {
            uint8_t b = i, r = 0;
            for (int j = 0; j < 8; j++) { r = (r << 1) | (b & 1); b >>= 1; }
            table[i] = r;
        }
    }
    uint32_t reverseBits(uint32_t n) {
        return (table[n & 0xFF] << 24) | (table[(n >> 8) & 0xFF] << 16)
             | (table[(n >> 16) & 0xFF] << 8) | table[(n >> 24) & 0xFF];
    }
};

public class Solution {
    public int reverseBits(int n) {
        n = (n >>> 16) | (n << 16);
        n = ((n & 0xFF00FF00) >>> 8)  | ((n & 0x00FF00FF) << 8);
        n = ((n & 0xF0F0F0F0) >>> 4)  | ((n & 0x0F0F0F0F) << 4);
        n = ((n & 0xCCCCCCCC) >>> 2)  | ((n & 0x33333333) << 2);
        n = ((n & 0xAAAAAAAA) >>> 1)  | ((n & 0x55555555) << 1);
        return n;
    }
}

// 方法三：Java 內建
public class Solution {
    public int reverseBits(int n) {
        return Integer.reverse(n);
    }
}
// 逐位搬移：取出 n 的最低位，放到結果的最低位後左移
// 時間複雜度: O(32)，空間複雜度: O(1)
function reverseBits(n: number): number {
    let result = 0;
    for (let i = 0; i < 32; i++) {
        result = (result << 1) | (n & 1);
        n >>>= 1;                           // 無號右移
    }
    return result >>> 0;                    // 轉回無號 32 位元
}
// 分治交換：先交換高低 16 位，再 8 位、4 位、2 位、1 位（韌體常見寫法）
// 時間複雜度: O(1)，空間複雜度: O(1)
uint32_t reverseBits(uint32_t n) {
    n = (n >> 16) | (n << 16);
    n = ((n & 0xff00ff00u) >> 8) | ((n & 0x00ff00ffu) << 8);
    n = ((n & 0xf0f0f0f0u) >> 4) | ((n & 0x0f0f0f0fu) << 4);
    n = ((n & 0xccccccccu) >> 2) | ((n & 0x33333333u) << 2);
    n = ((n & 0xaaaaaaaau) >> 1) | ((n & 0x55555555u) << 1);
    return n;
}

複雜度分析

時間複雜度：
  • 方法一：O(32) = O(1)
  • 方法二（分治）：O(5) = O(1)，實際運算次數最少
  • 方法三（查表）：O(4) = O(1)，加上一次性建表 O(256)
空間複雜度：
  • 方法一、二：O(1)
  • 方法三：O(256) 查表空間

重點提示

💡 關鍵技巧 1：分治遮罩要記熟

0xAAAAAAAA / 0x55555555（奇偶位）、0xCCCCCCCC / 0x33333333（每 2 位）、0xF0F0F0F0 / 0x0F0F0F0F（每 4 位），這組遮罩在 popcount、bit reverse、byte swap 都會用到。

💡 關鍵技巧 2：進階題的標準答案

面試官問「呼叫很多次怎麼優化」時，答案就是：拆 byte 查表 + 快取。這題就是在考這個。

⚠️ 常見錯誤：
  • Java 一定要用 >>>，用 >> 對負數會補 1 造成錯誤
  • Python 整數沒有位寬限制，左移後要記得 & 0xFFFFFFFF（本題因為固定 32 輪所以安全）
  • C++ 用 int 而非 uint32_t 會有 UB

韌體實務：Byte Swap（大小端轉換）

🔧 endianness 轉換是同一個技巧
// 32 位元 big-endian ↔ little-endian
uint32_t bswap32(uint32_t x) {
    return ((x & 0xFF000000) >> 24) |
           ((x & 0x00FF0000) >> 8)  |
           ((x & 0x0000FF00) << 8)  |
           ((x & 0x000000FF) << 24);
}
// GCC 內建：__builtin_bswap32(x)
// 網路位元組序：htonl() / ntohl()

差別：bit reverse 是反轉「每一個位元」，
      byte swap 是只反轉「位元組順序」，byte 內部不動。
