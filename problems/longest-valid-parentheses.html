32. Longest Valid Parentheses
Hard

題目描述

給定一個只包含 ( 和 ) 的字串，找出最長有效（格式正確且連續）括號子字串的長度。

範例 1:
輸入: s = "(()"
輸出: 2
解釋: 最長有效括號子字串是 "()"
範例 2:
輸入: s = ")()())"
輸出: 4
解釋: 最長有效括號子字串是 "()()"
範例 3:
輸入: s = ""
輸出: 0

解題思路

方法一：堆疊記錄索引（推薦）

堆疊中存放的是索引而非字元，並先放入 -1 作為「最後一個未匹配右括號的位置」哨兵。

遇到 ( 就把索引推入堆疊；遇到 ) 則先彈出一個元素：若堆疊變空，代表這個右括號無法匹配，把它自己的索引推入當作新的基準；否則用當前索引減去堆疊頂端索引，即為以此處結尾的有效長度。

一次掃描即可，邏輯清楚且不易出錯。

方法二：動態規劃

定義 dp[i] 為「以 s[i] 結尾的最長有效括號長度」，只有 s[i] 為 ) 時才可能非零。

若 s[i-1] 為 (，則 dp[i] = dp[i-2] + 2；若 s[i-1] 為 )，則檢查與之配對的位置 j = i - dp[i-1] - 1，當 s[j] 為 ( 時 dp[i] = dp[i-1] + 2 + dp[j-1]。

答案為 dp 陣列的最大值，時間 O(n)、空間 O(n)。

方法三：左右兩次掃描（O(1) 空間）

由左往右計數 left、right，兩者相等時更新答案，right 超過 left 時歸零。

再由右往左做一次對稱的掃描，即可補上像 "(()" 這類左括號偏多的情況。此法只需常數額外空間。

程式碼實現

class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]          # 哨兵：最後一個未匹配右括號的索引
        longest = 0

        for i, ch in enumerate(s):
            if ch == '(':
                stack.append(i)
            else:
                stack.pop()
                if not stack:
                    stack.append(i)      # 此右括號無法匹配，成為新基準
                else:
                    longest = max(longest, i - stack[-1])

        return longest
class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);
        int longest = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    longest = Math.max(longest, i - stack.peek());
                }
            }
        }
        return longest;
    }
}

// 時間複雜度: O(n)，空間複雜度: O(n)
function longestValidParentheses(s: string): number {
    const stack: number[] = [-1];
    let best = 0;
    for (let i = 0; i < s.length; i++) {
        if (s[i] === '(') {
            stack.push(i);
        } else {
            stack.pop();
            if (stack.length === 0) stack.push(i);       // 新的分界點
            else best = Math.max(best, i - stack[stack.length - 1]);
        }
    }
    return best;
}
// 堆疊存索引，棧底永遠放「最後一個未匹配的右括號位置」
// 時間複雜度: O(n)，空間複雜度: O(n)
int longestValidParentheses(char* s) {
    int n = strlen(s);
    int* stack = malloc(sizeof(int) * (n + 1));
    int top = 0, best = 0;
    stack[top++] = -1;
    for (int i = 0; i < n; i++) {
        if (s[i] == '(') {
            stack[top++] = i;
        } else {
            top--;
            if (top == 0) stack[top++] = i;              // 新的分界點
            else if (i - stack[top - 1] > best) best = i - stack[top - 1];
        }
    }
    free(stack);
    return best;
}
class Solution {
public:
    int longestValidParentheses(string s) {
        stack<int> st;
        st.push(-1);
        int longest = 0;

        for (int i = 0; i < (int)s.size(); i++) {
            if (s[i] == '(') {
                st.push(i);
            } else {
                st.pop();
                if (st.empty()) {
                    st.push(i);
                } else {
                    longest = max(longest, i - st.top());
                }
            }
        }
        return longest;
    }
};

複雜度分析

時間複雜度: O(n)

每個字元只被推入與彈出堆疊各一次，單次掃描即可完成。

空間複雜度: O(n)

最壞情況（例如全部是左括號）堆疊會存放 n 個索引；兩次掃描解法可降到 O(1)。

重點提示

  • 堆疊存索引：存索引而非字元，才能用「當前位置減基準位置」直接算出長度
  • 哨兵 -1 的作用：讓第一段從開頭起算的有效括號能正確得到長度，省去特判
  • 彈出後再判空：先 pop 再檢查是否為空，是區分「成功匹配」與「多餘右括號」的關鍵
  • 與 valid-parentheses 的差異：本題求最長連續有效長度，不只是判斷整體是否合法，因此必須追蹤位置資訊
