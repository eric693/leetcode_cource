#14 Longest Common Prefix

Easy
String Trie Divide and Conquer

題目描述

編寫一個函數來尋找字串陣列中的最長公共前綴。

如果不存在公共前綴，返回空字串 ""。

範例

範例 1：
輸入：strs = ["flower","flow","flight"]
輸出："fl"
範例 2：
輸入：strs = ["dog","racecar","car"]
輸出：""
解釋：輸入不存在公共前綴。

解題思路

💡 方法一：縱向掃描（推薦，最直覺）
一列一列（一個字元位置一個字元位置）往下比：

  f l o w e r
  f l o w
  f l i g h t
  ↑ ↑ ↑
  ✓ ✓ ✗

第 0 個字元：全部都是 'f' ✓
第 1 個字元：全部都是 'l' ✓
第 2 個字元：'o','o','i' 不同 ✗ → 停止

答案 = "fl"

提早停止條件：
1. 遇到不同的字元
2. 某個字串已經走到結尾（前綴不可能比最短的字串長）

最佳情況只比第一個字元就結束，效率很好。

方法二：橫向掃描

逐一與前一個結果取交集
prefix = "flower"
prefix = LCP("flower", "flow")   = "flow"
prefix = LCP("flow", "flight")   = "fl"
→ 答案 "fl"

若中途 prefix 變成空字串，可以立刻返回。

方法三：排序取頭尾（面試小技巧）

⚡ 只需要比較兩個字串
字典序排序後，只要比較【第一個】和【最後一個】字串即可！

原理：字典序最小和最大的兩個字串，
      它們的公共前綴必定是所有字串的公共前綴。
      （中間的字串必然介於兩者之間，前綴也被夾住）

["flower","flow","flight"]
排序後 → ["flight","flow","flower"]
比較 "flight" 和 "flower" → "fl" ✓

複雜度 O(n log n × L)，理論上比縱向掃描差，
但程式碼極短，適合快速寫出來。

程式碼實現

# 方法一：縱向掃描（推薦）
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""

        first = strs[0]
        for i in range(len(first)):
            ch = first[i]
            for s in strs[1:]:
                # 走到某字串結尾，或字元不同 → 停止
                if i >= len(s) or s[i] != ch:
                    return first[:i]
        return first


# 方法二：橫向掃描
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        prefix = strs[0]
        for s in strs[1:]:
            while not s.startswith(prefix):
                prefix = prefix[:-1]     # 每次砍掉最後一個字元
                if not prefix:
                    return ""
        return prefix


# 方法三：排序取頭尾（最短的寫法）
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        strs.sort()
        first, last = strs[0], strs[-1]
        i = 0
        while i < len(first) and i < len(last) and first[i] == last[i]:
            i += 1
        return first[:i]

class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs == null || strs.length == 0) return "";

        for (int i = 0; i < strs[0].length(); i++) {
            char c = strs[0].charAt(i);
            for (int j = 1; j < strs.length; j++) {
                if (i >= strs[j].length() || strs[j].charAt(i) != c) {
                    return strs[0].substring(0, i);
                }
            }
        }

    }

// 方法二：橫向掃描
class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs == null || strs.length == 0) return "";
        String prefix = strs[0];
        for (int i = 1; i < strs.length; i++) {
            while (strs[i].indexOf(prefix) != 0) {
                prefix = prefix.substring(0, prefix.length() - 1);
                if (prefix.isEmpty()) return "";
            }
        }
        return prefix;
    }
}
// 縱向比較：以第一個字串為基準，逐字元檢查所有字串
// 時間複雜度: O(S)，S 為所有字元總數；空間複雜度: O(1)
function longestCommonPrefix(strs: string[]): string {
    const first = strs[0];
    for (let i = 0; i < first.length; i++) {
        for (let j = 1; j < strs.length; j++) {
            if (i === strs[j].length || strs[j][i] !== first[i]) {
                return first.slice(0, i);
            }
        }
    }
    return first;
}
// 縱向比較：以第一個字串為基準，逐字元檢查所有字串
// 時間複雜度: O(S)，S 為所有字元總數；空間複雜度: O(1)
char* longestCommonPrefix(char** strs, int strsSize) {
    char* first = strs[0];
    int i = 0;
    for (; first[i]; i++) {
        int j = 1;
        for (; j < strsSize; j++) {
            if (strs[j][i] != first[i]) break;   // 包含 strs[j] 已經結束（'\0'）的情況
        }
        if (j < strsSize) break;
    }
    char* ans = malloc(i + 1);
    memcpy(ans, first, i);
    ans[i] = '\0';
    return ans;
}

複雜度分析

時間複雜度：O(S)
  • S = 所有字串的字元總數（最壞情況要比對全部）
  • 實務上通常遠低於此，因為很快就會遇到不同字元
  • 方法三（排序）為 O(n log n × L)
空間複雜度：O(1)，不計返回值所需空間

重點提示

💡 關鍵技巧：邊界檢查要完整

必須同時檢查「索引是否超出其他字串長度」和「字元是否相同」。只檢查字元會在 ["ab", "a"] 這種輸入上越界崩潰。

💡 面試延伸：如果要支援大量查詢怎麼辦？

建一棵 Trie，從根節點往下走，只要節點只有一個子節點且不是單字結尾就繼續，否則停止。走過的路徑就是最長公共前綴。建樹 O(S)，之後每次查詢 O(L)。

⚠️ 常見錯誤：
  • 忘記處理空陣列或包含空字串的情況
  • 索引越界（沒檢查其他字串的長度）
  • 方法三修改了輸入陣列的順序（若題目要求不可修改，要先複製）

補充說明

方法四：分治法

🔀 把陣列切半各自求解再合併
LCP(strs[0..n-1]) = LCP( LCP(strs[0..mid]), LCP(strs[mid+1..n-1]) )

["flower","flow","flight","flock"]
        /                    \
["flower","flow"]      ["flight","flock"]
    = "flow"                = "fl"
        \                    /
          LCP("flow","fl") = "fl" ✓

複雜度同樣是 O(S)，但可以平行化處理，
適合超大量字串的分散式場景。

方法五：Trie 解法

建 Trie 後從根往下走，停止條件：
  1. 當前節點有 > 1 個子節點（開始分岔）
  2. 當前節點是某個單字的結尾（不能再往下）

["flower","flow","flight"]
root → f → l → 這裡分岔成 o 和 i → 停止
答案 = "fl" ✓

適用場景：字串集合固定，但要反覆查詢
          「某個子集合的最長公共前綴」。

實務應用

  • 檔案路徑：找出一組路徑的共同根目錄
  • IP 路由：最長前綴匹配（Longest Prefix Match）決定封包走哪條路由
  • 版本控制：git 用前綴唯一性讓你只打 commit hash 的前幾碼
  • 自動補全：輸入框顯示所有候選的共同部分
