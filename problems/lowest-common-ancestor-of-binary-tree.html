#236 Lowest Common Ancestor of a Binary Tree

Medium
Tree DFS Binary Tree Recursion

題目描述

給定一個二元樹，找到該樹中兩個指定節點 p、q 的最近公共祖先（LCA）。

最近公共祖先的定義為：「對於有根樹 T 的兩個節點 p、q，最近公共祖先表示為一個節點 x，滿足 x 是 p、q 的祖先且 x 的深度盡可能大（一個節點也可以是它自己的祖先）。」

注意：這是普通二元樹，不是 BST，所以不能利用大小關係。

範例

範例 1：
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4

輸入：p = 5, q = 1
輸出：3
範例 2：
輸入：（同上樹）p = 5, q = 4
輸出：5
解釋：節點 5 是節點 4 的祖先，根據定義，5 也是自己的祖先。

解題思路

核心：後序遍歷 + 「往上回報」
遞迴函數的語意定義（這是最關鍵的一步）：

  lca(node) 回傳：
    - 若 node 子樹中「同時」找到 p 和 q → 回傳 LCA
    - 若只找到其中一個 → 回傳那一個
    - 若都沒找到 → 回傳 null

【三種情況】

情況 1：node == null 或 node == p 或 node == q
        → 直接回傳 node（找到目標，或走到底）

情況 2：左右子樹「各回傳一個非 null」
        → 表示 p 和 q 分別在兩側
        → node 就是 LCA！回傳 node

情況 3：只有一側非 null
        → 兩個目標都在那一側（或只找到一個）
        → 把那一側的結果往上傳

完整推導：p = 5, q = 4

從葉子往上回報
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4

lca(6) = null（不是 p 也不是 q，無子樹）
lca(7) = null
lca(4) = 4  ← 命中 q！
lca(2)：left = lca(7) = null, right = lca(4) = 4
        只有一側非 null → 回傳 4
lca(5) = 5  ← 命中 p！直接回傳，不再往下找
        （這裡是關鍵：即使 q 在 5 的子樹裡，
          也不需要繼續找，因為 5 必定是答案）
lca(0) = null, lca(8) = null
lca(1)：兩側都 null → 回傳 null
lca(3)：left = 5, right = null
        只有一側非 null → 回傳 5 ✓

答案 = 5 ✓

為什麼「遇到 p 就直接回傳」是對的？

兩種情況都正確
假設在節點 x 遇到了 p，直接回傳 x：

情況 A：q 也在 x 的子樹裡
  → LCA 就是 x（因為 x 是 p 自己，且 x 是 q 的祖先）✓
  → 直接回傳 x 正確

情況 B：q 不在 x 的子樹裡
  → x 只是「找到 p 的訊號」往上傳
  → 上層某個節點會同時收到左右兩側的訊號，
     在那裡正確判定 LCA ✓

所以不管哪種情況，提早返回都不會出錯，
而且還能省去不必要的搜尋。

程式碼實現

# 遞迴（推薦，簡潔優雅）
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        # 情況 1：走到底，或命中目標
        if not root or root is p or root is q:
            return root

        # 分別在左右子樹中尋找
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        # 情況 2：兩側各找到一個 → root 就是 LCA
        if left and right:
            return root

        # 情況 3：只有一側有結果，往上傳
        return left if left else right


# 方法二：記錄父節點 + 集合（更直覺，也更好處理多次查詢）
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        parent = {root: None}

        # BFS/DFS 建立每個節點的父節點對照表
        stack = [root]
        while stack:
            node = stack.pop()
            if node.left:
                parent[node.left] = node
                stack.append(node.left)
            if node.right:
                parent[node.right] = node
                stack.append(node.right)

        # 收集 p 的所有祖先
        ancestors = set()
        node = p
        while node:
            ancestors.add(node)
            node = parent[node]

        # 從 q 往上找第一個在 p 祖先集合中的節點
        node = q
        while node not in ancestors:
            node = parent[node]
        return node
// 遞迴（推薦）
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // 情況 1：走到底，或命中目標
        if (!root || root == p || root == q) return root;

        TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        // 情況 2：兩側各找到一個 → root 就是 LCA
        if (left && right) return root;

        // 情況 3：只有一側有結果，往上傳
        return left ? left : right;
    }
};
// 遞迴（推薦）
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 情況 1：走到底，或命中目標
        if (root == null || root == p || root == q) return root;

        TreeNode left  = lowestCommonAncestor(root.left,  p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        // 情況 2：兩側各找到一個 → root 就是 LCA
        if (left != null && right != null) return root;

        // 情況 3：只有一側有結果，往上傳
        return (left != null) ? left : right;
    }
}
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 * }
 */
// 後序遞迴：左右子樹各找到一個，當前節點就是 LCA
// 時間複雜度: O(n)，空間複雜度: O(h)
function lowestCommonAncestor(root: TreeNode | null, p: TreeNode | null, q: TreeNode | null): TreeNode | null {
    if (!root || root === p || root === q) return root;
    const left = lowestCommonAncestor(root.left, p, q);
    const right = lowestCommonAncestor(root.right, p, q);
    if (left && right) return root;
    return left ?? right;
}
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */
// 後序遞迴：左右子樹各找到一個，當前節點就是 LCA
// 時間複雜度: O(n)，空間複雜度: O(h)
struct TreeNode* lowestCommonAncestor(struct TreeNode* root, struct TreeNode* p, struct TreeNode* q) {
    if (!root || root == p || root == q) return root;
    struct TreeNode* left = lowestCommonAncestor(root->left, p, q);
    struct TreeNode* right = lowestCommonAncestor(root->right, p, q);
    if (left && right) return root;
    return left ? left : right;
}

複雜度分析

時間複雜度：O(n)
  • 最壞情況需要走訪每個節點一次
空間複雜度：O(h)
  • 遞迴堆疊深度等於樹高，最壞（退化成鏈）為 O(n)
  • 父節點對照表法為 O(n)

重點提示

關鍵技巧 1：先定義好遞迴函數的「語意」

本題的精髓在於清楚定義「這個函數回傳什麼」。定義好之後，三種情況的處理自然就浮現了。這是解所有樹遞迴題的通用方法：先想清楚回傳值代表什麼意思。

關鍵技巧 2：後序遍歷的「資訊上傳」模式

需要「先知道子樹的結果，才能決定當前節點」的題目，都是後序遍歷。例如 #543 樹的直徑、#110 平衡二元樹、#124 最大路徑和，模式完全相同。

對比 #235（BST 版本）

如果是 BST，可以利用大小關係直接往下走：都比 root 小就往左、都比 root 大就往右、一大一小（或等於）就是 LCA。時間 O(h)，不需要走訪整棵樹，比本題更快。

常見錯誤：
  • 比較節點時用 val 而非參考（若題目允許重複值就會出錯）
  • 誤以為需要先確認 p、q 都存在（本題保證存在；若不保證，需額外用旗標記錄是否真的找到兩者）
  • 情況 3 寫成只回傳 left，漏掉 right
  • 找到答案後沒有提早返回，做了不必要的搜尋（雖然不影響正確性）

補充說明

#235 BST 版本的解法

// 利用 BST 的大小關係，只需 O(h)，且可以寫成迭代
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    while (root) {
        if (p->val < root->val && q->val < root->val)
            root = root->left;        // 兩者都在左子樹
        else if (p->val > root->val && q->val > root->val)
            root = root->right;       // 兩者都在右子樹
        else
            return root;              // 分岔點（或命中其中一個）就是 LCA
    }
    return nullptr;
}

#1650：有 parent 指標的版本

轉化成鏈結串列找交點
若每個節點都有 parent 指標，
從 p 往上走和從 q 往上走，就是兩條「鏈結串列」，
它們的交會點就是 LCA —— 完全等同於 #160！

Node* lowestCommonAncestor(Node* p, Node* q) {
    Node *a = p, *b = q;
    while (a != b) {
        a = a->parent ? a->parent : q;   // 走完換到對方起點
        b = b->parent ? b->parent : p;
    }
    return a;
}

O(h) 時間，O(1) 空間，非常漂亮。

進階：多次查詢的 LCA

倍增法（Binary Lifting）
如果要對同一棵樹做「大量 LCA 查詢」，
每次 O(n) 太慢，可以預處理：

up[v][k] = 節點 v 的第 2^k 個祖先

預處理 O(n log n)：
  up[v][0] = parent[v]
  up[v][k] = up[ up[v][k-1] ][k-1]

查詢 O(log n)：
  1. 先把較深的節點往上跳到同深度
  2. 兩者一起從大到小的 k 往上跳，
     只要 up[u][k] != up[v][k] 就跳
  3. 最後 parent[u] 就是 LCA

這是競賽與大型樹結構（如檔案系統、組織架構）
的標準做法，也是離線演算法 Tarjan LCA 的替代方案。
