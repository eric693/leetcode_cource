#234 Palindrome Linked List

Easy
Linked List Two Pointers Stack Recursion

題目描述

給你一個單向鏈結串列的頭節點 head，請你判斷該串列是否為回文串列。如果是，返回 true；否則返回 false。

進階：你能否用 O(n) 時間複雜度和 O(1) 空間複雜度解決此題？

範例

範例 1：
輸入：head = [1,2,2,1]
輸出：true
範例 2：
輸入：head = [1,2]
輸出：false
範例 3：
輸入：head = [1,2,3,2,1]
輸出：true（奇數長度，中間節點不影響）

解題思路

💡 O(1) 空間解法三部曲
單向串列不能往回走，所以要「把後半段反轉」再比對。

步驟 1：快慢指標找中點
步驟 2：反轉後半段
步驟 3：從頭和從中點同時往後比對

list = [1,2,3,2,1]

【步驟 1】找中點
1 → 2 → 3 → 2 → 1
        ↑ slow（fast 走到尾端）

【步驟 2】反轉後半段（從 slow 開始）
前半：1 → 2 → 3
後半：1 → 2 → 3（反轉後）

【步驟 3】同步比對
  1 vs 1 ✓
  2 vs 2 ✓
  遇到 null 結束 → 是回文 ✓

注意：只要比對到其中一邊走完就好，
      奇數長度時中間節點會被兩邊共用，不影響結果。

反轉串列的標準寫法

🎯 三指標翻轉
prev = None, curr = head
while curr:
    next_node = curr.next    # 1. 先存下一個
    curr.next = prev         # 2. 反轉指標方向
    prev = curr              # 3. prev 前進
    curr = next_node         # 4. curr 前進
return prev                  # prev 是新的頭

原：1 → 2 → 3 → null
後：null ← 1 ← 2 ← 3

其他解法比較

📊 三種做法
方法          時間    空間    優點
--------------------------------------------------
複製到陣列    O(n)    O(n)   最簡單，5 行搞定
用堆疊        O(n)    O(n)   前半推入堆疊，後半比對
反轉後半段    O(n)    O(1)   ★ 進階要求的答案
遞迴          O(n)    O(n)   優雅但有堆疊深度風險

程式碼實現

# 方法一：反轉後半段（O(1) 空間，推薦）
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        if not head or not head.next:
            return True

        # 步驟 1：快慢指標找中點
        slow = fast = head
        while fast.next and fast.next.next:
            slow = slow.next
            fast = fast.next.next

        # 步驟 2：反轉後半段
        second = self.reverse(slow.next)

        # 步驟 3：比對前後半段
        p1, p2 = head, second
        result = True
        while p2:                     # 後半段較短，以它為準
            if p1.val != p2.val:
                result = False
                break
            p1 = p1.next
            p2 = p2.next

        # 步驟 4（好習慣）：把串列還原
        slow.next = self.reverse(second)
        return result

    def reverse(self, node):
        prev = None
        while node:
            nxt = node.next
            node.next = prev
            prev = node
            node = nxt
        return prev


# 方法二：複製到陣列（最簡單，O(n) 空間）
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        vals = []
        while head:
            vals.append(head.val)
            head = head.next
        return vals == vals[::-1]

class Solution {
    ListNode* reverse(ListNode* node) {
        ListNode* prev = nullptr;
        while (node) {
            ListNode* nxt = node->next;
            node->next = prev;
            prev = node;
            node = nxt;
        }
        return prev;
    }

public:
    bool isPalindrome(ListNode* head) {
        if (!head || !head->next) return true;

        // 步驟 1：找中點
        ListNode *slow = head, *fast = head;
        while (fast->next && fast->next->next) {
            slow = slow->next;
            fast = fast->next->next;
        }

        // 步驟 2：反轉後半段
        ListNode* second = reverse(slow->next);

        // 步驟 3：比對
        ListNode *p1 = head, *p2 = second;
        bool result = true;
        while (p2) {
            if (p1->val != p2->val) { result = false; break; }
            p1 = p1->next;
            p2 = p2->next;
        }

        // 步驟 4：還原串列（面試加分項）
        slow->next = reverse(second);
        return result;
    }
};
// 方法一：反轉後半段（O(1) 空間，推薦）
class Solution {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;

        // 步驟 1：找中點
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 步驟 2：反轉後半段
        ListNode second = reverse(slow.next);

        // 步驟 3：比對
        ListNode p1 = head, p2 = second;
        boolean result = true;
        while (p2 != null) {
            if (p1.val != p2.val) { result = false; break; }
            p1 = p1.next;
            p2 = p2.next;
        }

        // 步驟 4：還原串列
        slow.next = reverse(second);
        return result;
    }

    private ListNode reverse(ListNode node) {
        ListNode prev = null;
        while (node != null) {
            ListNode nxt = node.next;
            node.next = prev;
            prev = node;
            node = nxt;
        }
        return prev;
    }
}

 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 * }
 */
// 快慢指針找中點 → 反轉後半段 → 與前半段逐一比較
// 時間複雜度: O(n)，空間複雜度: O(1)
function isPalindrome(head: ListNode | null): boolean {
    let slow = head, fast = head;
    while (fast && fast.next) {
        slow = slow!.next;
        fast = fast.next.next;
    }

    let prev: ListNode | null = null;          // 反轉後半段
    while (slow) {
        const next: ListNode | null = slow.next;
        slow.next = prev;
        prev = slow;
        slow = next;
    }

    let a = head, b = prev;
    while (b) {
        if (a!.val !== b.val) return false;
        a = a!.next;
        b = b.next;
    }
    return true;
}
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
// 快慢指針找中點 → 反轉後半段 → 與前半段逐一比較
// 時間複雜度: O(n)，空間複雜度: O(1)
bool isPalindrome(struct ListNode* head) {
    struct ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }

    struct ListNode* prev = NULL;              // 反轉後半段
    while (slow) {
        struct ListNode* next = slow->next;
        slow->next = prev;
        prev = slow;
        slow = next;
    }

    for (struct ListNode *a = head, *b = prev; b; a = a->next, b = b->next) {
        if (a->val != b->val) return false;
    }
    return true;
}

複雜度分析

時間複雜度：O(n)
  • 找中點 O(n/2) + 反轉 O(n/2) + 比對 O(n/2) + 還原 O(n/2)
空間複雜度：
  • 反轉法：O(1) ★ 進階要求
  • 陣列/堆疊法：O(n)
  • 遞迴法：O(n) 的呼叫堆疊

重點提示

💡 關鍵技巧 1：找中點的迴圈條件

用 fast.next && fast.next.next（而不是 fast && fast.next），可以讓 slow 停在前半段的最後一個，方便用 slow.next 切開，奇偶長度都正確。

💡 關鍵技巧 2：比對以後半段為準

奇數長度時前半段會多一個（中間節點），所以 while (p2) 才正確。用 p1 當條件會多比一次而出錯。

💡 面試加分：記得還原串列

修改了輸入資料結構卻不還原，在多執行緒或串列被其他地方參考時是嚴重的副作用。面試時主動提到「我會把串列還原」通常會被加分。

⚠️ 常見錯誤：
  • 反轉時忘記先存 next，指標一改就找不到後續節點
  • 找中點的邊界條件寫錯，導致奇偶長度其中一種出錯
  • 空串列或單節點沒有提前返回 true

補充說明

遞迴解法（優雅但費空間）

🔄 利用遞迴回溯模擬「從後往前」
class Solution {
    ListNode* front;
public:
    bool check(ListNode* node) {
        if (!node) return true;
        if (!check(node->next)) return false;   // 先遞迴到底
        if (node->val != front->val) return false;  // 回溯時比對
        front = front->next;                     // front 往後移
        return true;
    }
    bool isPalindrome(ListNode* head) {
        front = head;
        return check(head);
    }
};

原理：遞迴回溯的順序是「從尾到頭」，
      而 front 指標是「從頭到尾」，剛好對撞比對。

缺點：遞迴深度等於串列長度，10 萬個節點會 stack overflow。

相關題型：#143 Reorder List

把 [1,2,3,4,5] 重排成 [1,5,2,4,3]，解法同樣是「找中點 → 反轉後半段 → 交錯合併」。這三個子程序（找中點、反轉、合併）是鏈結串列題目的三大基本功，值得反覆練熟。
