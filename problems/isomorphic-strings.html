205. Isomorphic Strings
Easy

題目描述

給定兩個字串 s 和 t，判斷它們是否同構。

如果 s 中的字元可以按某種映射關係替換得到 t，那麼這兩個字串是同構的。每個出現的字元都應當映射到另一個字元，同時不改變字元的順序，且不同字元不能映射到同一個字元，相同字元只能映射到同一個字元。

範例 1:
輸入: s = "egg", t = "add"
輸出: true
解釋: e -> a，g -> d
範例 2:
輸入: s = "foo", t = "bar"
輸出: false
解釋: o 需要同時映射到 a 和 r，矛盾
範例 3:
輸入: s = "paper", t = "title"
輸出: true

解題思路

方法一：雙向映射表（推薦）

同時維護兩張映射：s→t 與 t→s。逐位檢查每一對字元 (a, b)。

若 s→t 中已有 a 但對應值不是 b，或 t→s 中已有 b 但對應值不是 a，即代表衝突，回傳 false。

雙向都要檢查：只檢查單向時，"badc" 與 "baba" 會被誤判為同構（d、c 都映射到 b、a 之外會漏掉 b 被兩個字元指向的情況）。

方法二：比較首次出現位置

對兩個字串各記錄每個字元「上一次出現的位置」，若兩邊在每個索引上的值都相同，即為同構。

本質上是把字串正規化成同一種模式編碼再比較，一次遍歷即可完成。

程式碼實現

class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        s_to_t, t_to_s = {}, {}
        for a, b in zip(s, t):
            if a in s_to_t and s_to_t[a] != b:
                return False
            if b in t_to_s and t_to_s[b] != a:
                return False
            s_to_t[a] = b
            t_to_s[b] = a
        return True
class Solution {
    public boolean isIsomorphic(String s, String t) {
        if (s.length() != t.length()) return false;
        Map<Character, Character> sToT = new HashMap<>();
        Map<Character, Character> tToS = new HashMap<>();
        for (int i = 0; i < s.length(); i++) {
            char a = s.charAt(i), b = t.charAt(i);
            if (sToT.containsKey(a) && sToT.get(a) != b) return false;
            if (tToS.containsKey(b) && tToS.get(b) != a) return false;
            sToT.put(a, b);
            tToS.put(b, a);
        }
        return true;
    }
}
// 雙向映射：記錄每個字元「上一次出現的位置」，兩邊必須一致
// 時間複雜度: O(n)，空間複雜度: O(1)（字元集固定）
function isIsomorphic(s: string, t: string): boolean {
    const lastS = new Map<string, number>();
    const lastT = new Map<string, number>();
    for (let i = 0; i < s.length; i++) {
        if ((lastS.get(s[i]) ?? -1) !== (lastT.get(t[i]) ?? -1)) return false;
        lastS.set(s[i], i);
        lastT.set(t[i], i);
    }
    return true;
}
// 雙向映射：記錄每個字元「上一次出現的位置 + 1」，兩邊必須一致
// 時間複雜度: O(n)，空間複雜度: O(1)（固定 256 格）
bool isIsomorphic(char* s, char* t) {
    int lastS[256] = {0}, lastT[256] = {0};
    for (int i = 0; s[i]; i++) {
        unsigned char a = s[i], b = t[i];
        if (lastS[a] != lastT[b]) return false;
        lastS[a] = lastT[b] = i + 1;          // +1 讓 0 代表「沒出現過」
    }
    return true;
}
class Solution {
public:
    bool isIsomorphic(string s, string t) {
        if (s.size() != t.size()) return false;
        unordered_map<char, char> sToT, tToS;
        for (int i = 0; i < (int)s.size(); i++) {
            char a = s[i], b = t[i];
            if (sToT.count(a) && sToT[a] != b) return false;
            if (tToS.count(b) && tToS[b] != a) return false;
            sToT[a] = b;
            tToS[b] = a;
        }
        return true;
    }
};

複雜度分析

時間複雜度: O(n)

單次走訪字串，每個位置做常數次雜湊查詢與插入。

空間複雜度: O(k)

k 為字元集大小（本題最多 256），映射表的大小與字串長度無關。

重點提示

  • 必須雙向檢查：只檢查 s→t 會漏掉「兩個不同字元映射到同一字元」的違規情況
  • 先比長度：長度不同必定不同構，可提早回傳
  • 與 Word Pattern 同型：同樣的雙向映射技巧可直接套用在 LeetCode 290 Word Pattern
  • 位置編碼解法：把字串轉成「每個字元上次出現位置」的序列，兩序列相等即同構
