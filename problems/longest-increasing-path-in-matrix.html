#329 Longest Increasing Path in a Matrix

Hard
Array Dynamic Programming DFS Memoization Matrix

題目描述

給定一個 m × n 整數矩陣 matrix，找出其中最長遞增路徑的長度。

路徑規則：

  • 可以從任何單元格開始
  • 可以朝上、下、左、右四個方向移動
  • 不能斜向移動或移動到邊界外
  • 必須嚴格遞增（下一個值必須大於當前值）

範例

範例 1：
輸入：
matrix = [
  [9,9,4],
  [6,6,8],
  [2,1,1]
]

輸出：4

解釋：最長遞增路徑為 [1, 2, 6, 9]
路徑：(2,1) → (2,0) → (1,0) → (0,0)
      1    →   2    →   6    →   9
範例 2：
輸入：
matrix = [
  [3,4,5],
  [3,2,6],
  [2,2,1]
]

輸出：4

解釋：最長遞增路徑為 [3, 4, 5, 6]
不能沿著 [3, 2, 1] 走，因為不是遞增的
範例 3：
輸入：matrix = [[1]]
輸出：1

解題思路

💡 核心概念：DFS + 記憶化搜尋

策略：從每個點出發 DFS 搜索，用記憶化避免重複計算。

  1. 對每個格子進行 DFS
  2. 探索四個方向的鄰居
  3. 只能走到更大的數字
  4. 記錄每個格子的最長路徑長度
  5. 取所有格子的最大值

為什麼需要記憶化？

🔍 避免重複計算
問題：
同一個格子可能被多次訪問

例如矩陣：
[1, 2, 3]
[4, 5, 6]

從 (0,0) 出發可以走到 (0,1)
從 (1,0) 出發也可以走到 (0,1)

如果每次都重新計算 (0,1) 的最長路徑，會很浪費時間

解決：
用 memo[i][j] 記錄從 (i,j) 出發的最長路徑
計算過一次就不用再算了

DFS 遞迴關係

📊 狀態定義
定義：
dfs(i, j) = 從位置 (i,j) 出發的最長遞增路徑長度

遞迴關係：
dfs(i, j) = 1 + max(
    dfs(i-1, j),  // 上
    dfs(i+1, j),  // 下
    dfs(i, j-1),  // 左
    dfs(i, j+1)   // 右
)
其中只考慮值更大的鄰居

基礎情況：
如果四周沒有更大的值，返回 1（只有自己）

詳細範例演示

🔄 完整 DFS 過程
matrix = [
  [9, 9, 4],
  [6, 6, 8],
  [2, 1, 1]
]

從 (2,1) = 1 開始：
1 → 可以走到 2 (2,0)
    2 → 可以走到 6 (1,0)
        6 → 可以走到 9 (0,0)
            9 → 沒有更大的鄰居
            memo[0][0] = 1
        memo[1][0] = 1 + memo[0][0] = 2
    memo[2][0] = 1 + memo[1][0] = 3
memo[2][1] = 1 + memo[2][0] = 4 ✓

從 (0,2) = 4 開始：
4 → 可以走到 8 (1,2)
    8 → 可以走到 9 (0,1)
        9 → 沒有更大的鄰居
        memo[0][1] = 1
    memo[1][2] = 1 + memo[0][1] = 2
memo[0][2] = 1 + memo[1][2] = 3

最終答案：max(所有 memo 值) = 4

拓撲排序解法（進階）

另一種思路
思路：
把矩陣看作有向圖
邊：從小的數字指向大的數字
問題 = 找最長路徑

步驟：
1. 計算每個點的出度
2. 從出度為 0 的點開始（局部最大值）
3. 反向 BFS，逐層剝離
4. 層數 = 最長路徑長度

程式碼實現

# 方法一：DFS + 記憶化（推薦）
class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        if not matrix or not matrix[0]:
            return 0
        
        m, n = len(matrix), len(matrix[0])
        memo = [[0] * n for _ in range(m)]
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        def dfs(i, j):
            # 已經計算過
            if memo[i][j] != 0:
                return memo[i][j]
            
            # 至少自己算一個長度
            max_length = 1
            
            # 探索四個方向
            for di, dj in directions:
                ni, nj = i + di, j + dj
                # 檢查邊界和遞增條件
                if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
                    length = 1 + dfs(ni, nj)
                    max_length = max(max_length, length)
            
            memo[i][j] = max_length
            return max_length
        
        # 從每個點出發
        result = 0
        for i in range(m):
            for j in range(n):
                result = max(result, dfs(i, j))
        
        return result


# 方法二：拓撲排序（BFS）
class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        if not matrix or not matrix[0]:
            return 0
        
        m, n = len(matrix), len(matrix[0])
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        # 計算出度
        out_degree = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                for di, dj in directions:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
                        out_degree[i][j] += 1
        
        # 從出度為 0 的點開始（局部最大值）
        queue = deque()
        for i in range(m):
            for j in range(n):
                if out_degree[i][j] == 0:
                    queue.append((i, j))
        
        # BFS 逐層剝離
        length = 0
        while queue:
            length += 1
            size = len(queue)
            for _ in range(size):
                i, j = queue.popleft()
                for di, dj in directions:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] < matrix[i][j]:
                        out_degree[ni][nj] -= 1
                        if out_degree[ni][nj] == 0:
                            queue.append((ni, nj))
        
        return length


# 方法三：詳細註解版本
class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        """
        DFS + 記憶化搜尋
        
        時間複雜度：O(m*n)，每個格子只訪問一次
        空間複雜度：O(m*n)，記憶化數組和遞迴棧
        """
        if not matrix or not matrix[0]:
            return 0
        
        m, n = len(matrix), len(matrix[0])
        # memo[i][j] 表示從 (i,j) 出發的最長路徑
        memo = [[0] * n for _ in range(m)]
        # 四個方向：上下左右
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        def dfs(i, j):
            """從 (i,j) 出發的最長遞增路徑長度"""
            # 記憶化：已經計算過了
            if memo[i][j] != 0:
                return memo[i][j]
            
            # 初始長度為 1（只有自己）
            max_length = 1
            
            # 嘗試四個方向
            for di, dj in directions:
                ni, nj = i + di, j + dj
                
                # 檢查邊界
                if not (0 <= ni < m and 0 <= nj < n):
                    continue
                
                # 檢查遞增條件
                if matrix[ni][nj] <= matrix[i][j]:
                    continue
                
                # 遞迴搜尋鄰居
                length = 1 + dfs(ni, nj)
                max_length = max(max_length, length)
            
            # 記憶化
            memo[i][j] = max_length
            return max_length
        
        # 從每個格子出發，找最大值
        result = 0
        for i in range(m):
            for j in range(n):
                result = max(result, dfs(i, j))
        
        return result

from functools import lru_cache

class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        if not matrix or not matrix[0]:
            return 0
        
        m, n = len(matrix), len(matrix[0])
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        @lru_cache(None)
        def dfs(i, j):
            max_length = 1
            for di, dj in directions:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
                    max_length = max(max_length, 1 + dfs(ni, nj))
            return max_length
        
        return max(dfs(i, j) for i in range(m) for j in range(n))

class Solution {
    private int[][] directions = {{-1,0}, {1,0}, {0,-1}, {0,1}};
    private int[][] memo;
    
    public int longestIncreasingPath(int[][] matrix) {
        if (matrix.length == 0 || matrix[0].length == 0) return 0;
        
        int m = matrix.length, n = matrix[0].length;
        memo = new int[m][n];
        int result = 0;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result = Math.max(result, dfs(matrix, i, j));
            }
        }
        
        return result;
    }
    
    private int dfs(int[][] matrix, int i, int j) {
        if (memo[i][j] != 0) return memo[i][j];

        int maxLength = 1;
        
        for (int[] dir : directions) {
            int ni = i + dir[0];
            int nj = j + dir[1];
            
            if (ni >= 0 && ni < m && nj >= 0 && nj < n &&

                maxLength = Math.max(maxLength, 1 + dfs(matrix, ni, nj));

// DFS + 記憶化：memo[i][j] = 從 (i, j) 出發的最長遞增路徑
// 時間複雜度: O(m·n)，空間複雜度: O(m·n)
function longestIncreasingPath(matrix: number[][]): number {
    const m = matrix.length, n = matrix[0].length;
    const memo: number[][] = Array.from({ length: m }, () => new Array(n).fill(0));
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    const dfs = (i: number, j: number): number => {
        if (memo[i][j]) return memo[i][j];
        let best = 1;
        for (const [di, dj] of dirs) {
            const x = i + di, y = j + dj;
            if (x >= 0 && x < m && y >= 0 && y < n && matrix[x][y] > matrix[i][j]) {
                best = Math.max(best, 1 + dfs(x, y));
            }
        }
        return (memo[i][j] = best);
    };

    let ans = 0;
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) ans = Math.max(ans, dfs(i, j));
    }
    return ans;
}
// DFS + 記憶化：memo[i][j] = 從 (i, j) 出發的最長遞增路徑
// 時間複雜度: O(m·n)，空間複雜度: O(m·n)
static int m, n;
static int* memo;
static const int DIRS[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

static int dfs(int** matrix, int i, int j) {
    if (memo[i * n + j]) return memo[i * n + j];
    int best = 1;
    for (int d = 0; d < 4; d++) {
        int x = i + DIRS[d][0], y = j + DIRS[d][1];
        if (x >= 0 && x < m && y >= 0 && y < n && matrix[x][y] > matrix[i][j]) {
            int len = 1 + dfs(matrix, x, y);
            if (len > best) best = len;
        }
    }
    return memo[i * n + j] = best;
}

int longestIncreasingPath(int** matrix, int matrixSize, int* matrixColSize) {
    m = matrixSize;
    n = matrixColSize[0];
    memo = calloc(m * n, sizeof(int));
    int ans = 0;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            int len = dfs(matrix, i, j);
            if (len > ans) ans = len;
        }
    }
    free(memo);
    return ans;
}

複雜度分析

DFS + 記憶化：
  • 時間複雜度：O(m × n)，每個格子只訪問一次
  • 空間複雜度：O(m × n)，記憶化數組 + 遞迴棧
拓撲排序：
  • 時間複雜度：O(m × n)，BFS 遍歷所有格子
  • 空間複雜度：O(m × n)，出度數組 + 隊列

重點提示

💡 關鍵技巧 1：記憶化必須

不加記憶化會超時（Time Limit Exceeded）。

💡 關鍵技巧 2：遞增條件

只能走到嚴格大於當前值的格子，這保證了無環。

💡 關鍵技巧 3：從每個點出發

不知道起點在哪，所以要嘗試所有格子。

⚠️ 常見錯誤：
  • 忘記記憶化，導致 TLE
  • 遞增條件寫錯（應該是嚴格大於 >，不是 ≥）
  • 邊界檢查遺漏
  • 返回值忘記加 1（自己也算一個長度）
為什麼保證無環？
關鍵：嚴格遞增 = 不會回頭

因為只能走到更大的數字
所以路徑是單向的，不可能形成環

例如：1 → 2 → 3
不可能 3 → 1，因為 1 < 3

這保證了 DFS 不會無限遞迴
也不需要 visited 數組！
