#142 Linked List Cycle II

Medium
Linked List Two Pointers Hash Table

題目描述

給定一個鏈結串列的頭節點 head，返回鏈結串列開始入環的第一個節點。如果串列無環，則返回 null。

進階：你是否可以使用 O(1) 空間解決此題？（這是本題的重點，也是面試的必考推導）

範例

範例 1：
輸入：head = [3,2,0,-4], pos = 1
輸出：返回索引為 1 的節點（值為 2）
解釋：鏈結串列中有一個環，尾部連接到第二個節點。
範例 2：
輸入：head = [1,2], pos = 0
輸出：返回索引為 0 的節點
範例 3：
輸入：head = [1], pos = -1
輸出：null（無環）

解題思路

Floyd 判圈演算法（龜兔賽跑）
第一階段：slow 走 1 步、fast 走 2 步，若相遇則有環
第二階段：把其中一個指標移回 head，兩者都改成每次走 1 步，
          再次相遇的位置就是「環的入口」

聽起來很神奇，但可以嚴格證明。

數學證明（面試必問）

為什麼移回 head 就會在入口相遇？
定義：
  a = head 到「環入口」的距離
  b = 環入口 到「相遇點」的距離
  c = 相遇點 繞回「環入口」的距離
  環長 = b + c

    head --- a ---> 入口 --- b ---> 相遇點
                     ↑                |
                     +------- c -------+

相遇時：
  slow 走的距離 = a + b
  fast 走的距離 = a + b + k(b + c)   （在環裡多繞了 k 圈，k >= 1）

因為 fast 速度是 slow 的兩倍：
  2(a + b) = a + b + k(b + c)
  a + b = k(b + c)
  a = k(b + c) - b
  a = (k-1)(b + c) + c

【結論】a = c + (k-1) × 環長

意義：從 head 走 a 步，和從相遇點走 c 步（再繞 k-1 圈），
      會停在同一個位置 —— 也就是環的入口！

所以第二階段兩個指標同速前進，必定在入口相遇 ✓

為什麼 fast 一定追得上 slow？

進入環後，fast 每一步都比 slow 多前進 1 個節點，兩者距離每輪縮小 1，因此絕不會跳過，必定在有限步內相遇。這也是為什麼速度差要設為 1（fast 走 2、slow 走 1）。

程式碼實現

# 方法一：Floyd 判圈（O(1) 空間，推薦）
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head

        # 第一階段：找相遇點
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                # 第二階段：一個指標回到 head，同速前進
                ptr = head
                while ptr != slow:
                    ptr = ptr.next
                    slow = slow.next
                return ptr          # 相遇處即為環的入口
        return None                 # fast 走到底，無環


# 方法二：HashSet（O(n) 空間，最直覺）
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        visited = set()
        node = head
        while node:
            if node in visited:
                return node         # 第一個重複出現的節點就是入口
            visited.add(node)
            node = node.next
        return None
// 方法一：Floyd 判圈（O(1) 空間，推薦）
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode *slow = head, *fast = head;

        // 第一階段：找相遇點
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {
                // 第二階段：ptr 從 head 出發，同速前進
                ListNode *ptr = head;
                while (ptr != slow) {
                    ptr = ptr->next;
                    slow = slow->next;
                }
                return ptr;         // 環的入口
            }
        }
        return nullptr;             // 無環
    }
};

// 方法二：HashSet
public class Solution {
    public ListNode detectCycle(ListNode head) {
        Set<ListNode> visited = new HashSet<>();
        while (head != null) {
            if (!visited.add(head)) return head;
            head = head.next;
        }
        return null;
    }
}
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 * }
 */
// Floyd 判圈：相遇後，一個指標回到起點，兩者同速前進的交會點就是入環點
// 時間複雜度: O(n)，空間複雜度: O(1)
function detectCycle(head: ListNode | null): ListNode | null {
    let slow = head, fast = head;
    while (fast && fast.next) {
        slow = slow!.next;
        fast = fast.next.next;
        if (slow === fast) {
            let p = head;
            while (p !== slow) {
                p = p!.next;
                slow = slow!.next;
            }
            return p;
        }
    }
    return null;
}
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
// Floyd 判圈：相遇後，一個指標回到起點，兩者同速前進的交會點就是入環點
// 時間複雜度: O(n)，空間複雜度: O(1)
struct ListNode* detectCycle(struct ListNode* head) {
    struct ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            struct ListNode* p = head;
            while (p != slow) {
                p = p->next;
                slow = slow->next;
            }
            return p;
        }
    }
    return NULL;
}

複雜度分析

時間複雜度：O(n)
  • 第一階段最多走 n + 環長 步
  • 第二階段最多走 a 步（a < n）
空間複雜度：
  • Floyd：O(1) ★ 這是本題要考的重點
  • HashSet：O(n)

重點提示

關鍵技巧：記住結論 a = c（模環長）

「head 到入口的距離」等於「相遇點到入口的距離」（可能多繞幾圈）。這個結論是本題唯一需要記的東西，但面試官幾乎一定會要你推導，務必練習寫出證明過程。

延伸：如何求環的長度？

從相遇點出發，讓一個指標繞一圈回到相遇點，計數即為環長。配合入口位置，就能完整描述整個環的結構。

常見錯誤：
  • 迴圈條件必須是 fast && fast->next，少一個判斷就會對無環串列 null pointer 崩潰
  • 第二階段誤用 fast 而不是相遇點（其實用 slow 或 fast 都可以，因為它們此刻在同一位置）
  • 第二階段忘記把速度改成 1:1，仍用 1:2 會錯
  • Python 比較節點要用 is / == 比較物件參考，不要比 val（值可能重複）

補充說明

Floyd 判圈的通用性

只要是「函數迭代」就能用
任何形如 x → f(x) 的迭代序列，只要狀態空間有限，
最終必定進入循環（ρ 形結構），都可以用 Floyd 找出：
  - 循環的起點
  - 循環的長度

應用實例：
  #141/#142  鏈結串列        f(node) = node.next
  #287       找重複數字      f(i) = nums[i]
  #202       快樂數          f(n) = 各位數平方和
  隨機數產生器週期檢測       f(x) = LCG 遞推式
  Pollard's rho 大數分解     f(x) = (x² + c) mod n

#287 的巧妙轉化

nums 有 n+1 個元素，值域是 [1, n]，必有重複。
把 i → nums[i] 看成一條鏈結串列的邊，
因為有兩個索引指向同一個值，必定形成環，
環的入口就是重複的數字！

int findDuplicate(vector<int>& nums) {
    int slow = nums[0], fast = nums[nums[0]];
    while (slow != fast) { slow = nums[slow]; fast = nums[nums[fast]]; }
    slow = 0;
    while (slow != fast) { slow = nums[slow]; fast = nums[fast]; }
    return slow;
}
