#199 Binary Tree Right Side View

Medium
Tree BFS DFS Binary Tree

題目描述

給定一個二元樹的根節點 root，想像自己站在它的右側，按照從頂部到底部的順序，返回從右側所能看到的節點值。

換句話說：每一層最右邊的那個節點。

範例

範例 1：
輸入：root = [1,2,3,null,5,null,4]

      1        ← 看得到 1
     / \
    2   3      ← 看得到 3
     \   \
      5   4    ← 看得到 4

輸出：[1,3,4]
範例 2：
輸入：root = [1,2,3,4,null,null,null,5]

      1
     / \
    2   3
   /
  4
 /
5

輸出：[1,3,4,5]
注意第 3 層看到的是 4（右子樹在該層沒有節點），
   這說明「右側視圖」不等於「一直往右走」！
範例 3：
輸入：root = []
輸出：[]

解題思路

第一個陷阱：不能只是「一直往右走」

如範例 2，若某一層的右子樹是空的，那一層看到的就是左子樹的節點。所以必須逐層處理，而不是沿著 right 指標往下。

方法一：BFS 層序遍歷（最直覺）

每層取最後一個節點
標準的層序遍歷，每一層記錄【最後一個】出隊的節點。

while (!queue.empty()) {
    int size = queue.size();          // 這一層的節點數
    for (int i = 0; i < size; i++) {
        node = queue.pop();
        if (i == size - 1) result.push_back(node->val);  // 該層最後一個
        if (node->left)  queue.push(node->left);
        if (node->right) queue.push(node->right);
    }
}

【追蹤範例 2】
第 1 層：[1]        → 最後一個 = 1
第 2 層：[2, 3]     → 最後一個 = 3
第 3 層：[4]        → 最後一個 = 4（3 沒有子節點）
第 4 層：[5]        → 最後一個 = 5

結果 [1, 3, 4, 5] ✓

方法二：DFS「先右後左」（更巧妙）

每層第一個到達的節點就是答案
用 DFS 且【先遞迴右子樹】，
那麼每一層【第一個】被訪問到的節點，
必定是該層最右邊的節點！

void dfs(node, depth) {
    if (!node) return;

    // 第一次到達這個深度 → 記錄
    if (depth == result.size()) result.push_back(node->val);

    dfs(node->right, depth + 1);   // ★ 先右！
    dfs(node->left,  depth + 1);
}

【追蹤範例 2】
dfs(1, 0)：result.size()=0 == depth=0 → 記錄 1，result=[1]
  dfs(3, 1)：size=1 == 1 → 記錄 3，result=[1,3]
    （3 沒有子節點）
  dfs(2, 1)：size=2 != 1 → 不記錄（該層已有 3）
    dfs(null, 2) 跳過
    dfs(4, 2)：size=2 == 2 → 記錄 4，result=[1,3,4]
      dfs(null, 3) 跳過
      dfs(5, 3)：size=3 == 3 → 記錄 5，result=[1,3,4,5] ✓

★ 條件 `depth == result.size()` 非常精妙：
   它表示「這是第一次到達這個深度」。

兩種方法比較

           BFS                    DFS
------------------------------------------------------
時間       O(n)                   O(n)
空間       O(w) 最寬一層的寬度     O(h) 樹高
直覺性     ★★★ 很直觀            ★★ 需要理解「先右」的巧思
變形擴充   容易（左側視圖只要取第一個）  容易（改成先左）
極端情況   完全二元樹時 w = n/2    退化成鏈時 h = n

兩種都要會，面試時可以先寫 BFS 再提 DFS 版本。

程式碼實現

# 方法一：BFS 層序遍歷（推薦，最直覺）
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        from collections import deque

        result = []
        queue = deque([root])

        while queue:
            size = len(queue)              # 這一層的節點數
            for i in range(size):
                node = queue.popleft()
                if i == size - 1:          # 該層最後一個 = 最右邊
                    result.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

        return result


# 方法二：DFS 先右後左
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        result = []

        def dfs(node, depth):
            if not node:
                return
            # 第一次到達這個深度 → 必定是該層最右邊
            if depth == len(result):
                result.append(node.val)

            dfs(node.right, depth + 1)     # ★ 先遞迴右子樹
            dfs(node.left, depth + 1)

        dfs(root, 0)
        return result
// 方法一：BFS 層序遍歷（推薦）
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> result;
        if (!root) return result;

        queue<TreeNode*> q;
        q.push(root);

        while (!q.empty()) {
            int size = q.size();               // 這一層的節點數
            for (int i = 0; i < size; i++) {
                TreeNode* node = q.front(); q.pop();
                if (i == size - 1) result.push_back(node->val);  // 最右邊
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        return result;
    }
};

public:

// 方法一：BFS 層序遍歷（推薦）
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();               // 這一層的節點數
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (i == size - 1) result.add(node.val);   // 該層最右
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return result;
    }
}

// 方法二：DFS 先右後左
class Solution {
    private List<Integer> result = new ArrayList<>();

    public List<Integer> rightSideView(TreeNode root) {
        dfs(root, 0);
        return result;
    }

    private void dfs(TreeNode node, int depth) {
        if (node == null) return;

        if (depth == result.size()) result.add(node.val);  // 第一次到這層

        dfs(node.right, depth + 1);    // ★ 先右
        dfs(node.left,  depth + 1);
    }
}
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 * }
 */
// BFS：每層最後一個節點就是右視圖看到的節點
// 時間複雜度: O(n)，空間複雜度: O(n)
function rightSideView(root: TreeNode | null): number[] {
    const result: number[] = [];
    if (!root) return result;
    let queue: TreeNode[] = [root];

    while (queue.length) {
        result.push(queue[queue.length - 1].val);
        const next: TreeNode[] = [];
        for (const node of queue) {
            if (node.left) next.push(node.left);
            if (node.right) next.push(node.right);
        }
        queue = next;
    }
    return result;
}
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */
// DFS（根 → 右 → 左）：每層第一次到達的節點就是右視圖
// 時間複雜度: O(n)，空間複雜度: O(h)
static void dfs(struct TreeNode* node, int depth, int* result, int* size) {
    if (!node) return;
    if (depth == *size) result[(*size)++] = node->val;   // 這層第一次到達
    dfs(node->right, depth + 1, result, size);
    dfs(node->left, depth + 1, result, size);
}

int* rightSideView(struct TreeNode* root, int* returnSize) {
    int* result = malloc(sizeof(int) * 100);             // 節點數 ≤ 100
    *returnSize = 0;
    dfs(root, 0, result, returnSize);
    return result;
}

複雜度分析

時間複雜度：O(n)
  • 每個節點恰好被訪問一次
空間複雜度：
  • BFS：O(w)，w 為樹的最大寬度；完全二元樹時最壞 O(n/2) = O(n)
  • DFS：O(h)，h 為樹高；退化成鏈時最壞 O(n)
  • 不計輸出所需的 O(h) 空間

重點提示

關鍵技巧 1：「右側視圖」≠「一直往右走」

當右子樹在某一層沒有節點時，該層看到的是左子樹的節點。必須逐層判斷，這是本題最重要的觀念，也是面試官設下的第一個陷阱。

關鍵技巧 2：depth == result.size() 的妙用

這個條件優雅地表達了「第一次到達這個深度」，不需要額外的 visited 或 maxDepth 變數。同樣的技巧可以用在「每層第一個/最後一個節點」的各種變形題。

BFS 分層的標準寫法

int size = queue.size() 先固定住這一層的數量，再用 for 迴圈處理。這是所有「層序遍歷」題目的核心模板（#102、#103、#107、#515、#637 全都用它）。

常見錯誤：
  • 直接沿著 node.right 往下走（範例 2 會錯）
  • DFS 版本寫成「先左後右」（會變成左側視圖）
  • BFS 內層迴圈直接用 queue.size() 當條件（會把下一層也算進來）
  • 沒處理空樹

延伸：左側視圖怎麼寫？

BFS 版：把 `i == size - 1` 改成 `i == 0`
DFS 版：把遞迴順序改成「先左後右」

// 左側視圖 DFS
void dfs(TreeNode* node, int depth) {
    if (!node) return;
    if (depth == result.size()) result.push_back(node->val);
    dfs(node->left,  depth + 1);    // ★ 先左
    dfs(node->right, depth + 1);
}

【俯視圖 / 底視圖】（#314 垂直遍歷的變形）
則要按「水平距離」分組：
  根節點的 col = 0，左子 col-1，右子 col+1
  同一個 col 中取最上面（或最下面）的節點

面試延伸問題

  • 「如果樹非常深（10 萬層）？」→ DFS 遞迴會 stack overflow，改用 BFS 或顯式堆疊
  • 「如果樹非常寬？」→ BFS 佇列會很大，改用 DFS 較省空間
  • 「如果要輸出每一層的所有節點？」→ #102，把整層收集起來即可
  • 「如果是 N 元樹？」→ 把 left/right 換成 for (child : children)，邏輯完全相同
