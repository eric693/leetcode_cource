#135 Candy

Hard
Array Greedy

題目描述

有 n 個孩子站成一排。給你一個整數陣列 ratings 表示每個孩子的評分。

分糖果的規則：

  • 每個孩子至少分配到 1 個糖果
  • 評分更高的孩子必須比他兩側評分低的鄰居獲得更多的糖果

請計算並返回需要準備的最少糖果數目。

範例

範例 1：
輸入：ratings = [1,0,2]

輸出：5

解釋：
孩子們的糖果分配：[2, 1, 2]
- 索引 0（評分 1）：2 顆糖（因為比右邊的 0 高）
- 索引 1（評分 0）：1 顆糖（最低評分）
- 索引 2（評分 2）：2 顆糖（因為比左邊的 0 高）
總計：2 + 1 + 2 = 5
範例 2：
輸入：ratings = [1,2,2]

輸出：4

解釋：
孩子們的糖果分配：[1, 2, 1]
- 索引 0（評分 1）：1 顆糖
- 索引 1（評分 2）：2 顆糖（比左邊高）
- 索引 2（評分 2）：1 顆糖（和左邊相等，不需要更多）
總計：1 + 2 + 1 = 4

解題思路

💡 核心概念：兩次掃描（貪心策略）

關鍵洞察：左右規則可以分開處理！

  1. 第一次從左到右：處理「比左邊高」的情況
  2. 第二次從右到左：處理「比右邊高」的情況
  3. 每個位置取兩次掃描的最大值

為什麼需要兩次掃描？

🔍 問題分析
規則拆解：
原規則：評分高的孩子比「兩側」評分低的鄰居獲得更多糖果

可以拆成兩個獨立規則：
1. 如果 ratings[i] > ratings[i-1]，則 candy[i] > candy[i-1]
2. 如果 ratings[i] > ratings[i+1]，則 candy[i] > candy[i+1]

為什麼一次掃描不行？
從左到右掃描時，無法知道右邊的情況
從右到左掃描時，無法知道左邊的情況

解決方案：
兩次掃描，分別處理左右關係
最後取兩者的最大值（同時滿足兩個規則）

詳細範例演示

🔄 完整掃描過程：ratings = [1,2,87,87,87,2,1]
ratings = [1, 2, 87, 87, 87, 2, 1]
索引:      0  1   2   3   4  5  6

初始化：
left  = [1, 1, 1, 1, 1, 1, 1]  每人先給 1 顆

第一次掃描（從左到右）：
處理規則：如果比左邊高，糖果 = 左邊 + 1

i=1: ratings[1]=2 > ratings[0]=1  → left[1] = left[0] + 1 = 2
i=2: ratings[2]=87 > ratings[1]=2 → left[2] = left[1] + 1 = 3
i=3: ratings[3]=87 = ratings[2]=87 → left[3] = 1（相等不增加）
i=4: ratings[4]=87 = ratings[3]=87 → left[4] = 1
i=5: ratings[5]=2 < ratings[4]=87  → left[5] = 1（更低重置為 1）
i=6: ratings[6]=1 < ratings[5]=2   → left[6] = 1

結果: left = [1, 2, 3, 1, 1, 1, 1]

第二次掃描（從右到左）：
處理規則：如果比右邊高，糖果 = 右邊 + 1

right = [1, 1, 1, 1, 1, 1, 1]  重新初始化

i=5: ratings[5]=2 > ratings[6]=1  → right[5] = right[6] + 1 = 2
i=4: ratings[4]=87 > ratings[5]=2 → right[4] = right[5] + 1 = 3
i=3: ratings[3]=87 = ratings[4]=87 → right[3] = 1
i=2: ratings[2]=87 = ratings[3]=87 → right[2] = 1
i=1: ratings[1]=2 < ratings[2]=87  → right[1] = 1
i=0: ratings[0]=1 < ratings[1]=2   → right[0] = 1

結果: right = [1, 1, 1, 1, 3, 2, 1]

取最大值（同時滿足左右規則）：
candy[i] = max(left[i], right[i])

candy = [max(1,1), max(2,1), max(3,1), max(1,1), max(1,3), max(1,2), max(1,1)]
      = [1, 2, 3, 1, 3, 2, 1]

總糖果數：1 + 2 + 3 + 1 + 3 + 2 + 1 = 13

優化：單陣列版本

🚀 空間優化
觀察：
不需要存儲兩個陣列 left 和 right
可以在第一個陣列上直接更新

步驟：
1. 從左到右掃描，更新 candy 陣列
2. 從右到左掃描，取 max(當前值, 右邊+1)

優勢：
空間複雜度從 O(2n) 降到 O(n)

程式碼實現

# 方法一：兩次掃描（最優解）
class Solution:
    def candy(self, ratings: List[int]) -> int:
        n = len(ratings)
        if n <= 1:
            return n
        
        # 初始化，每個孩子先給 1 顆糖
        candies = [1] * n
        
        # 第一次掃描：從左到右
        # 如果比左邊評分高，糖果 = 左邊 + 1
        for i in range(1, n):
            if ratings[i] > ratings[i - 1]:
                candies[i] = candies[i - 1] + 1
        
        # 第二次掃描：從右到左
        # 如果比右邊評分高，糖果 = max(當前, 右邊 + 1)
        for i in range(n - 2, -1, -1):
            if ratings[i] > ratings[i + 1]:
                candies[i] = max(candies[i], candies[i + 1] + 1)
        
        return sum(candies)


# 方法二：兩個陣列版本（更清晰）
class Solution:
    def candy(self, ratings: List[int]) -> int:
        n = len(ratings)
        if n <= 1:
            return n
        
        left = [1] * n
        right = [1] * n
        
        # 從左到右
        for i in range(1, n):
            if ratings[i] > ratings[i - 1]:
                left[i] = left[i - 1] + 1
        
        # 從右到左
        for i in range(n - 2, -1, -1):
            if ratings[i] > ratings[i + 1]:
                right[i] = right[i + 1] + 1
        
        # 取最大值
        return sum(max(l, r) for l, r in zip(left, right))


# 方法三：詳細註解版本
class Solution:
    def candy(self, ratings: List[int]) -> int:
        """
        貪心策略：兩次掃描
        
        核心思想：
        左右規則可以分開處理，最後取最大值
        """
        n = len(ratings)
        
        # 邊界情況
        if n <= 1:
            return n
        
        # 每個孩子至少 1 顆糖
        candies = [1] * n
        
        # 第一次掃描：處理「比左邊高」的情況
        # 從左到右遍歷
        for i in range(1, n):
            # 如果當前孩子評分比左邊高
            if ratings[i] > ratings[i - 1]:
                # 糖果數 = 左邊孩子 + 1
                candies[i] = candies[i - 1] + 1
            # 如果評分不比左邊高，保持 1 顆（已初始化）
        
        # 第二次掃描：處理「比右邊高」的情況
        # 從右到左遍歷
        for i in range(n - 2, -1, -1):
            # 如果當前孩子評分比右邊高
            if ratings[i] > ratings[i + 1]:
                # 需要滿足：
                # 1. 比右邊孩子多（右邊 + 1）
                # 2. 同時保持之前從左掃描得到的值
                # 所以取兩者最大值
                candies[i] = max(candies[i], candies[i + 1] + 1)
        
        # 返回總糖果數
        return sum(candies)


# 方法四：一次掃描（進階，較複雜）
class Solution:
    def candy(self, ratings: List[int]) -> int:
        """
        優化版本：只掃描一次
        時間 O(n)，空間 O(1)
        """
        n = len(ratings)
        if n <= 1:
            return n
        
        total = 1
        up = 0      # 上升序列長度
        down = 0    # 下降序列長度
        peak = 0    # 峰值糖果數
        
        for i in range(1, n):
            if ratings[i] > ratings[i - 1]:
                # 上升
                up += 1
                down = 0
                peak = up + 1
                total += peak
            elif ratings[i] == ratings[i - 1]:
                # 相等，重置
                up = down = peak = 0
                total += 1
            else:
                # 下降
                up = 0
                down += 1
                # 如果下降序列長度超過峰值，需要調整峰值
                total += down + (1 if down >= peak else 0)
        
        return total

// 方法一：兩次掃描（最優解）
class Solution {
public:
    int candy(vector& ratings) {
        int n = ratings.size();
        if (n <= 1) return n;
        
        vector candies(n, 1);
        
        // 從左到右
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }
        
        // 從右到左
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = max(candies[i], candies[i + 1] + 1);
            }
        }
        
        return accumulate(candies.begin(), candies.end(), 0);
    }
};

// 方法一：兩次掃描（最優解）
class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        if (n <= 1) return n;
        
        int[] candies = new int[n];
        Arrays.fill(candies, 1);
        
        // 從左到右
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }
        
        // 從右到左
        int total = candies[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = Math.max(candies[i], candies[i + 1] + 1);
            }
            total += candies[i];
        }
        
        return total;
    }
}

// 兩次掃描：左到右滿足左鄰規則，右到左滿足右鄰規則
// 時間複雜度: O(n)，空間複雜度: O(n)
function candy(ratings: number[]): number {
    const n = ratings.length;
    const candies = new Array(n).fill(1);

    for (let i = 1; i < n; i++) {
        if (ratings[i] > ratings[i - 1]) candies[i] = candies[i - 1] + 1;
    }
    for (let i = n - 2; i >= 0; i--) {
        if (ratings[i] > ratings[i + 1]) candies[i] = Math.max(candies[i], candies[i + 1] + 1);
    }
    return candies.reduce((a, b) => a + b, 0);
}
// 兩次掃描：左到右滿足左鄰規則，右到左滿足右鄰規則
// 時間複雜度: O(n)，空間複雜度: O(n)
int candy(int* ratings, int ratingsSize) {
    int n = ratingsSize;
    int* candies = malloc(sizeof(int) * n);
    for (int i = 0; i < n; i++) candies[i] = 1;

    for (int i = 1; i < n; i++) {
        if (ratings[i] > ratings[i - 1]) candies[i] = candies[i - 1] + 1;
    }
    for (int i = n - 2; i >= 0; i--) {
        if (ratings[i] > ratings[i + 1] && candies[i] <= candies[i + 1]) {
            candies[i] = candies[i + 1] + 1;
        }
    }
    int total = 0;
    for (int i = 0; i < n; i++) total += candies[i];
    free(candies);
    return total;
}

複雜度分析

兩次掃描解法：
  • 時間複雜度：O(n) - 兩次遍歷
  • 空間複雜度：O(n) - 糖果陣列
一次掃描解法：
  • 時間複雜度：O(n)
  • 空間複雜度：O(1) - 只用常數變數

重點提示

💡 關鍵技巧 1：規則拆分

把「兩側」規則拆成「左邊」和「右邊」兩個獨立規則。

💡 關鍵技巧 2：取最大值

同時滿足左右規則 = 取兩次掃描結果的最大值。

💡 關鍵技巧 3：相等情況

評分相等時不需要更多糖果，保持當前值即可。

⚠️ 常見錯誤：
  • 只掃描一次（無法同時處理左右關係）
  • 相等時也增加糖果（題目要求是「更高」才需要更多）
  • 第二次掃描忘記取 max（需要同時滿足兩個規則）
  • 初始化不是 1（題目要求每人至少 1 顆）
🎯 為什麼兩次掃描是對的？
證明：
規則：評分高的孩子比「兩側」評分低的鄰居多

等價於：
1. 如果比左邊高，要比左邊多
2. 如果比右邊高，要比右邊多

兩次掃描保證：
- 第一次掃描：滿足規則 1
- 第二次掃描：在保持規則 1 的前提下，滿足規則 2
- 取 max 確保兩個規則同時滿足

因此是正確的最優解！
