#148 Sort List

Medium
Linked List Sorting Merge Sort Divide and Conquer

題目描述

給你鏈結串列的頭節點 head，請將其按升序排列並返回排序後的鏈結串列。

進階：你可以在 O(n log n) 時間複雜度和常數級 O(1) 空間複雜度下，對串列進行排序嗎？

範例

範例 1：
輸入：head = [4,2,1,3]
輸出：[1,2,3,4]
範例 2：
輸入：head = [-1,5,3,4,0]
輸出：[-1,0,3,4,5]
範例 3：
輸入：head = []
輸出：[]

解題思路

💡 為什麼一定是合併排序（Merge Sort）？
排序法        陣列       鏈結串列      原因
------------------------------------------------------------
快速排序      O(n log n) 不適合        需要隨機存取做 partition
堆積排序      O(n log n) 不適合        需要索引存取 2i、2i+1
合併排序      O(n log n) ★ 最適合      只需要循序存取
                                        且合併時不需要額外陣列！

陣列的合併排序需要 O(n) 額外空間存放暫存陣列，
但鏈結串列的合併只要改指標，不需要複製資料 → O(1) 空間！

這是鏈結串列少數比陣列「更有優勢」的場合。

方法一：自頂向下（遞迴，好寫但空間 O(log n)）

🎯 分治三步驟
1. 找中點，從中間斷開成兩條串列
2. 遞迴排序左右兩半
3. 合併兩條有序串列（就是 #21）

[4, 2, 1, 3]
      ↓ 切開
[4, 2]      [1, 3]
  ↓            ↓
[4] [2]     [1] [3]
  ↓ merge      ↓ merge
[2, 4]      [1, 3]
      ↓ merge
[1, 2, 3, 4] ✓

⚠️ 切斷是關鍵：找到中點後必須 mid.next = None，
   否則左半段會一直延伸到結尾，造成無限遞迴。

方法二：自底向上（迭代，真正的 O(1) 空間）

⚡ 從小區塊開始兩兩合併
不用遞迴，改用「步長」由小到大合併：

step = 1：每 1 個一組，兩兩合併 → 得到長度 2 的有序段
step = 2：每 2 個一組，兩兩合併 → 得到長度 4 的有序段
step = 4：...
直到 step >= n

[4, 2, 1, 3]
step=1: (4,2) → (2,4) ; (1,3) → (1,3)
        結果：[2, 4, 1, 3]
step=2: (2,4) 與 (1,3) 合併 → [1, 2, 3, 4] ✓

優點：沒有遞迴堆疊，空間真正是 O(1)
缺點：程式碼較長，需要小心處理切分與串接

程式碼實現

# 方法一：自頂向下遞迴（推薦，好寫好懂）
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        # 1. 找中點並切斷（slow 停在前半段最後一個）
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        mid = slow.next
        slow.next = None            # 關鍵：一定要切斷！

        # 2. 遞迴排序兩半
        left = self.sortList(head)
        right = self.sortList(mid)

        # 3. 合併
        return self.merge(left, right)

    def merge(self, l1, l2):
        dummy = ListNode(0)
        cur = dummy
        while l1 and l2:
            if l1.val <= l2.val:    # <= 保證穩定性
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next
            cur = cur.next
        cur.next = l1 if l1 else l2
        return dummy.next


# 方法二：自底向上迭代（真正的 O(1) 空間）
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 先算長度
        n, node = 0, head
        while node:
            n += 1
            node = node.next

        dummy = ListNode(0, head)
        step = 1
        while step < n:
            prev, cur = dummy, dummy.next
            while cur:
                left = cur
                right = self.split(left, step)      # 切出長度 step 的左段
                cur = self.split(right, step)       # 切出右段，cur 指向剩餘
                prev = self.mergeInto(prev, left, right)
            step *= 2
        return dummy.next

    def split(self, head, n):
        # 從 head 往後走 n-1 步後切斷，回傳後半段的頭
        while head and n > 1:
            head = head.next
            n -= 1
        if not head:
            return None
        rest = head.next
        head.next = None
        return rest

    def mergeInto(self, prev, l1, l2):
        # 合併 l1、l2 接在 prev 後面，回傳合併後的尾節點
        cur = prev
        while l1 and l2:
            if l1.val <= l2.val:
                cur.next, l1 = l1, l1.next
            else:
                cur.next, l2 = l2, l2.next
            cur = cur.next
        cur.next = l1 if l1 else l2
        while cur.next:
            cur = cur.next
        return cur

class Solution {
    ListNode* merge(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);
        ListNode* cur = &dummy;
        while (l1 && l2) {
            if (l1->val <= l2->val) { cur->next = l1; l1 = l1->next; }
            else                    { cur->next = l2; l2 = l2->next; }
            cur = cur->next;
        }
        cur->next = l1 ? l1 : l2;
        return dummy.next;
    }

public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;

        // 找中點並切斷
        ListNode *slow = head, *fast = head->next;

            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* mid = slow->next;
        slow->next = nullptr;          // 關鍵：切斷

        return merge(sortList(head), sortList(mid));

// 方法一：自頂向下遞迴（推薦）
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) return head;

        // 找中點並切斷
        ListNode slow = head, fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode mid = slow.next;
        slow.next = null;              // 關鍵：切斷

        ListNode left = sortList(head);
        ListNode right = sortList(mid);
        return merge(left, right);
    }

    private ListNode merge(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0), cur = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
            else                  { cur.next = l2; l2 = l2.next; }
            cur = cur.next;
        }
        cur.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 * }
 */
// 合併排序：快慢指針切半 → 遞迴排序 → 合併
// 時間複雜度: O(n log n)，空間複雜度: O(log n)
function sortList(head: ListNode | null): ListNode | null {
    if (!head || !head.next) return head;

    let slow: ListNode = head, fast: ListNode | null = head.next;
    while (fast && fast.next) {
        slow = slow.next!;
        fast = fast.next.next;
    }
    const right = slow.next;
    slow.next = null;                          // 切斷成兩半

    let a = sortList(head), b = sortList(right);
    const dummy = new ListNode(0);
    let tail = dummy;
    while (a && b) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = a ?? b;
    return dummy.next;
}
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
// 合併排序：快慢指針切半 → 遞迴排序 → 合併
// 時間複雜度: O(n log n)，空間複雜度: O(log n)
static struct ListNode* mergeTwo(struct ListNode* a, struct ListNode* b) {
    struct ListNode dummy = {0, NULL};
    struct ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) { tail->next = a; a = a->next; }
        else { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}

struct ListNode* sortList(struct ListNode* head) {
    if (!head || !head->next) return head;

    struct ListNode *slow = head, *fast = head->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    struct ListNode* right = slow->next;
    slow->next = NULL;                         // 切斷成兩半

    return mergeTwo(sortList(head), sortList(right));
}

複雜度分析

時間複雜度：O(n log n)
  • 共 log n 層，每層合併的總成本為 O(n)
  • 與輸入順序無關，沒有最壞情況退化的問題（不像快排）
空間複雜度：
  • 自頂向下遞迴：O(log n) 的遞迴堆疊
  • 自底向上迭代：O(1) ★ 完全符合進階要求
  • 兩者都不需要額外陣列，因為合併只是改指標

重點提示

💡 關鍵技巧 1：找中點後一定要切斷

slow.next = null 少了這行就會無限遞迴 stack overflow。這是本題最常見的 bug。

💡 關鍵技巧 2：fast 從 head.next 起跑

兩個節點時（[4,2]），若 fast 從 head 起跑，slow 會停在第二個，切出來的左半段是整條串列 → 無限遞迴。從 head.next 起跑可讓 slow 停在前半段最後一個，保證兩邊都非空。

💡 面試回答重點

被問「為什麼不用快排？」時，答：快排需要隨機存取才能有效率地做 partition，而且鏈結串列上很難挑好的 pivot，最壞會退化成 O(n²)。合併排序在串列上反而比在陣列上更好，因為省掉了 O(n) 的暫存空間。

⚠️ 常見錯誤：
  • 忘記切斷造成無限遞迴
  • fast 起始位置寫錯，導致兩個節點的情況無法收斂
  • merge 用 < 而非 <=，雖然結果正確但失去穩定性
  • 沒有處理空串列或單節點

排序演算法比較表（面試必備）

📊 常見排序法
演算法      平均        最壞        空間      穩定  適用
------------------------------------------------------------------
氣泡/插入   O(n²)      O(n²)       O(1)      是    小資料、近乎有序
選擇        O(n²)      O(n²)       O(1)      否    幾乎不用
合併        O(n log n) O(n log n)  O(n)      是    需穩定、外部排序、鏈結串列★
快速        O(n log n) O(n²)       O(log n)  否    通用、快取友善（實務最快）
堆積        O(n log n) O(n log n)  O(1)      否    需要最壞保證、Top-K
計數/基數   O(n + k)   O(n + k)    O(k)      是    值域小的整數

「穩定」= 相等元素的相對順序不變，
在多鍵排序（先排 A 再排 B）時非常重要。

實務補充：Timsort

Python 的 sorted() 和 Java 的 Arrays.sort(Object[]) 都使用 Timsort——合併排序與插入排序的混合。它會偵測資料中已經有序的片段（run）並直接利用，對真實世界中「部分有序」的資料特別快，且保有穩定性。

邊界情況檢查清單

  • 空串列 → 直接返回 null
  • 單一節點 → 直接返回（也是遞迴的終止條件）
  • 兩個節點 → 注意 fast 起跑點，否則無限遞迴
  • 全部值相同 → merge 用 <= 可保持穩定
  • 含負數 → 本題無特殊處理需求
