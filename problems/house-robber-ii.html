#213 House Robber II

Medium
Dynamic Programming Array

題目描述

你是一個專業的小偷，計劃偷竊沿街的房屋，每間房內都藏有一定的現金。這個地方所有的房屋都圍成一圈，這意味著第一個房屋和最後一個房屋是緊挨著的。

同時，相鄰的房屋裝有相互連通的防盜系統，如果兩間相鄰的房屋在同一晚上被小偷闖入，系統會自動報警。

給定一個代表每個房屋存放金額的非負整數陣列，計算你在不觸動警報裝置的情況下，能夠偷竊到的最高金額。

範例

範例 1：
輸入：nums = [2,3,2]
輸出：3
解釋：不能先偷房屋 1（2）再偷房屋 3（2），因為它們是相鄰的（環狀）。所以只能偷房屋 2 得到 3。
範例 2：
輸入：nums = [1,2,3,1]
輸出：4
解釋：偷房屋 1（1）和房屋 3（3），總計 1 + 3 = 4。
範例 3：
輸入：nums = [1,2,3]
輸出：3

解題思路

💡 核心：把「環」拆成兩個「線」
環狀的麻煩在於：首尾相鄰，不能同時偷。

【關鍵洞察】第一間房只有兩種可能：偷 或 不偷

情況 A：不偷第一間 → 最後一間就沒有限制了
        → 對 nums[1 .. n-1] 跑普通的 #198
情況 B：偷第一間   → 最後一間一定不能偷
        → 對 nums[0 .. n-2] 跑普通的 #198

答案 = max(情況 A, 情況 B)

⚠️ 注意：情況 B 的範圍 [0, n-2] 中，
   我們並沒有「強制」偷第一間，
   但這沒關係 —— 因為「偷第一間」的所有可能方案
   都被包含在這個範圍的解裡了，
   而任何不偷第一間的方案又被情況 A 涵蓋。
   兩者的聯集覆蓋了所有合法方案 ✓

回顧 #198：線性版的狀態轉移

🎯 dp[i] = max(不偷第 i 間, 偷第 i 間)
dp[i] = 前 i 間房能偷到的最大金額

dp[i] = max(dp[i-1],              # 不偷第 i 間
            dp[i-2] + nums[i])    # 偷第 i 間（則 i-1 不能偷）

因為只依賴前兩個狀態，可以用兩個變數滾動：

int rob(vector& nums, int start, int end) {
    int prev2 = 0, prev1 = 0;      // dp[i-2], dp[i-1]
    for (int i = start; i <= end; i++) {
        int cur = max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

空間 O(1)。

完整追蹤：nums = [1,2,3,1]

🔄 兩種情況各跑一次
【情況 A】不偷第 0 間 → 處理 nums[1..3] = [2,3,1]
  i=1: cur = max(0, 0+2) = 2   → prev2=0, prev1=2
  i=2: cur = max(2, 0+3) = 3   → prev2=2, prev1=3
  i=3: cur = max(3, 2+1) = 3   → 結果 3

【情況 B】可偷第 0 間 → 處理 nums[0..2] = [1,2,3]
  i=0: cur = max(0, 0+1) = 1   → prev2=0, prev1=1
  i=1: cur = max(1, 0+2) = 2   → prev2=1, prev1=2
  i=2: cur = max(2, 1+3) = 4   → 結果 4 ★

答案 = max(3, 4) = 4 ✓（偷房屋 0 和 2，即 1 + 3）

邊界情況

當 n == 1 時不能拆成兩段（會產生空範圍），必須直接返回 nums[0]。這是本題唯一的特判。

程式碼實現

class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)

        # 特判：只有一間房，沒有環的問題
        if n == 1:
            return nums[0]

        def rob_line(start, end):
            # 對 nums[start..end] 跑線性版的打家劫舍
            prev2, prev1 = 0, 0        # dp[i-2], dp[i-1]
            for i in range(start, end + 1):
                cur = max(prev1, prev2 + nums[i])
                prev2, prev1 = prev1, cur
            return prev1

        # 情況 A：不偷第一間，範圍 [1, n-1]
        # 情況 B：可偷第一間，範圍 [0, n-2]（則最後一間不能偷）
        return max(rob_line(1, n - 1), rob_line(0, n - 2))
class Solution {
    // 對 nums[start..end] 跑線性版打家劫舍（#198）
    int robLine(vector<int>& nums, int start, int end) {
        int prev2 = 0, prev1 = 0;      // dp[i-2], dp[i-1]
        for (int i = start; i <= end; i++) {
            int cur = max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }

public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];    // 特判：只有一間房

        // 情況 A：不偷第一間 [1, n-1]
        // 情況 B：可偷第一間 [0, n-2]
        return max(robLine(nums, 1, n - 1),
                   robLine(nums, 0, n - 2));
    }
};
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];    // 特判：只有一間房

        // 情況 A：不偷第一間 [1, n-1]
        // 情況 B：可偷第一間 [0, n-2]
        return Math.max(robLine(nums, 1, n - 1),
                        robLine(nums, 0, n - 2));
    }

    // 對 nums[start..end] 跑線性版打家劫舍
    private int robLine(int[] nums, int start, int end) {
        int prev2 = 0, prev1 = 0;      // dp[i-2], dp[i-1]
        for (int i = start; i <= end; i++) {
            int cur = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}

複雜度分析

時間複雜度：O(n)
  • 跑兩次線性 DP，各 O(n)
  • 常數是 2，但仍是 O(n)
空間複雜度：O(1)
  • 滾動變數版本只用了兩個變數
  • 若用 dp 陣列則是 O(n)

重點提示

💡 關鍵技巧：環狀問題「拆環成鏈」

環狀 DP 的通用套路：對「某個特殊元素選或不選」分情況討論，把環拆成兩個線性問題。這個技巧在環狀陣列的各種問題中都適用。

💡 為什麼「不強制偷第一間」也是對的？

情況 B 的範圍 [0, n-2] 其實包含了「偷第一間」和「不偷第一間但也不偷最後一間」兩類方案。雖然有重疊，但因為我們取的是 max，重複計算不會造成錯誤（不像求「方案數」時重複會出錯）。這是很值得注意的細節。

⚠️ 常見錯誤：
  • 忘記 n == 1 的特判（範圍 [0, -1] 和 [1, 0] 都是空的，會回傳 0）
  • 範圍寫錯（應該是 [1, n-1] 和 [0, n-2]）
  • 試圖用一次 DP 解決環狀問題（狀態會很複雜且容易出錯）
  • 滾動變數更新順序寫錯（要先更新 prev2 再更新 prev1）

#337 House Robber III：樹型版本

🌲 每個節點回傳兩個狀態
房屋排成二元樹，父子節點不能同時偷。

回傳 pair<偷這個節點的最大值, 不偷這個節點的最大值>

pair<int,int> dfs(TreeNode* node) {
    if (!node) return {0, 0};
    auto [lRob, lSkip] = dfs(node->left);
    auto [rRob, rSkip] = dfs(node->right);

    int rob  = node->val + lSkip + rSkip;      // 偷自己 → 子節點都不能偷
    int skip = max(lRob, lSkip) + max(rRob, rSkip);  // 不偷自己 → 子節點隨意
    return {rob, skip};
}

答案 = max(dfs(root).first, dfs(root).second)

⭐ 這種「回傳多個狀態」的技巧是樹型 DP 的核心。

#918 環狀最大子陣列和：另一種拆環思路

求環狀陣列的最大子陣列和，有兩種情況：

情況 A：答案不跨越邊界 → 就是普通的 Kadane 演算法
情況 B：答案跨越邊界   → 等價於「總和 - 中間那段最小子陣列和」

答案 = max(maxSubarray, total - minSubarray)

⚠️ 特例：若全部都是負數，
   total - minSubarray 會等於 0（把整個陣列都當成最小段），
   但題目要求子陣列非空，所以要特判返回 maxSubarray。

int maxSubarraySumCircular(vector<int>& nums) {
    int total = 0, maxSum = INT_MIN, curMax = 0;
    int minSum = INT_MAX, curMin = 0;
    for (int x : nums) {
        curMax = max(curMax + x, x);  maxSum = max(maxSum, curMax);
        curMin = min(curMin + x, x);  minSum = min(minSum, curMin);
        total += x;
    }
    return maxSum > 0 ? max(maxSum, total - minSum) : maxSum;
}

這是「拆環」的另一種思路 —— 用補集轉換，
和本題的「分情況討論」是環狀問題的兩大武器。

DP 空間優化的通用觀念

  • 若 dp[i] 只依賴 dp[i-1] → 用一個變數
  • 若依賴 dp[i-1] 和 dp[i-2] → 用兩個變數（本題）
  • 若二維 dp[i][j] 只依賴上一行 → 用一維滾動陣列
  • 優化前務必先寫出正確的完整版本，確認無誤後再壓縮
