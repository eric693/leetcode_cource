#994 Rotting Oranges

Medium
BFS Matrix Array Graph

題目描述

在給定的 m × n 網格 grid 中，每個儲存格可以有以下三個值之一：

  • 0 代表空儲存格
  • 1 代表新鮮橘子
  • 2 代表腐爛的橘子

每分鐘，腐爛的橘子周圍 4 個方向上相鄰的新鮮橘子都會腐爛。

返回直到儲存格中沒有新鮮橘子為止所必須經過的最小分鐘數。如果不可能，返回 -1。

範例

範例 1：
輸入：grid = [[2,1,1],[1,1,0],[0,1,1]]
輸出：4

第 0 分鐘        第 1 分鐘        第 2 分鐘
2 1 1            2 2 1            2 2 2
1 1 0     →      2 1 0     →      2 2 0
0 1 1            0 1 1            0 1 1

第 3 分鐘        第 4 分鐘
2 2 2            2 2 2
2 2 0     →      2 2 0
0 2 1            0 2 2
範例 2：
輸入：grid = [[2,1,1],[0,1,1],[1,0,1]]
輸出：-1
解釋：左下角的橘子被 0 隔開，永遠不會腐爛。
範例 3：
輸入：grid = [[0,2]]
輸出：0
解釋：一開始就沒有新鮮橘子，所以答案是 0。

解題思路

💡 核心：多源 BFS（Multi-source BFS）
關鍵觀察：腐爛是【同時】從所有爛橘子向外擴散的，
          這正是 BFS「逐層擴散」的模型。

⭐ 多源 BFS 的做法：
   把【所有】初始的爛橘子一次全部放進佇列，
   然後正常做 BFS，每一「層」就是一分鐘。

這等價於：想像有一個虛擬的超級源點，
連向所有爛橘子（距離 0），再從它做單源 BFS。

    2 1 1
    1 1 0
    0 1 1

初始佇列 = [(0,0)]，只有一個爛橘子

第 1 層（1 分鐘）：(0,1), (1,0) 腐爛
第 2 層（2 分鐘）：(0,2), (1,1) 腐爛
第 3 層（3 分鐘）：(2,1) 腐爛
第 4 層（4 分鐘）：(2,2) 腐爛
新鮮橘子歸零 → 答案 4 ✓

實作要點：逐層處理

🎯 用 queue.size() 分層
while (!queue.empty() && fresh > 0) {
    int size = queue.size();       // ← 記錄「這一層」有幾個
    for (int i = 0; i < size; i++) {
        取出一個，向四方擴散
    }
    minutes++;                     // 處理完一整層 = 過了一分鐘
}

⚠️ 必須先把 size 存下來，
   因為迴圈中會不斷往 queue 加新元素，
   直接用 queue.size() 當條件會把新一層也算進來。

兩個關鍵細節

🔍 容易出錯的地方
【細節 1】要先統計新鮮橘子的數量 fresh
  結束時若 fresh > 0，代表有橘子永遠爛不到 → 返回 -1

【細節 2】迴圈條件要加上 fresh > 0
  否則最後一層擴散完後，還會多算一分鐘。

  範例：grid = [[2,1]]
    初始 fresh = 1
    第一層擴散後 fresh = 0，minutes = 1 ✓
    若沒有 fresh > 0 的條件，
    下一輪佇列還有元素（剛加入的 (0,1)），
    處理完後 minutes 會變成 2 ✗

【細節 3】一開始就沒有新鮮橘子
  fresh == 0，迴圈直接不執行，返回 0 ✓

程式碼實現

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        from collections import deque

        m, n = len(grid), len(grid[0])
        queue = deque()
        fresh = 0

        # 1. 統計新鮮橘子，並把所有爛橘子一次放進佇列（多源）
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    queue.append((i, j))
                elif grid[i][j] == 1:
                    fresh += 1

        # 一開始就沒有新鮮橘子
        if fresh == 0:
            return 0

        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        minutes = 0

        # 2. 逐層 BFS，每一層代表一分鐘
        while queue and fresh > 0:
            size = len(queue)              # 固定住「這一層」的數量
            for _ in range(size):
                x, y = queue.popleft()
                for dx, dy in directions:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == 1:
                        grid[nx][ny] = 2   # 腐爛（同時當作已訪問標記）
                        fresh -= 1
                        queue.append((nx, ny))
            minutes += 1

        # 3. 若還有新鮮橘子，代表永遠爛不到
        return minutes if fresh == 0 else -1
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        queue<pair<int,int>> q;
        int fresh = 0;

        // 1. 統計新鮮橘子，所有爛橘子一次入隊（多源 BFS）
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2)      q.push({i, j});
                else if (grid[i][j] == 1) fresh++;
            }
        }

        if (fresh == 0) return 0;

        int dirs[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};
        int minutes = 0;

        // 2. 逐層 BFS
        while (!q.empty() && fresh > 0) {
            int size = q.size();          // 固定住這一層的數量
            for (int i = 0; i < size; i++) {
                auto [x, y] = q.front(); q.pop();
                for (auto& d : dirs) {
                    int nx = x + d[0], ny = y + d[1];
                    if (nx >= 0 && nx < m && ny >= 0 && ny < n
                        && grid[nx][ny] == 1) {
                        grid[nx][ny] = 2;  // 腐爛 = 已訪問
                        fresh--;
                        q.push({nx, ny});
                    }
                }
            }
            minutes++;
        }

        return fresh == 0 ? minutes : -1;
    }
};
class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Deque<int[]> queue = new ArrayDeque<>();
        int fresh = 0;

        // 1. 統計新鮮橘子，所有爛橘子一次入隊
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2)      queue.offer(new int[]{i, j});
                else if (grid[i][j] == 1) fresh++;
            }
        }

        if (fresh == 0) return 0;

        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};
        int minutes = 0;

        // 2. 逐層 BFS
        while (!queue.isEmpty() && fresh > 0) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int[] cur = queue.poll();
                for (int[] d : dirs) {
                    int nx = cur[0] + d[0], ny = cur[1] + d[1];
                    if (nx >= 0 && nx < m && ny >= 0 && ny < n
                        && grid[nx][ny] == 1) {
                        grid[nx][ny] = 2;
                        fresh--;
                        queue.offer(new int[]{nx, ny});
                    }
                }
            }
            minutes++;
        }

        return fresh == 0 ? minutes : -1;
    }
}

複雜度分析

時間複雜度：O(m × n)
  • 初始掃描一次網格 O(mn)
  • BFS 中每個儲存格最多入隊一次 O(mn)
空間複雜度：O(m × n)
  • 最壞情況（全部都是爛橘子）佇列會存下整個網格
  • 直接在原網格上標記，省下額外的 visited 陣列

重點提示

💡 關鍵技巧 1：多源 BFS

「多個起點同時擴散」就把所有起點一次放進初始佇列。這比對每個起點各跑一次 BFS 快非常多，是解一整類「擴散/傳染/最近距離」問題的標準手法。

💡 關鍵技巧 2：用原地修改取代 visited 陣列

把 1 改成 2 既表示「腐爛了」也表示「已訪問」，一舉兩得，省下 O(mn) 空間。若題目不允許修改輸入，才需要額外的 visited。

💡 關鍵技巧 3：迴圈條件加 fresh > 0

這是本題最容易踩的坑。少了它，最後一層擴散完後還會多算一分鐘，導致答案大 1。

⚠️ 常見錯誤：
  • 多算一分鐘（沒加 fresh > 0 條件）
  • 沒處理「一開始就沒有新鮮橘子」→ 應返回 0 而非 -1
  • 直接用 queue.size() 當內層迴圈條件（會把新加入的一層也算進來）
  • 用 DFS 解 —— DFS 無法保證「最短時間」，這類題一定要用 BFS

什麼時候用 BFS？什麼時候用 DFS？

問題類型                        用哪個
------------------------------------------------------
最短路徑 / 最少步數 / 最短時間   BFS ★（DFS 不保證最短）
逐層 / 分層處理                  BFS
連通分量計數（島嶼數量）         都可以
找出所有路徑 / 組合              DFS + 回溯
拓撲排序                         都可以（Kahn 是 BFS）
偵測環                           DFS 較自然

本題是「最小分鐘數」→ 必須用 BFS。
