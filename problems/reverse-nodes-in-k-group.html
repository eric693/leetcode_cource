#25 Reverse Nodes in k-Group

Hard
Linked List Recursion Iteration

題目描述

給定一個鏈表，每 k 個節點一組進行翻轉，返回翻轉後的鏈表。

限制條件：

  • k 是一個正整數，它的值小於或等於鏈表的長度
  • 如果節點總數不是 k 的整數倍，那麼請將最後剩餘的節點保持原有順序
  • 你不能只是單純的改變節點內部的值，而是需要實際進行節點交換

範例

範例 1：
輸入：head = [1,2,3,4,5], k = 2
輸出：[2,1,4,3,5]
解釋： 
原始: 1 → 2 → 3 → 4 → 5
      └───┘   └───┘   │
      翻轉    翻轉    保持

結果: 2 → 1 → 4 → 3 → 5
範例 2：
輸入：head = [1,2,3,4,5], k = 3
輸出：[3,2,1,4,5]
解釋： 
原始: 1 → 2 → 3 → 4 → 5
      └───────┘   └───┘
         翻轉      不足3個，保持

結果: 3 → 2 → 1 → 4 → 5
範例 3：
輸入：head = [1,2,3,4,5], k = 1
輸出：[1,2,3,4,5]
解釋：k = 1 時不需要翻轉

解題思路

核心概念：分組翻轉 + 連接
這題是 #206 Reverse Linked List 的進階版，需要：
  1. 檢查長度：確保有 k 個節點才翻轉
  2. 局部翻轉：翻轉當前 k 個節點
  3. 連接組別：將翻轉後的組與前後節點連接
  4. 遞迴或迭代：處理下一組

方法一：遞迴解法（最優雅）

遞迴步驟詳解
1️⃣ 檢查是否有 k 個節點
   head → 1 → 2 → 3 → 4 → 5
   計數: 1   2   3   (有3個，可以翻轉)

2️⃣ 翻轉前 k 個節點
   翻轉前: 1 → 2 → 3 → 4 → 5
   翻轉後: 3 → 2 → 1 → 4 → 5
           ↑       ↑   ↑
         newHead tail next

3️⃣ 遞迴處理剩餘部分
   tail.next = reverseKGroup(next, k)
   
4️⃣ 返回新頭節點
   return newHead (即原來的第 k 個節點)

方法二：迭代解法

使用 dummy node 和四個指標來追蹤：

  • prevGroup：上一組的尾節點
  • groupStart：當前組的第一個節點
  • groupEnd：當前組的最後一個節點
  • nextGroup：下一組的第一個節點

程式碼實現

# 方法一：遞迴解法
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        # 1. 檢查是否有 k 個節點
        curr = head
        count = 0
        while curr and count < k:
            curr = curr.next
            count += 1
        
        # 不足 k 個，直接返回
        if count < k:
            return head
        
        # 2. 翻轉前 k 個節點
        prev = None
        curr = head
        next_node = None
        
        for i in range(k):
            next_node = curr.next
            curr.next = prev
            prev = curr
            curr = next_node
        
        # 3. 遞迴處理剩餘部分
        # prev 現在是翻轉後的頭節點
        # head 現在是翻轉後的尾節點
        # curr 是下一組的開始
        head.next = self.reverseKGroup(curr, k)
        
        # 4. 返回新頭節點
        return prev


# 方法二：迭代解法
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        # 輔助函數：翻轉鏈表的一段 [start, end]
        def reverseSegment(start, end):
            prev = None
            curr = start
            while prev != end:
                next_node = curr.next
                curr.next = prev
                prev = curr
                curr = next_node
            return end, start  # 返回新頭和新尾
        
        dummy = ListNode(0)
        dummy.next = head
        prevGroup = dummy
        
        while True:
            # 找到當前組的第 k 個節點
            groupEnd = prevGroup
            for i in range(k):
                groupEnd = groupEnd.next
                if not groupEnd:
                    return dummy.next  # 不足 k 個
            
            groupStart = prevGroup.next
            nextGroup = groupEnd.next
            
            # 翻轉當前組
            newGroupHead, newGroupTail = reverseSegment(groupStart, groupEnd)
            
            # 連接前後
            prevGroup.next = newGroupHead
            newGroupTail.next = nextGroup
            
            # 移動到下一組
            prevGroup = newGroupTail


# 方法三：簡潔的遞迴版本
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        # 檢查長度
        node = head
        for i in range(k):
            if not node:
                return head
            node = node.next
        
        # 翻轉 k 個節點
        prev, curr = None, head
        for i in range(k):
            curr.next, prev, curr = prev, curr, curr.next
        
        # 遞迴處理下一組
        head.next = self.reverseKGroup(curr, k)
        
        return prev

class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prevGroup = dummy;
        
        while (true) {
            // 找到第 k 個節點
            ListNode groupEnd = prevGroup;
            for (int i = 0; i < k; i++) {
                groupEnd = groupEnd.next;
                if (groupEnd == null) return dummy.next;
            }
            
            ListNode groupStart = prevGroup.next;
            ListNode nextGroup = groupEnd.next;
            
            // 翻轉當前組
            ListNode prev = nextGroup;
            ListNode curr = groupStart;
            
            while (curr != nextGroup) {
                ListNode next = curr.next;
                curr.next = prev;
                prev = curr;
                curr = next;
            }
            
            // 連接
            prevGroup.next = groupEnd;
            prevGroup = groupStart;
        }

/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 * }
 */
// 每次確認後面還有 k 個節點，再把這一段原地反轉並接回去
// 時間複雜度: O(n)，空間複雜度: O(1)
function reverseKGroup(head: ListNode | null, k: number): ListNode | null {
    const dummy = new ListNode(0, head);
    let groupPrev = dummy;

    while (true) {
        let kth: ListNode | null = groupPrev;
        for (let i = 0; i < k && kth; i++) kth = kth.next;
        if (!kth) break;                              // 不足 k 個，保持原樣

        const groupNext = kth.next;
        let prev: ListNode | null = groupNext, cur = groupPrev.next;
        while (cur !== groupNext) {                   // 反轉這 k 個節點
            const next: ListNode | null = cur!.next;
            cur!.next = prev;
            prev = cur;
            cur = next;
        }
        const first = groupPrev.next!;                // 反轉前的第一個，反轉後變最後一個
        groupPrev.next = kth;
        groupPrev = first;
    }
    return dummy.next;
}
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
// 每次確認後面還有 k 個節點，再把這一段原地反轉並接回去
// 時間複雜度: O(n)，空間複雜度: O(1)
struct ListNode* reverseKGroup(struct ListNode* head, int k) {
    struct ListNode dummy = {0, head};
    struct ListNode* groupPrev = &dummy;

    while (1) {
        struct ListNode* kth = groupPrev;
        for (int i = 0; i < k && kth; i++) kth = kth->next;
        if (!kth) break;                              // 不足 k 個，保持原樣

        struct ListNode* groupNext = kth->next;
        struct ListNode *prev = groupNext, *cur = groupPrev->next;
        while (cur != groupNext) {                    // 反轉這 k 個節點
            struct ListNode* next = cur->next;
            cur->next = prev;
            prev = cur;
            cur = next;
        }
        struct ListNode* first = groupPrev->next;     // 反轉後變成這段的最後一個
        groupPrev->next = kth;
        groupPrev = first;
    }
    return dummy.next;
}

複雜度分析

時間複雜度：O(n)
  • 需要遍歷整個鏈表一次
  • 每個節點最多被訪問兩次（檢查 + 翻轉）
空間複雜度：
  • 遞迴解法：O(n/k)，遞迴調用棧的深度
  • 迭代解法：O(1)，只使用常數額外空間

重點提示

關鍵技巧 1：檢查長度

必須先檢查是否有 k 個節點，避免不完整的翻轉。

關鍵技巧 2：保存指標

翻轉時要保存 prevGroup、groupEnd、nextGroup 等關鍵指標。

關鍵技巧 3：Dummy Node

使用 dummy node 可以統一處理頭節點的情況。

常見錯誤：
  • 忘記檢查剩餘節點數量，導致不完整翻轉
  • 指標連接順序錯誤，導致鏈表斷裂
  • 沒有正確處理組與組之間的連接
  • 翻轉後忘記更新 prevGroup 指標
完整翻轉過程（k=3）
初始: dummy → 1 → 2 → 3 → 4 → 5 → 6 → 7
              ↑           ↑   ↑
         groupStart   groupEnd next

第一組翻轉後:
      dummy → 3 → 2 → 1 → 4 → 5 → 6 → 7
                      ↑   ↑
                 prevGroup next

第二組翻轉後:
      dummy → 3 → 2 → 1 → 6 → 5 → 4 → 7
                          ↑       ↑   ↑
                     newHead  newTail next

最終結果:
      3 → 2 → 1 → 6 → 5 → 4 → 7
      └───────┘   └───────┘   │
        第一組      第二組    保持
