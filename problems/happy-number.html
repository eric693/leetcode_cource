202. Happy Number
Easy

題目描述

編寫一個演算法來判斷一個數 n 是不是快樂數。

快樂數的定義為：對於一個正整數，每一次將該數替換為它每個位置上的數字的平方和；重複這個過程直到這個數變為 1，或是無限循環但始終變不到 1。如果這個過程結果為 1，那麼這個數就是快樂數。

範例 1:
輸入: n = 19
輸出: true
解釋: 1² + 9² = 82，8² + 2² = 68，6² + 8² = 100，1² + 0² + 0² = 1
範例 2:
輸入: n = 2
輸出: false
解釋: 過程會進入 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 的循環

解題思路

方法一：快慢指標（推薦）

把「求各位數字平方和」看成一個函數 next(n)，整個過程就是一條隱式的鏈結串列：n → next(n) → next(next(n)) → …

不是快樂數就代表這條鏈上有環，因此可用 Floyd 判圈法：slow 每次走一步、fast 每次走兩步，兩者相遇時檢查是否為 1。

這個做法只需 O(1) 額外空間。

方法二：雜湊集合記錄

把每次算出的數字放進集合，若某個數字再次出現代表進入循環，回傳 false；若算到 1 則回傳 true。

思路最直觀，代價是需要 O(log n) 的額外空間存放走過的數字。

程式碼實現

class Solution:
    def isHappy(self, n: int) -> bool:
        def next_num(x: int) -> int:
            total = 0
            while x > 0:
                x, digit = divmod(x, 10)
                total += digit * digit
            return total

        slow, fast = n, next_num(n)
        while fast != 1 and slow != fast:
            slow = next_num(slow)
            fast = next_num(next_num(fast))
        return fast == 1
class Solution {
    private int nextNum(int x) {
        int total = 0;
        while (x > 0) {
            int digit = x % 10;
            total += digit * digit;
            x /= 10;
        }
        return total;
    }

    public boolean isHappy(int n) {
        int slow = n, fast = nextNum(n);
        while (fast != 1 && slow != fast) {
            slow = nextNum(slow);
            fast = nextNum(nextNum(fast));
        }
        return fast == 1;
    }
}

複雜度分析

時間複雜度: O(log n)

單次計算平方和的成本與位數成正比，而數字會迅速降到三位數以內的小範圍，之後鏈長是常數等級。

空間複雜度: O(1)

快慢指標只用兩個整數變數，不需要記錄走過的數字。

重點提示

  • 本質是判圈：看出「反覆套用同一函數」等價於鏈結串列，就能直接搬用 Floyd 判圈法
  • 數值不會爆炸：任何數經一次轉換後最多變成三位數等級（999 → 243），因此不必擔心溢位
  • 迴圈終止條件：兩個條件缺一不可：fast 到達 1 為真，slow 與 fast 相遇為假
  • 取位數技巧：用 x % 10 取個位、x /= 10 去掉個位，是處理數字各位的標準寫法
