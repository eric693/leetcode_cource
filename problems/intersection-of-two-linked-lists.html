#160 Intersection of Two Linked Lists

Easy
Linked List Two Pointers Hash Table

題目描述

給你兩個單向鏈結串列的頭節點 headA 和 headB，請你找出並返回兩個單向串列相交的起始節點。如果兩個串列不存在相交節點，返回 null。

題目資料保證整個鏈式結構中不存在環，且函數返回結果後，串列必須保持其原始結構。

進階：能否設計一個時間複雜度 O(m+n)、僅用 O(1) 記憶體的解決方案？

範例

範例 1：
A: 4 → 1 ↘
           8 → 4 → 5
B: 5 → 6 → 1 ↗

輸入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5]
輸出：值為 8 的節點
範例 2：
輸入：listA = [2,6,4], listB = [1,5]
輸出：null（不相交）

解題思路

⚠️ 重要觀念：「相交」指的是節點位址相同，不是值相同！

一旦兩條串列相交，從交點之後就完全共用同一段節點，所以尾巴一定一樣長。

方法一：雙指標「走完自己走對方」（最優雅）

💡 消除長度差的神技
設 A 獨有長度 a、B 獨有長度 b、共同部分長度 c

指標 pA：走 A（a + c）再走 B（b + c）→ 總共 a + c + b
指標 pB：走 B（b + c）再走 A（a + c）→ 總共 b + c + a

兩者走過的總步數完全相同！所以第二輪必定同時抵達交點。

實例：A = [4,1,8,4,5]  B = [5,6,1,8,4,5]  交點值 8
pA: 4 1 8 4 5 | 5 6 1 [8] ...
pB: 5 6 1 8 4 5 | 4 1 [8] ...
                     ↑ 第 9 步同時抵達 ✓

若不相交：兩者會同時走到 null，null == null 迴圈結束，
          自然返回 null，不需要特判 ✓

方法二：對齊長度

🎯 先算長度差，長的先走

分別算出兩條串列長度 lenA、lenB，讓較長的那條先走 |lenA - lenB| 步，之後同步前進，第一個相同的節點就是交點。邏輯較直白，但程式碼比方法一長。

方法三：HashSet

把 A 的所有節點放進 HashSet，再遍歷 B 找第一個在集合中的節點。O(m+n) 時間但需要 O(m) 空間，不符合進階要求，適合當作面試的第一個答案再優化。

程式碼實現

# 方法一：走完自己走對方（推薦，O(1) 空間）
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        if not headA or not headB:
            return None

        pA, pB = headA, headB
        # 兩指標走過的總長度相同：a+c+b == b+c+a
        while pA is not pB:
            pA = pA.next if pA else headB   # 走完 A 就換到 B 開頭
            pB = pB.next if pB else headA   # 走完 B 就換到 A 開頭
        return pA        # 交點，或不相交時的 None


# 方法二：對齊長度
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        def length(node):
            n = 0
            while node:
                n += 1
                node = node.next
            return n

        lenA, lenB = length(headA), length(headB)
        # 讓較長的先走完長度差
        while lenA > lenB:
            headA = headA.next
            lenA -= 1
        while lenB > lenA:
            headB = headB.next
            lenB -= 1

        while headA is not headB:
            headA = headA.next
            headB = headB.next
        return headA
// 方法一：走完自己走對方（推薦）
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        if (!headA || !headB) return nullptr;

        ListNode *pA = headA, *pB = headB;
        while (pA != pB) {
            pA = pA ? pA->next : headB;   // 走完 A 換到 B
            pB = pB ? pB->next : headA;   // 走完 B 換到 A
        }
        return pA;   // 交點，或都是 nullptr
    }
};

// 方法二：對齊長度
class Solution {
    int getLength(ListNode* node) {
        int n = 0;
        while (node) { n++; node = node->next; }
        return n;
    }
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        int lenA = getLength(headA), lenB = getLength(headB);
        while (lenA > lenB) { headA = headA->next; lenA--; }
        while (lenB > lenA) { headB = headB->next; lenB--; }
        while (headA != headB) { headA = headA->next; headB = headB->next; }
        return headA;
    }
};
// 方法一：走完自己走對方（推薦）
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) return null;

        ListNode pA = headA, pB = headB;
        while (pA != pB) {
            pA = (pA == null) ? headB : pA.next;   // 走完 A 換到 B
            pB = (pB == null) ? headA : pB.next;   // 走完 B 換到 A
        }
        return pA;
    }
}

// 方法三：HashSet（好懂但費空間）
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        Set<ListNode> set = new HashSet<>();
        while (headA != null) { set.add(headA); headA = headA.next; }
        while (headB != null) {
            if (set.contains(headB)) return headB;
            headB = headB.next;
        }
        return null;
    }
}

複雜度分析

時間複雜度：O(m + n)
  • 方法一：每個指標最多走 m + n 步
  • 方法二：算長度 O(m+n) + 同步走 O(min(m,n))
空間複雜度：
  • 方法一、二：O(1) ★ 符合進階要求
  • 方法三（HashSet）：O(m)

重點提示

💡 關鍵技巧：用「換軌」消除長度差

pA = pA ? pA->next : headB 這一行是本題精華。注意判斷的是指標本身是否為 null，不是 pA->next，否則會少走一步而錯過交點。

💡 不相交的情況自動處理

若不相交，兩指標會在第二輪同時變成 null，null == null 使迴圈結束並返回 null，完全不需要特判。這是這個寫法最漂亮的地方。

⚠️ 常見錯誤：
  • 比較節點的值而不是參考（值可能重複，一定要比位址）
  • 寫成 pA = pA->next ? pA->next : headB，少走一步導致不相交時無限迴圈
  • Python 用 == 比較節點物件時，若自訂了 __eq__ 會出錯，建議用 is

補充說明

為什麼相交後不會再分開？

🔍 單向串列的結構限制

每個節點只有一個 next 指標，所以一旦兩條路徑進入同一個節點，之後的路徑必然完全相同。這代表相交部分一定是「Y 字形」，不可能是「X 字形」。理解這點，長度差的解法就很自然了。

延伸：如果串列可能有環怎麼辦？

  • 先用 Floyd 判圈找出兩條串列各自的環入口
  • 兩條都無環 → 用本題方法
  • 一條有環一條無環 → 不可能相交
  • 兩條都有環且入口相同 → 在入環前相交，把入口當終點用本題方法
  • 兩條都有環但入口不同 → 從一個入口繞環一圈，若能碰到另一個入口則共用同一個環，否則不相交
