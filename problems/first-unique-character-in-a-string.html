387. First Unique Character in a String
Easy

題目描述

給定一個字串 s，找出其中第一個不重複的字元，並返回它的索引。如果不存在，則返回 -1。

字串只包含小寫英文字母。

範例 1:
輸入: s = "leetcode"
輸出: 0
解釋: 字元 l 只出現一次，且是第一個
範例 2:
輸入: s = "loveleetcode"
輸出: 2
解釋: 前兩個字元 l、o 都重複出現，v 是第一個唯一字元
範例 3:
輸入: s = "aabb"
輸出: -1

解題思路

方法一：兩次遍歷 + 計數（推薦）

第一次遍歷統計每個字元出現的次數，存在雜湊表或長度 26 的陣列中。

第二次依原字串順序遍歷，回傳第一個計數為 1 的字元索引。第二次遍歷必須走原字串，因為雜湊表本身不保證與字串一致的順序。

方法二：記錄首次出現位置

只走訪一次，對每個字元記錄「首次出現的索引」，重複出現時把值標記為無效（例如 -1）。

最後在 26 個字母中取所有有效索引的最小值。適合字元集固定的情況。

程式碼實現

class Solution:
    def firstUniqChar(self, s: str) -> int:
        count = [0] * 26
        for ch in s:
            count[ord(ch) - ord('a')] += 1
        for i, ch in enumerate(s):
            if count[ord(ch) - ord('a')] == 1:
                return i
        return -1
class Solution {
    public int firstUniqChar(String s) {
        int[] count = new int[26];
        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
        }
        for (int i = 0; i < s.length(); i++) {
            if (count[s.charAt(i) - 'a'] == 1) return i;
        }
        return -1;
    }
}
// 計數陣列：第一輪統計次數，第二輪找第一個次數為 1 的字元
// 時間複雜度: O(n)，空間複雜度: O(1)（固定 26 格）
function firstUniqChar(s: string): number {
    const count = new Array(26).fill(0);
    for (let i = 0; i < s.length; i++) count[s.charCodeAt(i) - 97]++;
    for (let i = 0; i < s.length; i++) {
        if (count[s.charCodeAt(i) - 97] === 1) return i;
    }
    return -1;
}
// 計數陣列：第一輪統計次數，第二輪找第一個次數為 1 的字元
// 時間複雜度: O(n)，空間複雜度: O(1)（固定 26 格）
int firstUniqChar(char* s) {
    int count[26] = {0};
    for (int i = 0; s[i]; i++) count[s[i] - 'a']++;
    for (int i = 0; s[i]; i++) {
        if (count[s[i] - 'a'] == 1) return i;
    }
    return -1;
}
class Solution {
public:
    int firstUniqChar(string s) {
        vector<int> count(26, 0);
        for (char ch : s) count[ch - 'a']++;
        for (int i = 0; i < (int)s.size(); i++) {
            if (count[s[i] - 'a'] == 1) return i;
        }
        return -1;
    }
};

複雜度分析

時間複雜度: O(n)

兩次線性遍歷，每次對字元做常數時間的陣列存取。

空間複雜度: O(1)

計數陣列固定為 26 個元素，與輸入長度無關。

重點提示

  • 第二次要走字串：走計數表得到的是字母順序，走字串才是題目要的出現順序
  • 陣列勝過雜湊表：字元集限定小寫字母時，長度 26 的陣列比 HashMap 更快也更省
  • 索引轉換：用 ch 減去字元 a 把字元對應到 0..25
  • 無解回傳 -1：像 "aabb" 這種全部重複的情況要記得回傳 -1
