#461 Hamming Distance

Easy
Bit Manipulation

題目描述

兩個整數之間的漢明距離（Hamming Distance）指的是這兩個數字對應二進位位元不同的位置數目。

給你兩個整數 x 和 y，計算並返回它們之間的漢明距離。

漢明距離是通訊與儲存系統中錯誤偵測與更正碼（ECC）的基礎概念，韌體面試常考。

範例

範例 1：
輸入：x = 1, y = 4
輸出：2
1 = 0 0 0 1
4 = 0 1 0 0
        ↑ ↑
兩個位置不同 → 距離為 2
範例 2：
輸入：x = 3, y = 1
輸出：1
解釋：3 = 011, 1 = 001，只有第 1 位不同。

解題思路

💡 核心：XOR 後數 1 的個數
XOR 的特性：相同得 0，不同得 1
所以 x ^ y 的每個 1，就代表一個「不同的位置」

x = 1 = 0001
y = 4 = 0100
x^y   = 0101  → 有 2 個 1 → 漢明距離 = 2 ✓

問題轉化為：#191 Number of 1 Bits

數 1 的方法（三選一）

🎯 Brian Kernighan 最有效率
方法 A：逐位檢查，固定跑 32 次
    for i in 0..31: count += (xor >> i) & 1

方法 B：Brian Kernighan，跑「1 的個數」次
    while xor: xor &= xor - 1; count++

方法 C：內建函數
    __builtin_popcount(x ^ y)  /  Integer.bitCount(x ^ y)

追蹤方法 B（xor = 0101）：
  第 1 次：0101 & 0100 = 0100, count = 1
  第 2 次：0100 & 0011 = 0000, count = 2
  xor == 0 結束 → 答案 2 ✓

程式碼實現

# 方法一：Brian Kernighan（推薦）
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        xor = x ^ y
        count = 0
        while xor:
            xor &= xor - 1      # 每次消掉最右邊的 1
            count += 1
        return count


# 方法二：逐位檢查
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        xor = x ^ y
        count = 0
        for i in range(32):
            count += (xor >> i) & 1
        return count

// 方法一：Brian Kernighan（推薦）
class Solution {
public:
    int hammingDistance(int x, int y) {
        int xorVal = x ^ y, count = 0;
        while (xorVal) {
            xorVal &= (xorVal - 1);   // 消掉最右邊的 1
            count++;
        }
        return count;
    }
};

// 方法二：逐位移位比較
class Solution {
public:
    int hammingDistance(int x, int y) {
        int count = 0;
        while (x || y) {
            if ((x & 1) != (y & 1)) count++;
            x >>= 1;
            y >>= 1;
        }
        return count;
    }
};

class Solution {
    public int hammingDistance(int x, int y) {

        while (xor != 0) {

複雜度分析

時間複雜度：O(1)
  • Brian Kernighan：O(k)，k 為不同位的數量，最多 32
  • 逐位檢查：固定 O(32)
空間複雜度：O(1)

重點提示

💡 關鍵技巧：先轉化問題再解

「有幾個位不同」→ XOR → 「有幾個 1」。學會把陌生題目轉成已知題目，比記住解法更重要。

💡 面試延伸：Total Hamming Distance（#477）

要算陣列中所有配對的漢明距離總和。暴力是 O(n²)，正解是逐位統計：某一位有 c 個 1、n-c 個 0，該位貢獻 c × (n-c)，總複雜度 O(32n)。

⚠️ 常見錯誤：
  • 方法二的迴圈條件要寫 x || y，只寫 x 會漏掉 y 剩餘的高位
  • Java 對負數要用 >>>（本題保證非負所以還好）

補充說明

#477 Total Hamming Distance 解法

🎯 逐位統計，把 O(n²) 降成 O(32n)
nums = [4, 14, 2] = [00100, 01110, 00010]

第 1 位：1 的個數 c=2（14, 2），0 的個數 = 1
        貢獻 = 2 × 1 = 2
第 2 位：c=2（4, 14），0 的個數 = 1 → 貢獻 2
第 3 位：c=1（14），0 的個數 = 2 → 貢獻 2
總和 = 6 ✓

int totalHammingDistance(vector<int>& nums) {
    int n = nums.size(), total = 0;
    for (int i = 0; i < 32; i++) {
        int c = 0;
        for (int num : nums) c += (num >> i) & 1;
        total += c * (n - c);
    }
    return total;
}

通訊應用：ECC 錯誤更正碼

  • 偵測 d 個位元錯誤：碼字之間的最小漢明距離必須 ≥ d + 1
  • 更正 d 個位元錯誤：最小漢明距離必須 ≥ 2d + 1
  • Hamming(7,4) 碼最小距離為 3 → 可偵測 2 個錯誤、更正 1 個錯誤
  • DRAM 的 ECC、NAND Flash 的 BCH/LDPC 都建立在這個概念上
