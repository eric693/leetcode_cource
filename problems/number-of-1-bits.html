#191 Number of 1 Bits

Easy
Bit Manipulation Divide and Conquer

題目描述

撰寫一個函數，輸入一個無號整數（以二進位字串形式），返回其二進位表示中數字位數為 1 的個數（也被稱為漢明重量 Hamming Weight）。

這是韌體/嵌入式面試最經典的第一題，考的是你對位元運算的熟練度。

  • 輸入為 32 位元無號整數
  • 在 Java / C++ 中要特別注意有號與無號的差異

範例

範例 1：
輸入：n = 00000000000000000000000000001011
輸出：3
解釋：輸入的二進位字串中共有三位為 '1'。
範例 2：
輸入：n = 10000000000000000000000000000000
輸出：1
範例 3：
輸入：n = 11111111111111111111111111111101
輸出：31

解題思路

💡 方法一：逐位檢查（最直覺）

檢查每一位是否為 1，共檢查 32 次。

n = 1011

i=0: (n >> 0) & 1 = 1  ✓
i=1: (n >> 1) & 1 = 1  ✓
i=2: (n >> 2) & 1 = 0
i=3: (n >> 3) & 1 = 1  ✓
→ 共 3 個 1

方法二：Brian Kernighan 演算法（最重要！）

n & (n - 1) 會消掉最右邊的一個 1
原理：n-1 會把最右邊的 1 變成 0，其右邊的 0 全變成 1
     再和 n 做 AND，就正好消掉最右邊的那個 1

n     = 1011 1000
n - 1 = 1011 0111
n&(n-1)=1011 0000   ← 最右邊的 1 消失了

迴圈次數 = 1 的個數，而不是 32 次！

n = 1011
第 1 次：1011 & 1010 = 1010   count=1
第 2 次：1010 & 1001 = 1000   count=2
第 3 次：1000 & 0111 = 0000   count=3
n == 0，結束 → 答案 3

方法三：查表法（韌體常用）

⚡ 空間換時間

預先建好 0~255 的 popcount 表，一個 32 位元數只要查 4 次表。這是嵌入式系統在沒有硬體 popcount 指令時的標準做法。

程式碼實現

# 方法一：逐位檢查
class Solution:
    def hammingWeight(self, n: int) -> int:
        count = 0
        for i in range(32):
            if (n >> i) & 1:
                count += 1
        return count


# 方法二：Brian Kernighan（推薦，迴圈次數 = 1 的個數）
class Solution:
    def hammingWeight(self, n: int) -> int:
        count = 0
        while n:
            n &= n - 1      # 消掉最右邊的 1
            count += 1
        return count

// 方法三：查表法（韌體常用，空間換時間）
class Solution {
    // 0~255 每個數字的 1 的個數
    static uint8_t table[256];
public:
    int hammingWeight(uint32_t n) {
        return table[n & 0xFF] + table[(n >> 8) & 0xFF]
             + table[(n >> 16) & 0xFF] + table[(n >> 24) & 0xFF];
    }
};

// Brian Kernighan：n & (n - 1) 會清掉最低位的 1
// 時間複雜度: O(1 的個數)，空間複雜度: O(1)
function hammingWeight(n: number): number {
    let count = 0;
    while (n !== 0) {
        n &= n - 1;
        count++;
    }
    return count;
}
// Brian Kernighan：n & (n - 1) 會清掉最低位的 1
// 時間複雜度: O(1 的個數)，空間複雜度: O(1)
int hammingWeight(int n) {
    unsigned int v = (unsigned int)n;      // 轉成無號數，避免負數位移問題
    int count = 0;
    while (v) {
        v &= v - 1;
        count++;
    }
    return count;
}

複雜度分析

時間複雜度：
  • 方法一（逐位檢查）：O(32) = O(1)，固定跑 32 次
  • 方法二（Brian Kernighan）：O(k)，k 為 1 的個數，最多 32 次
  • 方法三（查表）：O(4) = O(1)
空間複雜度：
  • 方法一、二：O(1)
  • 方法三：O(256) 的查表空間

重點提示

💡 關鍵技巧 1：n & (n-1) 消最右邊的 1

這是位元運算的萬用技巧，也可用來判斷 2 的冪次方（n & (n-1) == 0）。務必背起來。

💡 關鍵技巧 2：n & (-n) 取出最右邊的 1

負數是二補數，-n = ~n + 1，所以 n & -n 剛好保留最低位的 1（lowbit），是樹狀陣列的核心。

⚠️ 常見錯誤：
  • Java 沒有 unsigned：用 n != 0 判斷，不要用 n > 0，否則負數會直接跳出
  • Java 右移要用無號右移 >>>，用 >> 會補符號位造成無限迴圈
  • C/C++ 對有號數右移是實作定義行為，請用 uint32_t

補充說明

位元運算速查表（面試必背）

📝 常用位元技巧
取得第 i 位          (n >> i) & 1
設定第 i 位為 1      n |= (1 << i)
清除第 i 位為 0      n &= ~(1 << i)
反轉第 i 位          n ^= (1 << i)
消掉最右邊的 1       n &= (n - 1)
取出最右邊的 1       n & (-n)
判斷是否為 2 的冪    n > 0 && (n & (n-1)) == 0
判斷奇偶             n & 1
乘 2 / 除 2          n << 1 / n >> 1
交換兩數（不用暫存） a ^= b; b ^= a; a ^= b;
