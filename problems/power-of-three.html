326. Power of Three
Easy

題目描述

給定一個整數 n，判斷它是否是 3 的冪次方。如果是，返回 true；否則返回 false。

整數 n 是 3 的冪次方需滿足：存在整數 x 使得 n == 3x。

範例 1:
輸入: n = 27
輸出: true
解釋: 27 = 3³
範例 2:
輸入: n = 0
輸出: false
解釋: 不存在 x 使得 3^x = 0
範例 3:
輸入: n = -1
輸出: false

解題思路

方法一：反覆整除（推薦）

先排除 n <= 0 的情況。接著只要 n 能被 3 整除就一直除以 3，最後檢查是否恰好剩下 1。

若中途出現無法整除的情形，代表 n 含有 3 以外的質因數，直接判定為 false。

方法二：利用最大 3 的冪（O(1) 無迴圈）

32 位元整數範圍內最大的 3 的冪是 3^19 = 1162261467。

因為 3 是質數，它的所有因數只有 3 的冪，所以只要 n > 0 且 1162261467 % n == 0，n 必為 3 的冪。

程式碼實現

class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        if n <= 0:
            return False
        while n % 3 == 0:
            n //= 3
        return n == 1
class Solution {
    public boolean isPowerOfThree(int n) {
        if (n <= 0) return false;
        while (n % 3 == 0) n /= 3;
        return n == 1;
    }
}

// 進階：O(1) 無迴圈解法
// return n > 0 && 1162261467 % n == 0;
// 3^19 = 1162261467 是 32 位元範圍內最大的 3 的冪，n 必須能整除它
// 時間複雜度: O(1)，空間複雜度: O(1)
function isPowerOfThree(n: number): boolean {
    return n > 0 && 1162261467 % n === 0;
}

複雜度分析

時間複雜度: O(log₃ n)

每次迴圈把 n 縮小為原本的三分之一，最多執行 log₃ n 次；常數解法為 O(1)。

空間複雜度: O(1)

只使用固定數量的變數。

重點提示

  • 先擋掉非正數：0 與負數都不是 3 的冪，漏判會讓 while 迴圈行為出錯
  • 質數性質是關鍵：3 為質數才使得「最大 3 的冪能被 n 整除」等價於「n 是 3 的冪」，此技巧不能套用在 4 的冪上
  • 與 2 的冪不同：2 的冪可用位元技巧 n & (n - 1) == 0，3 的冪沒有對應的位元捷徑
  • 魔術數字要說明：面試寫 1162261467 時務必解釋它是 3^19，也就是 int 範圍內最大的 3 的冪
