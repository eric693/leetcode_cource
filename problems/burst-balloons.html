#312 Burst Balloons

Hard
Array Dynamic Programming Divide and Conquer

題目描述

有 n 個氣球，編號為 0 到 n-1，每個氣球上都標有一個數字，這些數字存在陣列 nums 中。

現在要求你戳破所有的氣球。戳破第 i 個氣球，你可以獲得 nums[i-1] × nums[i] × nums[i+1] 枚硬幣。

規則：

  • 如果 i-1 或 i+1 超出了陣列的邊界，那麼就當它是一個數字為 1 的氣球
  • 戳破氣球 i 後，氣球 i-1 和 i+1 變成相鄰的氣球

求所能獲得硬幣的最大數量。

範例

範例 1：
輸入：nums = [3,1,5,8]

輸出：167

解釋：
nums = [3, 1, 5, 8] → [3, 5, 8] → [3, 8] → [8] → []
       戳破 1        戳破 5        戳破 3     戳破 8
coins = 3×1×5    + 3×5×8    + 1×3×8   + 1×8×1
      = 15       + 120      + 24      + 8
      = 167
範例 2：
輸入：nums = [1,5]
輸出：10

解題思路

核心概念：反向思考 + 區間 DP

關鍵洞察：不要想「先戳哪個」，而要想「最後戳哪個」！

  1. 假設最後戳破的是第 k 個氣球
  2. 那麼此時左右兩側的氣球都已經被戳破了
  3. 戳破 k 時，左右鄰居就是區間的邊界
  4. 得分 = 左邊界 × nums[k] × 右邊界

為什麼正向思考很難？

正向思考的困境
問題：戳破一個氣球後，陣列會改變

nums = [3, 1, 5, 8]

如果先戳 1:
→ nums 變成 [3, 5, 8]
→ 索引全部改變，很難定義子問題

子問題難以定義：
戳破氣球的順序會影響後續的選擇
無法獨立求解子問題

反向思考的妙處

反向思考 = 最後戳破
思路轉換：
不考慮「第一個戳哪個」
而考慮「最後一個戳哪個」

優勢：
假設 k 是區間 [i, j] 中最後被戳破的氣球
→ 戳破 k 時，[i, k-1] 和 [k+1, j] 都已經被戳破
→ k 的左右鄰居就是 i-1 和 j+1
→ 得分 = nums[i-1] × nums[k] × nums[j+1]

子問題獨立：
左邊區間 [i, k-1] 的最優解
右邊區間 [k+1, j] 的最優解
這兩個子問題互不影響！

DP 狀態定義

狀態轉移方程
狀態定義：
dp[i][j] = 戳破開區間 (i, j) 內所有氣球的最大硬幣數
           （不包括 i 和 j 本身）

邊界處理：
在陣列兩端添加虛擬氣球 1
nums = [1] + nums + [1]

狀態轉移：
假設 k 是 (i, j) 中最後被戳破的氣球

dp[i][j] = max(
    dp[i][k] + dp[k][j] + nums[i] × nums[k] × nums[j]
)
其中 k 從 i+1 到 j-1

解釋：
- dp[i][k]：左側子區間的最優解
- dp[k][j]：右側子區間的最優解
- nums[i] × nums[k] × nums[j]：最後戳破 k 的得分

詳細範例演示

完整 DP 過程：nums = [3,1,5,8]
添加虛擬邊界：
nums = [1, 3, 1, 5, 8, 1]
索引:   0  1  2  3  4  5

初始化：
長度為 1 的區間都是 0（沒有氣球可戳）

計算長度為 2 的區間：
(0,2): k=1, dp[0][2] = 1×3×1 = 3
(1,3): k=2, dp[1][3] = 3×1×5 = 15
(2,4): k=3, dp[2][4] = 1×5×8 = 40
(3,5): k=4, dp[3][5] = 5×8×1 = 40

計算長度為 3 的區間：
(0,3): 
  k=1: dp[0][1] + dp[1][3] + 1×3×5 = 0 + 15 + 15 = 30
  k=2: dp[0][2] + dp[2][3] + 1×1×5 = 3 + 0 + 5 = 8
  → dp[0][3] = 30

(1,4):
  k=2: dp[1][2] + dp[2][4] + 3×1×8 = 0 + 40 + 24 = 64
  k=3: dp[1][3] + dp[3][4] + 3×5×8 = 15 + 0 + 120 = 135
  → dp[1][4] = 135

(2,5):
  k=3: dp[2][3] + dp[3][5] + 1×5×1 = 0 + 40 + 5 = 45
  k=4: dp[2][4] + dp[4][5] + 1×8×1 = 40 + 0 + 8 = 48
  → dp[2][5] = 48

計算長度為 4 的區間：
(0,4):
  k=1: 0 + 135 + 1×3×8 = 159
  k=2: 3 + 40 + 1×1×8 = 51
  k=3: 30 + 0 + 1×5×8 = 70
  → dp[0][4] = 159

(1,5):
  k=2: 0 + 48 + 3×1×1 = 51
  k=3: 15 + 40 + 3×5×1 = 70
  k=4: 135 + 0 + 3×8×1 = 159
  → dp[1][5] = 159

最終答案 (0,5)：
  k=1: 0 + 159 + 1×3×1 = 162
  k=2: 3 + 48 + 1×1×1 = 52
  k=3: 30 + 40 + 1×5×1 = 75
  k=4: 159 + 0 + 1×8×1 = 167 ✓
  → dp[0][5] = 167

程式碼實現

# 方法一：區間 DP（標準解法）
class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        # 添加虛擬邊界
        nums = [1] + nums + [1]
        n = len(nums)
        
        # dp[i][j] 表示戳破開區間 (i, j) 內所有氣球的最大硬幣數
        dp = [[0] * n for _ in range(n)]
        
        # 按區間長度從小到大遍歷
        for length in range(2, n):  # 長度從 2 開始
            for i in range(n - length):
                j = i + length
                # 嘗試最後戳破 k
                for k in range(i + 1, j):
                    # 戳破 k 的得分 + 左右子區間的最優解
                    coins = nums[i] * nums[k] * nums[j]
                    dp[i][j] = max(dp[i][j], 
                                   dp[i][k] + dp[k][j] + coins)
        
        # 返回整個區間的答案
        return dp[0][n - 1]


# 方法二：記憶化遞迴
class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        nums = [1] + nums + [1]
        memo = {}
        
        def dp(i, j):
            # 基礎情況：區間內沒有氣球
            if i + 1 == j:
                return 0
            
            # 記憶化
            if (i, j) in memo:
                return memo[(i, j)]
            
            max_coins = 0
            # 嘗試最後戳破 k
            for k in range(i + 1, j):
                coins = nums[i] * nums[k] * nums[j]
                total = dp(i, k) + dp(k, j) + coins
                max_coins = max(max_coins, total)
            
            memo[(i, j)] = max_coins
            return max_coins
        
        return dp(0, len(nums) - 1)


# 方法三：詳細註解版本
class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        """
        區間 DP 經典題目
        
        核心思想：反向思考
        不考慮先戳哪個，而考慮最後戳哪個
        """
        # 添加虛擬邊界 1，簡化邊界處理
        nums = [1] + nums + [1]
        n = len(nums)
        
        # dp[i][j] = 戳破開區間 (i, j) 內所有氣球能獲得的最大硬幣
        # 開區間意味著不包括 i 和 j
        dp = [[0] * n for _ in range(n)]
        
        # 按區間長度遞增順序填表
        # 長度為 1 的區間（相鄰氣球）不用計算，默認為 0
        for length in range(2, n):
            # 枚舉所有長度為 length 的區間
            for i in range(n - length):
                j = i + length
                
                # 在區間 (i, j) 中，嘗試每個位置作為最後戳破的氣球
                for k in range(i + 1, j):
                    # 假設 k 是最後被戳破的
                    # 此時 (i, k) 和 (k, j) 內的氣球都已經被戳破
                    # k 的左右鄰居就是 i 和 j
                    
                    # 戳破 k 獲得的硬幣
                    coins = nums[i] * nums[k] * nums[j]
                    
                    # 總硬幣 = 左子區間 + 右子區間 + 戳破 k
                    total = dp[i][k] + dp[k][j] + coins
                    
                    # 取最大值
                    dp[i][j] = max(dp[i][j], total)
        
        # 答案是戳破開區間 (0, n-1) 內所有氣球
        # 也就是原陣列的所有氣球
        return dp[0][n - 1]

class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;
        // 添加虛擬邊界
        int[] newNums = new int[n + 2];
        newNums[0] = 1;
        newNums[n + 1] = 1;
        for (int i = 0; i < n; i++) {
            newNums[i + 1] = nums[i];
        }
        
        int len = newNums.length;
        int[][] dp = new int[len][len];
        
        // 按區間長度遞增
        for (int length = 2; length < len; length++) {
            for (int i = 0; i < len - length; i++) {
                int j = i + length;
                // 嘗試最後戳破 k
                for (int k = i + 1; k < j; k++) {
                    int coins = newNums[i] * newNums[k] * newNums[j];
                    dp[i][j] = Math.max(dp[i][j], 
                                        dp[i][k] + dp[k][j] + coins);
                }
            }
        }
        
        return dp[0][len - 1];
    }
}

// 區間 DP：dp[i][j] = 開區間 (i, j) 內氣球全戳破的最大分數，k 為最後戳破的氣球
// 時間複雜度: O(n³)，空間複雜度: O(n²)
function maxCoins(nums: number[]): number {
    const vals = [1, ...nums, 1];                 // 兩端補 1
    const n = vals.length;
    const dp: number[][] = Array.from({ length: n }, () => new Array(n).fill(0));

    for (let len = 2; len < n; len++) {           // 區間長度
        for (let i = 0; i + len < n; i++) {
            const j = i + len;
            for (let k = i + 1; k < j; k++) {
                dp[i][j] = Math.max(dp[i][j], dp[i][k] + dp[k][j] + vals[i] * vals[k] * vals[j]);
            }
        }
    }
    return dp[0][n - 1];
}
// 區間 DP：dp[i][j] = 開區間 (i, j) 內氣球全戳破的最大分數，k 為最後戳破的氣球
// 時間複雜度: O(n³)，空間複雜度: O(n²)
int maxCoins(int* nums, int numsSize) {
    int n = numsSize + 2;
    int* vals = malloc(sizeof(int) * n);
    vals[0] = vals[n - 1] = 1;                     // 兩端補 1
    for (int i = 0; i < numsSize; i++) vals[i + 1] = nums[i];

    int* dp = calloc(n * n, sizeof(int));          // dp[i][j] = dp[i * n + j]
    for (int len = 2; len < n; len++) {
        for (int i = 0; i + len < n; i++) {
            int j = i + len;
            for (int k = i + 1; k < j; k++) {
                int v = dp[i * n + k] + dp[k * n + j] + vals[i] * vals[k] * vals[j];
                if (v > dp[i * n + j]) dp[i * n + j] = v;
            }
        }
    }
    int ans = dp[n - 1];
    free(vals);
    free(dp);
    return ans;
}

複雜度分析

時間複雜度：O(n³)
  • 三層循環：區間長度 O(n) × 起點 O(n) × 分割點 O(n)
空間複雜度：O(n²)
  • DP 表格：O(n²)
  • 記憶化遞迴版本需要 O(n) 遞迴棧空間

重點提示

關鍵技巧 1：反向思考

不想「先戳哪個」，而想「最後戳哪個」，化難為易！

關鍵技巧 2：虛擬邊界

添加 [1, ..., 1] 簡化邊界處理，統一計算公式。

關鍵技巧 3：開區間定義

dp[i][j] 是開區間 (i, j)，不包括 i 和 j 本身。

常見錯誤：
  • 忘記添加虛擬邊界，導致邊界判斷複雜
  • 循環順序錯誤（必須先小區間再大區間）
  • 混淆開區間和閉區間的定義
  • k 的範圍錯誤（應該是 i+1 到 j-1）
為什麼要反向思考？
正向困境：
先戳哪個？戳完後陣列改變，子問題難定義

反向妙處：
最後戳哪個？戳之前左右都已經清空，子問題獨立

類比：
這就像拆房子和蓋房子
- 拆房子（正向）：先拆哪塊？順序影響結構
- 蓋房子（反向）：最後蓋哪塊？之前的都已蓋好

反向思考讓問題具有「最優子結構」！
