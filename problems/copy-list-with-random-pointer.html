#138 Copy List with Random Pointer

Medium
Linked List Hash Table

題目描述

給你一個長度為 n 的鏈結串列，每個節點包含一個額外增加的隨機指標 random，該指標可以指向串列中的任何節點或空節點。

請你構造這個串列的深拷貝（deep copy）。深拷貝應該由 n 個全新節點組成，其中每個新節點的值都設為其對應原節點的值，且新串列中的指標都應指向新串列中的節點，不能指向原串列的任何節點。

範例

範例 1：
輸入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
輸出：[[7,null],[13,0],[11,4],[10,2],[1,0]]
解釋：每組 [val, random_index] 表示節點值與 random 指向的索引。
範例 2：
輸入：head = [[1,1],[2,1]]
輸出：[[1,1],[2,1]]

解題思路

⚠️ 難點在哪？

複製 next 很簡單（順序走一遍就好），但 random 可能指向還沒被建立的節點。所以核心問題是：如何把「原節點」對應到「新節點」？

方法一：HashMap 建立對應關係（好懂，面試首選）

💡 兩趟掃描
第一趟：只複製節點的值，建立 map[原節點] = 新節點
第二趟：利用 map 把 next 和 random 接起來
        new.next   = map[old.next]
        new.random = map[old.random]

原串列：  A → B → C
          A.random → C
          B.random → A

第一趟建立 map：
  {A: A', B: B', C: C'}

第二趟接指標：
  A'.next = map[B] = B'
  A'.random = map[C] = C' ✓
  B'.next = map[C] = C'
  B'.random = map[A] = A' ✓

因為所有新節點都已存在，random 指到哪裡都查得到 ✓

方法二：節點交錯編織（O(1) 額外空間，最巧妙）

🎯 把新節點插在原節點後面
步驟 1：在每個原節點後面插入它的複製節點
  原：A → B → C
  後：A → A' → B → B' → C → C'

步驟 2：設定 random（關鍵！）
  對每個原節點 cur：
      cur.next.random = cur.random.next
  意思是「A' 的 random」= 「A 的 random 的下一個」
        = 「A 的 random 對應的新節點」✓

  A.random = C  →  A'.random = C.next = C' ✓

  這一步不需要 HashMap，因為「新節點就緊跟在對應原節點後面」，
  這個位置關係本身就是一張隱形的對照表！

步驟 3：拆分成兩條串列，還原原串列
  A → B → C  和  A' → B' → C'

程式碼實現

# Definition for a Node.
# class Node:
#     def __init__(self, x: int, next: 'Node' = None, random: 'Node' = None):
#         self.val = int(x)
#         self.next = next
#         self.random = random

# 方法一：HashMap（推薦，好懂好寫）
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None

        # 第一趟：建立 原節點 -> 新節點 的對應
        old_to_new = {}
        cur = head
        while cur:
            old_to_new[cur] = Node(cur.val)
            cur = cur.next

        # 第二趟：接上 next 和 random
        cur = head
        while cur:
            old_to_new[cur].next = old_to_new.get(cur.next)
            old_to_new[cur].random = old_to_new.get(cur.random)
            cur = cur.next

        return old_to_new[head]


# 方法二：節點交錯編織（O(1) 額外空間）
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None

        # 步驟 1：A → A' → B → B' → ...
        cur = head
        while cur:
            copy = Node(cur.val, cur.next)
            cur.next = copy
            cur = copy.next

        # 步驟 2：設定新節點的 random
        cur = head
        while cur:
            if cur.random:
                cur.next.random = cur.random.next
            cur = cur.next.next

        # 步驟 3：拆分兩條串列，還原原串列
        new_head = head.next
        cur = head
        while cur:
            copy = cur.next
            cur.next = copy.next
            copy.next = copy.next.next if copy.next else None
            cur = cur.next
        return new_head
// 方法一：HashMap（推薦）
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;
        unordered_map<Node*, Node*> oldToNew;

        // 第一趟：只複製值
        for (Node* cur = head; cur; cur = cur->next) {
            oldToNew[cur] = new Node(cur->val);
        }

        // 第二趟：接 next 和 random
        for (Node* cur = head; cur; cur = cur->next) {
            oldToNew[cur]->next   = oldToNew[cur->next];    // 不存在時為 nullptr
            oldToNew[cur]->random = oldToNew[cur->random];
        }
        return oldToNew[head];
    }
};

// 方法二：節點交錯編織（O(1) 額外空間）
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;

        // 步驟 1：A → A' → B → B'
        for (Node* cur = head; cur; ) {
            Node* copy = new Node(cur->val);
            copy->next = cur->next;
            cur->next = copy;
            cur = copy->next;
        }

        // 步驟 2：設定 random
        for (Node* cur = head; cur; cur = cur->next->next) {
            if (cur->random) cur->next->random = cur->random->next;
        }

        // 步驟 3：拆分
        Node* newHead = head->next;
        for (Node* cur = head; cur; ) {
            Node* copy = cur->next;
            cur->next = copy->next;
            copy->next = cur->next ? cur->next->next : nullptr;
            cur = cur->next;
        }
        return newHead;
    }
};
// 方法一：HashMap（推薦）
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;
        Map<Node, Node> oldToNew = new HashMap<>();

        // 第一趟：只複製值
        for (Node cur = head; cur != null; cur = cur.next) {
            oldToNew.put(cur, new Node(cur.val));
        }

        // 第二趟：接 next 和 random
        for (Node cur = head; cur != null; cur = cur.next) {
            oldToNew.get(cur).next   = oldToNew.get(cur.next);
            oldToNew.get(cur).random = oldToNew.get(cur.random);
        }
        return oldToNew.get(head);
    }
}

// 方法二：節點交錯編織
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;

        // 步驟 1：交錯插入
        for (Node cur = head; cur != null; ) {
            Node copy = new Node(cur.val);
            copy.next = cur.next;
            cur.next = copy;
            cur = copy.next;
        }

        // 步驟 2：設定 random
        for (Node cur = head; cur != null; cur = cur.next.next) {
            if (cur.random != null) cur.next.random = cur.random.next;
        }

        // 步驟 3：拆分
        Node newHead = head.next;
        for (Node cur = head; cur != null; ) {
            Node copy = cur.next;
            cur.next = copy.next;
            copy.next = (cur.next != null) ? cur.next.next : null;
            cur = cur.next;
        }
        return newHead;
    }
}
/**
 * Definition for _Node.
 * class _Node {
 *     val: number
 *     next: _Node | null
 *     random: _Node | null
 * }
 */
// 雜湊表：第一輪建立所有複製節點，第二輪接上 next 與 random
// 時間複雜度: O(n)，空間複雜度: O(n)
function copyRandomList(head: _Node | null): _Node | null {
    const map = new Map<_Node, _Node>();
    for (let cur = head; cur; cur = cur.next) {
        map.set(cur, new _Node(cur.val));
    }
    for (let cur = head; cur; cur = cur.next) {
        const copy = map.get(cur)!;
        copy.next = cur.next ? map.get(cur.next)! : null;
        copy.random = cur.random ? map.get(cur.random)! : null;
    }
    return head ? map.get(head)! : null;
}
/**
 * Definition for a Node.
 * struct Node {
 *     int val;
 *     struct Node *next;
 *     struct Node *random;
 * };
 */
// 交錯節點法：A → A' → B → B'，不需要雜湊表
// 時間複雜度: O(n)，空間複雜度: O(1)（不含輸出）
struct Node* copyRandomList(struct Node* head) {
    if (!head) return NULL;

    // 1. 在每個節點後面插入它的複製節點
    for (struct Node* cur = head; cur; cur = cur->next->next) {
        struct Node* copy = malloc(sizeof(struct Node));
        copy->val = cur->val;
        copy->next = cur->next;
        copy->random = NULL;
        cur->next = copy;
    }
    // 2. 複製節點的 random = 原節點 random 的下一個
    for (struct Node* cur = head; cur; cur = cur->next->next) {
        if (cur->random) cur->next->random = cur->random->next;
    }
    // 3. 拆開兩條鏈結串列，還原原串列
    struct Node* newHead = head->next;
    for (struct Node* cur = head; cur; cur = cur->next) {
        struct Node* copy = cur->next;
        cur->next = copy->next;
        copy->next = copy->next ? copy->next->next : NULL;
    }
    return newHead;
}

複雜度分析

時間複雜度：O(n)
  • 方法一：兩趟掃描 + HashMap 平均 O(1) 查詢
  • 方法二：三趟掃描，常數較大但沒有雜湊開銷
空間複雜度：
  • 方法一：O(n) 的 HashMap
  • 方法二：O(1) 額外空間 ★（不計算輸出的新串列）

重點提示

💡 關鍵技巧 1：先建節點，再接指標

「指標指向尚未建立的物件」是深拷貝的通病。解法一律是兩階段：先把所有物件都建出來，第二趟再連線。這在複製圖（#133 Clone Graph）、序列化反序列化中都是同樣套路。

💡 關鍵技巧 2：交錯編織 = 隱形的對照表

cur.next 就是 cur 的複製品，這個位置關係取代了 HashMap。想到這一層就能把空間降到 O(1)，是本題最漂亮的地方。

⚠️ 常見錯誤：
  • random 為 null 時沒判斷，直接 cur.random.next 造成崩潰
  • 方法二忘記還原原串列（題目要求原串列不能被破壞）
  • 拆分時最後一個節點的 next 沒設為 null
  • Java/C++ 用 map[cur->next] 時，若 key 不存在會自動插入 nullptr —— 這裡剛好是我們要的行為，但要理解為什麼

補充說明

延伸：深拷貝 vs 淺拷貝

🔍 兩者的差別
淺拷貝（shallow copy）：
  只複製物件本身，內部的指標/參考仍指向原物件
  → 修改複製品會影響原物件

深拷貝（deep copy）：
  遞迴複製所有被參考到的物件
  → 兩者完全獨立

C++ 中若類別有指標成員卻沒有自訂拷貝建構子，
預設的成員逐一複製就是淺拷貝，會導致：
  - 兩個物件指向同一塊記憶體
  - double free 崩潰

這就是「三/五法則（Rule of Three/Five）」的由來：
若你需要自訂解構子，通常也需要自訂拷貝建構子與拷貝賦值運算子。

class Solution:
    def __init__(self):
        self.visited = {}

    def copyRandomList(self, head):
        if not head:
            return None
        if head in self.visited:      # 已複製過，直接回傳（處理環與重複參考）
            return self.visited[head]

        copy = Node(head.val)
        self.visited[head] = copy      # 先登記再遞迴，避免無限迴圈
        copy.next = self.copyRandomList(head.next)
        copy.random = self.copyRandomList(head.random)
        return copy
