#19 Remove Nth Node From End of List

Medium
Linked List Two Pointers

題目描述

給你一個鏈結串列，刪除串列的倒數第 n 個節點，並且返回串列的頭節點。

進階：你能嘗試使用一趟掃描實現嗎？

範例

範例 1：
輸入：head = [1,2,3,4,5], n = 2
輸出：[1,2,3,5]
解釋：倒數第 2 個是 4，刪除它。
範例 2：
輸入：head = [1], n = 1
輸出：[]
範例 3：
輸入：head = [1,2], n = 1
輸出：[1]

解題思路

💡 核心：快慢指標保持 n 的間距
讓 fast 先走 n + 1 步，然後 fast 和 slow 一起走。
當 fast 走到 null 時，slow 剛好停在「要刪除節點的前一個」。

list = [1,2,3,4,5], n = 2（要刪 4）

dummy → 1 → 2 → 3 → 4 → 5 → null
  ↑
slow/fast

fast 先走 3 步（n+1 = 3）：
dummy → 1 → 2 → 3 → 4 → 5 → null
  ↑              ↑
slow           fast

一起走，直到 fast == null：
dummy → 1 → 2 → 3 → 4 → 5 → null
              ↑              ↑
            slow           fast

slow.next = 4，正是要刪的節點
slow.next = slow.next.next → 跳過 4 ✓

為什麼要用 dummy 節點？

統一處理「刪除頭節點」的情況
list = [1], n = 1 → 要刪的正是頭節點

沒有 dummy：slow 無法停在「頭節點的前一個」，
            必須特判 return head.next

有 dummy： dummy → 1 → null
          slow 停在 dummy，slow.next = head，
          直接刪除，程式碼零特判 ✓

最後永遠 return dummy.next（不是 return head，
因為 head 可能已被刪掉）

💡 通用原則：任何「可能刪除或修改頭節點」的鏈結串列題，
   第一件事就是建 dummy 節點。

為什麼是 n + 1 步而不是 n 步？

因為要刪除節點必須拿到它的前一個節點。走 n 步的話 slow 會停在待刪節點本身，就接不上前面了。

程式碼實現

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

# 一趟掃描：快慢指標（推薦）
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)      # 虛擬頭節點，避免特判刪除頭節點
        slow = fast = dummy

        # fast 先走 n + 1 步
        for _ in range(n + 1):
            fast = fast.next

        # 一起走到底，slow 停在待刪節點的前一個
        while fast:
            slow = slow.next
            fast = fast.next

        slow.next = slow.next.next     # 刪除
        return dummy.next


# 兩趟掃描：先算長度（較直覺）
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        length = 0
        node = head
        while node:
            length += 1
            node = node.next

        # 倒數第 n 個 = 正數第 (length - n + 1) 個
        prev = dummy
        for _ in range(length - n):
            prev = prev.next
        prev.next = prev.next.next
        return dummy.next
/**
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(nullptr) {}
 * };
 */

// 一趟掃描：快慢指標（推薦）
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);       // 虛擬頭節點
        ListNode *slow = &dummy, *fast = &dummy;

        // fast 先走 n + 1 步
        for (int i = 0; i <= n; i++) {
            fast = fast->next;
        }

        // 一起走到底
        while (fast) {
            slow = slow->next;
            fast = fast->next;
        }

        ListNode* toDelete = slow->next;
        slow->next = slow->next->next;
        delete toDelete;               // C++ 記得釋放記憶體
        return dummy.next;
    }
};
/**
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */

// 一趟掃描：快慢指標（推薦）
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);   // 虛擬頭節點
        ListNode slow = dummy, fast = dummy;

        // fast 先走 n + 1 步
        for (int i = 0; i <= n; i++) {
            fast = fast.next;
        }

        // 一起走到底，slow 停在待刪節點的前一個
        while (fast != null) {
            slow = slow.next;
            fast = fast.next;
        }

        slow.next = slow.next.next;
        return dummy.next;
    }
}
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     val: number
 *     next: ListNode | null
 * }
 */
// 前後指針：fast 先走 n+1 步，兩者同步前進，fast 到底時 slow 在目標前一個
// 時間複雜度: O(n)，空間複雜度: O(1)
function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
    const dummy = new ListNode(0, head);
    let fast: ListNode | null = dummy, slow: ListNode = dummy;
    for (let i = 0; i <= n; i++) fast = fast!.next;
    while (fast) {
        fast = fast.next;
        slow = slow.next!;
    }
    slow.next = slow.next!.next;
    return dummy.next;
}
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
// 前後指針：fast 先走 n+1 步，兩者同步前進，fast 到底時 slow 在目標前一個
// 時間複雜度: O(n)，空間複雜度: O(1)
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    struct ListNode dummy = {0, head};
    struct ListNode *fast = &dummy, *slow = &dummy;
    for (int i = 0; i <= n; i++) fast = fast->next;
    while (fast) {
        fast = fast->next;
        slow = slow->next;
    }
    struct ListNode* target = slow->next;
    slow->next = target->next;
    free(target);
    return dummy.next;
}

複雜度分析

時間複雜度：O(L)，L 為串列長度
  • 快慢指標版本只掃描一趟
  • 兩趟版本是 O(2L)，同樣是 O(L)
空間複雜度：O(1)，只用了固定數量的指標

重點提示

💡 關鍵技巧 1：dummy 節點

鏈結串列題目只要「頭節點可能被刪除或改變」，就建一個 dummy，可以消除大量邊界判斷。最後 return dummy.next。

💡 關鍵技巧 2：固定間距的雙指標

「倒數第 k 個」類型的問題，都可以用「讓一個指標先走 k 步」把倒數轉成正數，一趟掃描搞定。

⚠️ 常見錯誤：
  • fast 走 n 步而不是 n + 1 步，導致 slow 停在待刪節點本身
  • 沒用 dummy，忘記處理「刪除頭節點」的情況
  • 最後 return head 而不是 return dummy.next（head 可能已被刪）
  • C++ 沒有 delete 被刪的節點造成記憶體洩漏

補充說明

鏈結串列雙指標模板總整理

📝 四種常見的快慢指標配置
【固定間距 k】倒數第 k 個節點
  fast 先走 k 步，再一起走

【速度 1:2】找中點
  while (fast && fast->next) { slow=slow->next; fast=fast->next->next; }
  偶數長度時 slow 停在後半段第一個

【速度 1:2】判斷有環
  相遇即有環；再從 head 和相遇點同速走，會在入口相遇（Floyd）

【兩串列同步】找交點
  走完自己的走對方的，兩指標走過的總長度相同必定相遇

邊界情況檢查清單

  • 串列只有一個節點，n = 1 → 返回空串列
  • 刪除的是頭節點（n == 串列長度）→ dummy 自動處理
  • 刪除的是尾節點（n == 1）→ slow 停在倒數第二個，正確
  • 題目保證 1 ≤ n ≤ 串列長度，所以不需要處理 n 越界
