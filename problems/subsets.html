#78 Subsets

Medium
Backtracking Bit Manipulation Array

題目描述

給你一個整數陣列 nums，陣列中的元素互不相同。返回該陣列所有可能的子集（冪集）。

解集不能包含重複的子集。你可以按任意順序返回解集。

n 個元素的子集共有 2n 個（每個元素都有「選」或「不選」兩種可能）。

範例

範例 1：
輸入：nums = [1,2,3]
輸出：[[],[1],[2],[3],[1,2],[1,3],[2,3],[1,2,3]]
解釋：共 2³ = 8 個子集，包含空集。
範例 2：
輸入：nums = [0]
輸出：[[],[0]]

解題思路

💡 方法一：回溯（每個節點都是答案）
與排列不同：子集問題中，決策樹的【每一個節點】都是一個答案，
不只有葉子節點。

nums = [1,2,3]

                []            ← 也是答案！
        /       |       \
      [1]      [2]      [3]   ← 都是答案
     /   \      |
  [1,2] [1,3] [2,3]           ← 都是答案
    |
 [1,2,3]                      ← 也是答案

共 8 個節點 = 8 個子集 ✓

⭐ 用 start 參數控制：每層只能選 start 之後的元素，
   避免產生 [1,2] 和 [2,1] 這種重複的組合。

方法二：位元遮罩（非常優雅）

🎯 用 0 ~ 2ⁿ-1 的二進位表示「選或不選」
n = 3，用 3 位元表示每個元素選不選：

mask  二進位  選中的元素   子集
0     000     -            []
1     001     nums[0]      [1]
2     010     nums[1]      [2]
3     011     nums[0,1]    [1,2]
4     100     nums[2]      [3]
5     101     nums[0,2]    [1,3]
6     110     nums[1,2]    [2,3]
7     111     nums[0,1,2]  [1,2,3]

實作：
for (int mask = 0; mask < (1 << n); mask++) {
    vector subset;
    for (int i = 0; i < n; i++) {
        if (mask & (1 << i)) subset.push_back(nums[i]);
    }
    result.push_back(subset);
}

沒有遞迴，程式碼極短，而且不會 stack overflow。

方法三：迭代擴展（最直覺）

🔄 每加入一個元素，答案數量翻倍
result = [[]]

加入 1：把現有的每個子集都複製一份並加上 1
  [[]] → [[], [1]]

加入 2：
  [[], [1]] → [[], [1], [2], [1,2]]

加入 3：
  → [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]] ✓

每一輪答案數量剛好翻倍，最後是 2ⁿ 個。
這個做法直接體現了「冪集」的遞迴定義。

程式碼實現

# 方法一：回溯（推薦，可擴充到 #90 等變形）
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        result = []
        path = []

        def backtrack(start):
            result.append(path[:])       # 每個節點都是答案！

            for i in range(start, len(nums)):
                path.append(nums[i])     # 做選擇
                backtrack(i + 1)         # 下一層只能選 i 之後的
                path.pop()               # 撤銷選擇

        backtrack(0)
        return result


# 方法二：位元遮罩
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        result = []
        for mask in range(1 << n):       # 0 ~ 2^n - 1
            subset = [nums[i] for i in range(n) if mask & (1 << i)]
            result.append(subset)
        return result


# 方法三：迭代擴展
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        result = [[]]
        for num in nums:
            # 把現有每個子集複製一份並加上 num
            result += [subset + [num] for subset in result]
        return result

class Solution {
    vector<vector<int>> result;
    vector<int> path;

    void backtrack(vector<int>& nums, int start) {
        result.push_back(path);          // 每個節點都是答案

        for (int i = start; i < nums.size(); i++) {
            path.push_back(nums[i]);     // 做選擇
            backtrack(nums, i + 1);      // 只能選 i 之後的
            path.pop_back();             // 撤銷選擇
        }
    }

public:
    vector<vector<int>> subsets(vector<int>& nums) {
        backtrack(nums, 0);
        return result;
    }
};

// 方法一：回溯（推薦）
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();

    public List<List<Integer>> subsets(int[] nums) {
        backtrack(nums, 0);
        return result;
    }

    private void backtrack(int[] nums, int start) {
        result.add(new ArrayList<>(path));    // 每個節點都是答案

        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);                // 做選擇
            backtrack(nums, i + 1);           // 只能選 i 之後的
            path.remove(path.size() - 1);     // 撤銷選擇
        }
    }
}

// 方法三：迭代擴展
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        result.add(new ArrayList<>());
        for (int num : nums) {
            int size = result.size();
            for (int i = 0; i < size; i++) {
                List<Integer> newSubset = new ArrayList<>(result.get(i));
                newSubset.add(num);
                result.add(newSubset);
            }
        }
        return result;
    }
}
// 回溯：每走到一個節點就記錄一次目前路徑
// 時間複雜度: O(n · 2^n)，空間複雜度: O(n)
function subsets(nums: number[]): number[][] {
    const result: number[][] = [];
    const path: number[] = [];
    const backtrack = (start: number): void => {
        result.push([...path]);
        for (let i = start; i < nums.length; i++) {
            path.push(nums[i]);
            backtrack(i + 1);
            path.pop();
        }
    };
    backtrack(0);
    return result;
}
// 位元列舉：mask 的第 i 位為 1 代表選 nums[i]（n ≤ 10）
// 時間複雜度: O(n · 2^n)，空間複雜度: O(1)（不含輸出）
int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes) {
    int total = 1 << numsSize;
    int** result = malloc(sizeof(int*) * total);
    *returnColumnSizes = malloc(sizeof(int) * total);

    for (int mask = 0; mask < total; mask++) {
        int* subset = malloc(sizeof(int) * (numsSize ? numsSize : 1));
        int len = 0;
        for (int i = 0; i < numsSize; i++) {
            if (mask & (1 << i)) subset[len++] = nums[i];
        }
        result[mask] = subset;
        (*returnColumnSizes)[mask] = len;
    }
    *returnSize = total;
    return result;
}

複雜度分析

時間複雜度：O(n × 2ⁿ)
  • 共有 2ⁿ 個子集
  • 每個子集的建立/複製需要 O(n)
  • 這是輸出規模的下界，無法優化
空間複雜度：O(n)
  • 遞迴堆疊 + path，不計輸出的 O(n × 2ⁿ)
  • 位元遮罩版本沒有遞迴，空間更省

重點提示

💡 關鍵技巧 1：子集題「每個節點都收集答案」

和排列/組合不同，子集不需要等到葉子節點。result.add(path) 放在函數開頭而不是終止條件裡，這是本題與 #46 最大的結構差異。

💡 關鍵技巧 2：start 參數保證不重複

下一層從 i + 1 開始，確保每個元素最多被選一次且順序固定，自然就不會產生 [1,2] 和 [2,1] 這種重複。若允許重複選同一個元素（#39），則傳 i 而非 i + 1。

💡 位元遮罩的實務價值

當 n ≤ 20 左右時，「列舉所有子集」是狀態壓縮 DP 的基礎。位元遮罩表示集合的技巧在旅行商問題（TSP）、集合覆蓋等問題中極為重要。

⚠️ 常見錯誤：
  • 記錄結果時沒有複製 path（同 #46 的經典錯誤）
  • 把 result.add(path) 放在終止條件裡，只會得到完整集合
  • 遞迴傳 start 而非 i + 1，造成無限遞迴或重複
  • 忘記空集也是一個合法的子集

補充說明

#90 Subsets II：含重複元素

🎯 排序 + 同層去重
nums = [1,2,2]

先【排序】讓相同元素相鄰，然後加上剪枝：

for (int i = start; i < nums.size(); i++) {
    if (i > start && nums[i] == nums[i-1]) continue;  // ← 同層去重
    ...
}

⚠️ 條件是 i > start 而不是 i > 0，差別在於：
   i > start  → 只跳過【同一層】中重複的分支
   i > 0      → 會誤跳掉【不同層】的合法選擇（如 [2,2]）

結果：[[], [1], [1,2], [1,2,2], [2], [2,2]]
      不會出現兩個 [2] 或兩個 [1,2] ✓

位元遮罩的常用操作

集合操作              位元運算
------------------------------------------
空集                  0
全集（n 個元素）      (1 << n) - 1
加入元素 i            mask | (1 << i)
移除元素 i            mask & ~(1 << i)
判斷是否含元素 i      mask & (1 << i)
集合大小              __builtin_popcount(mask)
聯集 A ∪ B            a | b
交集 A ∩ B            a & b
差集 A \ B            a & ~b
補集                  mask ^ ((1 << n) - 1)

【列舉 mask 的所有子集】（很實用的技巧）
for (int sub = mask; sub; sub = (sub - 1) & mask) {
    // sub 是 mask 的一個非空子集
}
總複雜度 O(3ⁿ) 而非 O(4ⁿ)，是狀態壓縮 DP 的關鍵優化。

子集、組合、排列的數量對照

  • 子集：2ⁿ 個（每個元素選或不選）
  • 從 n 選 k 的組合：C(n,k) = n! / (k!(n-k)!)
  • 全排列：n! 個
  • 從 n 選 k 的排列：P(n,k) = n! / (n-k)!

注意 Σ C(n,k) for k=0..n = 2ⁿ，也就是「所有大小的組合加總 = 所有子集」，這是二項式定理的直接推論。
