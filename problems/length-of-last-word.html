58. Length of Last Word
Easy

題目描述

給定一個字串 s，由若干單詞組成，單詞之間以空格分隔，返回字串中最後一個單詞的長度。

單詞是指僅由字母組成、不包含任何空格的最大子字串。字串首尾與單詞之間可能有多個空格。

範例 1:
輸入: s = "Hello World"
輸出: 5
解釋: 最後一個單詞是 "World"，長度為 5
範例 2:
輸入: s = "   fly me   to   the moon  "
輸出: 4
解釋: 最後一個單詞是 "moon"，長度為 4
範例 3:
輸入: s = "luffy is still joyboy"
輸出: 6

解題思路

方法一：從右往左掃描（推薦）

先把指標放在字串尾端，往左跳過所有尾端空格；接著繼續往左走並計數，直到再次遇到空格或走出字串為止。

這個做法只掃描最後一個單詞及其後方空白，不需要處理整個字串，也不需要額外配置記憶體。

方法二：內建切分

使用語言內建的 split 依空白切開，過濾掉空字串後取最後一項的長度。

寫法最短，但會為所有單詞配置一個陣列，空間複雜度為 O(n)。

程式碼實現

class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        i = len(s) - 1
        # 跳過尾端空格
        while i >= 0 and s[i] == ' ':
            i -= 1
        length = 0
        # 往左數最後一個單詞的字元
        while i >= 0 and s[i] != ' ':
            length += 1
            i -= 1
        return length
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;
        while (i >= 0 && s.charAt(i) == ' ') i--;
        int length = 0;
        while (i >= 0 && s.charAt(i) != ' ') {
            length++;
            i--;
        }
        return length;
    }
}
// 從尾端往前：先跳過空白，再數字元
// 時間複雜度: O(n)，空間複雜度: O(1)
function lengthOfLastWord(s: string): number {
    let i = s.length - 1, len = 0;
    while (i >= 0 && s[i] === ' ') i--;
    while (i >= 0 && s[i] !== ' ') {
        len++;
        i--;
    }
    return len;
}
// 從尾端往前：先跳過空白，再數字元
// 時間複雜度: O(n)，空間複雜度: O(1)
int lengthOfLastWord(char* s) {
    int i = strlen(s) - 1, len = 0;
    while (i >= 0 && s[i] == ' ') i--;
    while (i >= 0 && s[i] != ' ') {
        len++;
        i--;
    }
    return len;
}
class Solution {
public:
    int lengthOfLastWord(string s) {
        int i = (int)s.size() - 1;
        while (i >= 0 && s[i] == ' ') i--;
        int length = 0;
        while (i >= 0 && s[i] != ' ') {
            length++;
            i--;
        }
        return length;
    }
};

複雜度分析

時間複雜度: O(n)

最壞情況（整個字串只有一個單詞）需要走訪全部字元，一般情況只走訪尾端一小段。

空間複雜度: O(1)

只使用兩個整數變數，沒有額外配置空間。

重點提示

  • 先去尾空格：題目允許字串以空格結尾，忘記跳過會直接回傳 0
  • 從右往左更省：答案只跟尾端有關，不必先切分整個字串
  • 邊界檢查順序：i >= 0 必須寫在存取 s[i] 之前，否則會越界
  • 空白只有空格：本題保證分隔符是空格，不需處理 tab 或換行
