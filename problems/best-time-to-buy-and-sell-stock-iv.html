#188 Best Time to Buy and Sell Stock IV

Hard
Array Dynamic Programming

題目描述

給定一個整數陣列 prices，其中 prices[i] 表示第 i 天的股票價格。

設計一個算法來計算你所能獲取的最大利潤。你最多可以完成 k 筆交易。

注意：

  • 你不能同時參與多筆交易（必須在再次購買前出售掉之前的股票）
  • 一次交易 = 買入 + 賣出

範例

範例 1：
輸入：k = 2, prices = [2,4,1]
輸出：2
解釋：在第 1 天 (價格 = 2) 買入，在第 2 天 (價格 = 4) 賣出，利潤 = 4-2 = 2
範例 2：
輸入：k = 2, prices = [3,2,6,5,0,3]
輸出：7
解釋：
  • 第 2 天 (價格 = 2) 買入，第 3 天 (價格 = 6) 賣出，利潤 = 6-2 = 4
  • 第 5 天 (價格 = 0) 買入，第 6 天 (價格 = 3) 賣出，利潤 = 3-0 = 3
  • 總利潤 = 4 + 3 = 7

解題思路

💡 核心概念：狀態機 DP

關鍵洞察：維護每次交易後的最大利潤狀態。

  1. 定義狀態：第 i 天完成 j 次交易後的最大利潤
  2. 區分持有股票和不持有股票兩種狀態
  3. 狀態轉移：買入、賣出、不操作
  4. 優化：當 k ≥ n/2 時等同於無限次交易

DP 狀態定義

📊 三維 DP
定義：
buy[i][j]  = 第 i 天，完成 j 次交易，當前持有股票的最大利潤
sell[i][j] = 第 i 天，完成 j 次交易，當前不持有股票的最大利潤

為什麼需要兩個狀態？
因為持有股票和不持有股票是兩種不同的狀態
需要分別記錄

什麼時候算「完成一次交易」？
買入時計數（賣出時已經計數過了）
或者：賣出時計數（買入時還沒完成）

本題採用：賣出時計數

狀態轉移方程

🔄 轉移邏輯
buy[i][j] 的轉移：
第 i 天持有股票，有兩種來源：
1. 昨天就持有：buy[i-1][j]
2. 今天買入：sell[i-1][j] - prices[i]

buy[i][j] = max(buy[i-1][j], sell[i-1][j] - prices[i])

sell[i][j] 的轉移：
第 i 天不持有股票，有兩種來源：
1. 昨天就不持有：sell[i-1][j]
2. 今天賣出：buy[i-1][j-1] + prices[i]
   （注意：賣出完成第 j 次交易）

sell[i][j] = max(sell[i-1][j], buy[i-1][j-1] + prices[i])

初始化：
buy[0][0] = -prices[0]  (第一天買入)
sell[0][0] = 0          (第一天不操作)
其他為負無窮（不可達）

優化：k 很大的情況

🚀 特殊優化
觀察：
如果 k >= n/2（n 是天數）
→ 相當於可以無限次交易
→ 退化為 #122 Best Time to Buy and Sell Stock II

為什麼？
最多只能做 n/2 次交易（每次交易至少需要 2 天）
如果 k >= n/2，k 的限制就失效了

優化策略：
if k >= len(prices) // 2:
    return 無限次交易的解法（貪心）

詳細範例演示

🔍 DP 表格：k=2, prices=[3,2,6,5,0,3]
prices = [3, 2, 6, 5, 0, 3]
天數 i:    0  1  2  3  4  5

初始化：
buy[0][0] = -3, buy[0][1] = -∞, buy[0][2] = -∞
sell[0][0] = 0, sell[0][1] = 0,  sell[0][2] = 0

第 1 天（價格 2）：
buy[1][0] = max(-3, 0-2) = -2
buy[1][1] = max(-∞, 0-2) = -2
sell[1][0] = max(0, -3+2) = 0
sell[1][1] = max(0, -∞+2) = 0

第 2 天（價格 6）：
buy[2][0] = max(-2, 0-6) = -2
buy[2][1] = max(-2, 0-6) = -2
sell[2][0] = max(0, -2+6) = 4
sell[2][1] = max(0, -2+6) = 4

第 3 天（價格 5）：
buy[3][0] = max(-2, 0-5) = -2
buy[3][1] = max(-2, 4-5) = -1
sell[3][0] = max(4, -2+5) = 4
sell[3][1] = max(4, -2+5) = 4

第 4 天（價格 0）：
buy[4][0] = max(-2, 0-0) = 0
buy[4][1] = max(-1, 4-0) = 4
sell[4][0] = max(4, 0+0) = 4
sell[4][1] = max(4, -1+0) = 4

第 5 天（價格 3）：
buy[5][0] = max(0, 0-3) = 0
buy[5][1] = max(4, 4-3) = 4
sell[5][0] = max(4, 0+3) = 4
sell[5][1] = max(4, 4+3) = 7 ✓

答案：sell[5][2] = 7

程式碼實現

# 方法一：DP（標準解法 + 優化）
class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        
        # 優化：k 很大時等同於無限次交易
        if k >= n // 2:
            return self.maxProfitUnlimited(prices)
        
        # buy[j] = 完成 j 次交易，持有股票的最大利潤
        # sell[j] = 完成 j 次交易，不持有股票的最大利潤
        buy = [-float('inf')] * (k + 1)
        sell = [0] * (k + 1)
        
        for price in prices:
            # 從後往前更新，避免覆蓋
            for j in range(k, 0, -1):
                sell[j] = max(sell[j], buy[j] + price)
                buy[j] = max(buy[j], sell[j - 1] - price)
        
        return sell[k]
    
    def maxProfitUnlimited(self, prices):
        """無限次交易的貪心解法"""
        profit = 0
        for i in range(1, len(prices)):
            if prices[i] > prices[i - 1]:
                profit += prices[i] - prices[i - 1]
        return profit


# 方法二：二維 DP（更清晰）
class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        if k >= n // 2:
            profit = 0
            for i in range(1, n):
                profit += max(0, prices[i] - prices[i - 1])
            return profit
        
        # buy[i][j] = 第 i 天完成 j 次交易，持有股票
        # sell[i][j] = 第 i 天完成 j 次交易，不持有股票
        buy = [[-float('inf')] * (k + 1) for _ in range(n)]
        sell = [[0] * (k + 1) for _ in range(n)]
        
        # 初始化第一天
        for j in range(k + 1):
            buy[0][j] = -prices[0]
        
        for i in range(1, n):
            for j in range(k, 0, -1):
                buy[i][j] = max(buy[i - 1][j], sell[i - 1][j] - prices[i])
                sell[i][j] = max(sell[i - 1][j], buy[i - 1][j - 1] + prices[i])
        
        return sell[n - 1][k]


# 方法三：詳細註解版本
class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        """
        股票交易系列最難版本
        
        狀態定義：
        buy[j]：完成 j 次交易，當前持有股票的最大利潤
        sell[j]：完成 j 次交易，當前不持有股票的最大利潤
        """
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        
        # 關鍵優化：k 過大時的處理
        # 如果 k >= n//2，等同於無限次交易
        if k >= n // 2:
            # 貪心：抓住每次上漲
            profit = 0
            for i in range(1, n):
                if prices[i] > prices[i - 1]:
                    profit += prices[i] - prices[i - 1]
            return profit
        
        # 初始化
        # buy[j] 初始為負無窮（不可能持有股票）
        # sell[j] 初始為 0（不操作）
        buy = [-float('inf')] * (k + 1)
        sell = [0] * (k + 1)
        
        # 遍歷每一天
        for price in prices:
            # 從後往前更新，避免同一天的狀態互相影響
            for j in range(k, 0, -1):
                # 賣出：完成第 j 次交易
                # 選擇：保持不持有 vs 今天賣出
                sell[j] = max(sell[j], buy[j] + price)
                
                # 買入：準備第 j 次交易
                # 選擇：保持持有 vs 今天買入
                buy[j] = max(buy[j], sell[j - 1] - price)
        
        # 最終答案：完成 k 次交易，不持有股票
        return sell[k]

class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        if not prices or k == 0:
            return 0
        
        n = len(prices)
        if k >= n // 2:
            return sum(max(0, prices[i] - prices[i-1]) for i in range(1, n))
        
        buy = [-prices[0]] * (k + 1)
        sell = [0] * (k + 1)
        
        for i in range(1, n):
            for j in range(k, 0, -1):
                sell[j] = max(sell[j], buy[j] + prices[i])
                buy[j] = max(buy[j], sell[j - 1] - prices[i])
        
        return sell[k]

class Solution {
    public int maxProfit(int k, int[] prices) {
        if (prices.length == 0 || k == 0) return 0;
        
        int n = prices.length;
        
        // k 很大時優化
        if (k >= n / 2) {
            int profit = 0;
            for (int i = 1; i < n; i++) {
                profit += Math.max(0, prices[i] - prices[i - 1]);
            }
            return profit;
        }
        
        int[] buy = new int[k + 1];
        int[] sell = new int[k + 1];
        Arrays.fill(buy, Integer.MIN_VALUE);
        
        for (int price : prices) {
            for (int j = k; j >= 1; j--) {
                sell[j] = Math.max(sell[j], buy[j] + price);
                buy[j] = Math.max(buy[j], sell[j - 1] - price);
            }
        }
        
        return sell[k];
    }
}

// 狀態機 DP：buy[j] / sell[j] 表示第 j 次交易買入後 / 賣出後的最大收益
// 時間複雜度: O(n·k)，空間複雜度: O(k)
function maxProfit(k: number, prices: number[]): number {
    const n = prices.length;
    if (n === 0 || k === 0) return 0;

    // k 大到等同不限次數時，直接用貪心
    if (k >= n / 2) {
        let profit = 0;
        for (let i = 1; i < n; i++) profit += Math.max(0, prices[i] - prices[i - 1]);
        return profit;
    }

    const buy = new Array(k + 1).fill(-Infinity);
    const sell = new Array(k + 1).fill(0);
    for (const p of prices) {
        for (let j = 1; j <= k; j++) {
            buy[j] = Math.max(buy[j], sell[j - 1] - p);  // 第 j 次買入
            sell[j] = Math.max(sell[j], buy[j] + p);     // 第 j 次賣出
        }
    }
    return sell[k];
}
// 狀態機 DP：buy[j] / sell[j] 表示第 j 次交易買入後 / 賣出後的最大收益
// 時間複雜度: O(n·k)，空間複雜度: O(k)
int maxProfit(int k, int* prices, int pricesSize) {
    int n = pricesSize;
    if (n == 0 || k == 0) return 0;

    // k 大到等同不限次數時，直接用貪心
    if (k >= n / 2) {
        int profit = 0;
        for (int i = 1; i < n; i++)
            if (prices[i] > prices[i - 1]) profit += prices[i] - prices[i - 1];
        return profit;
    }

    int* buy = malloc(sizeof(int) * (k + 1));
    int* sell = calloc(k + 1, sizeof(int));
    for (int j = 0; j <= k; j++) buy[j] = INT_MIN / 2;

    for (int i = 0; i < n; i++) {
        for (int j = 1; j <= k; j++) {
            if (sell[j - 1] - prices[i] > buy[j]) buy[j] = sell[j - 1] - prices[i];
            if (buy[j] + prices[i] > sell[j]) sell[j] = buy[j] + prices[i];
        }
    }
    int ans = sell[k];
    free(buy);
    free(sell);
    return ans;
}

複雜度分析

一維 DP 解法：
  • 時間複雜度：O(n × k)，n 是天數
  • 空間複雜度：O(k)
二維 DP 解法：
  • 時間複雜度：O(n × k)
  • 空間複雜度：O(n × k)

重點提示

💡 關鍵技巧 1：k 的優化

當 k ≥ n/2 時，退化為無限次交易問題。

💡 關鍵技巧 2：從後往前更新

避免同一天的狀態互相覆蓋。

💡 關鍵技巧 3：賣出時計數

交易在賣出時才算完成，這樣狀態轉移更清晰。

⚠️ 常見錯誤：
  • 沒有處理 k 很大的情況（會 TLE 或 MLE）
  • 從前往後更新導致狀態覆蓋
  • 初始化錯誤（buy 應該是負無窮）
  • 交易計數時機錯誤
