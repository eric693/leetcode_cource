128. Longest Consecutive Sequence
Medium

題目描述

給定一個未排序的整數陣列 nums，找出數字連續的最長序列（不要求序列元素在原陣列中連續）的長度。

請設計並實現時間複雜度為 O(n) 的演算法解決此問題。

範例 1:
輸入: nums = [100,4,200,1,3,2]
輸出: 4
解釋: 最長連續序列是 [1, 2, 3, 4]，長度為 4
範例 2:
輸入: nums = [0,3,7,2,5,8,4,6,0,1]
輸出: 9
解釋: 最長連續序列是 [0..8]
範例 3:
輸入: nums = []
輸出: 0

解題思路

方法一：雜湊集合 + 只從序列起點展開（推薦）

先把所有數字放進雜湊集合，讓「某個數字是否存在」變成 O(1) 查詢。

接著遍歷集合中的每個數字 x，只有當 x - 1 不在集合中時，x 才是某段連續序列的起點；此時才往上不斷檢查 x + 1、x + 2… 並計算長度。

這個「只從起點展開」的判斷是達成 O(n) 的關鍵：每個數字最多在它所屬序列被展開一次，總工作量是線性的。

方法二：排序後掃描

先排序再一次掃描，遇到相鄰差 1 就累加長度，遇到重複值跳過，差值大於 1 則重新計數。

寫法直觀但時間為 O(n log n)，不符合題目要求的線性複雜度，可作為驗證答案的對照解法。

程式碼實現

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        longest = 0

        for x in num_set:
            # 只從序列的起點開始展開
            if x - 1 in num_set:
                continue
            length = 1
            cur = x
            while cur + 1 in num_set:
                cur += 1
                length += 1
            longest = max(longest, length)

        return longest
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);

        int longest = 0;
        for (int x : set) {
            if (set.contains(x - 1)) continue;
            int length = 1, cur = x;
            while (set.contains(cur + 1)) {
                cur++;
                length++;
            }
            longest = Math.max(longest, length);
        }
        return longest;
    }
}
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> s(nums.begin(), nums.end());
        int longest = 0;

        for (int x : s) {
            if (s.count(x - 1)) continue;
            int length = 1, cur = x;
            while (s.count(cur + 1)) {
                cur++;
                length++;
            }
            longest = max(longest, length);
        }
        return longest;
    }
};

複雜度分析

時間複雜度: O(n)

雖然有巢狀迴圈，但內層 while 只會在序列起點被觸發，整體每個數字最多被造訪兩次。

空間複雜度: O(n)

雜湊集合需要儲存所有相異數字。

重點提示

  • 起點判斷是精髓：少了 x - 1 not in set 這行，複雜度會退化成 O(n²)
  • 遍歷集合而非陣列：走訪去重後的集合可避免重複元素造成的多餘展開
  • 自動處理重複值：集合去重後，[1,1,2] 的答案自然是 2
  • 空陣列回傳 0：記得初始化 longest = 0，避免空輸入時回傳錯誤值
