#260 Single Number III

Medium
Bit Manipulation Array

題目描述

給你一個整數陣列 nums，其中恰好有兩個元素只出現一次，其餘所有元素均出現兩次。找出只出現一次的那兩個元素。你可以按任意順序返回答案。

要求：時間複雜度 O(n)，空間複雜度 O(1)。

範例

範例 1：
輸入：nums = [1,2,1,3,2,5]
輸出：[3,5]（或 [5,3]）
範例 2：
輸入：nums = [-1,0]
輸出：[-1,0]
範例 3：
輸入：nums = [0,1]
輸出：[1,0]

解題思路

💡 第一步：全部 XOR，得到 a ^ b
XOR 性質：x ^ x = 0，x ^ 0 = x，且滿足交換律

nums = [1,2,1,3,2,5]
全 XOR = 1^2^1^3^2^5
       = (1^1) ^ (2^2) ^ 3 ^ 5
       = 0 ^ 0 ^ 3 ^ 5
       = 3 ^ 5 = 011 ^ 101 = 110 = 6

問題：我們只得到 a^b，怎麼把 a 和 b 分開？

第二步：用 lowbit 分組（本題精髓）

a ^ b 中為 1 的位，代表 a 和 b 在該位不同
xor = a ^ b = 110
取最低位的 1：lowbit = xor & (-xor) = 010

用第 1 位（值為 2 的那位）把整個陣列分成兩組：
  組 A：該位為 1 → {2, 3, 2}    (2=010, 3=011, 2=010)
  組 B：該位為 0 → {1, 1, 5}    (1=001, 1=001, 5=101)

關鍵保證：
  1. a 和 b 一定被分到不同組（因為該位不同）
  2. 相同的數字一定被分到同一組（完全相同當然同組）

各組內部 XOR：
  組 A: 2^3^2 = 3 ✓
  組 B: 1^1^5 = 5 ✓

為什麼是 x & (-x)？

🔍 二補數取 lowbit
-x = ~x + 1（二補數）

x  = 0110 1000
~x = 1001 0111
-x = 1001 1000   （~x + 1）

x & -x = 0000 1000  ← 剛好只留下最低位的 1

任何一個為 1 的位都可以用來分組，
取 lowbit 只是因為最容易計算。

程式碼實現

# XOR + lowbit 分組（標準解）
class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        # 第一步：全部 XOR，得到 a ^ b
        xor_all = 0
        for num in nums:
            xor_all ^= num

        # 第二步：取出最低位的 1（a 和 b 在這一位不同）
        lowbit = xor_all & (-xor_all)

        # 第三步：依這一位分兩組，各自 XOR
        a = b = 0
        for num in nums:
            if num & lowbit:
                a ^= num
            else:
                b ^= num
        return [a, b]

class Solution {
public:
    vector<int> singleNumber(vector<int>& nums) {
        // 第一步：全部 XOR，得到 a ^ b
        long long xorAll = 0;
        for (int num : nums) xorAll ^= num;

        // 第二步：取最低位的 1（用 long long 避免 INT_MIN 溢位）
        int lowbit = (int)(xorAll & -xorAll);

        // 第三步：分組 XOR
        int a = 0, b = 0;
        for (int num : nums) {
            if (num & lowbit) a ^= num;
            else              b ^= num;
        }
        return {a, b};
    }
};
// XOR + lowbit 分組（標準解）
class Solution {
    public int[] singleNumber(int[] nums) {
        // 第一步：全部 XOR，得到 a ^ b
        int xorAll = 0;
        for (int num : nums) xorAll ^= num;

        // 第二步：取最低位的 1
        // 注意 xorAll == Integer.MIN_VALUE 時 -xorAll 仍等於自己，剛好正確
        int lowbit = xorAll & (-xorAll);

        // 第三步：分組 XOR
        int a = 0, b = 0;
        for (int num : nums) {
            if ((num & lowbit) != 0) a ^= num;
            else                     b ^= num;
        }
        return new int[]{a, b};
    }
}
// 全部 XOR 得到 a ^ b，用最低位的 1 把數字分成兩組，各組再 XOR
// 時間複雜度: O(n)，空間複雜度: O(1)
function singleNumber(nums: number[]): number[] {
    let xor = 0;
    for (const x of nums) xor ^= x;
    const lowbit = xor & -xor;              // a 與 b 在這一位不同
    let a = 0, b = 0;
    for (const x of nums) {
        if (x & lowbit) a ^= x;
        else b ^= x;
    }
    return [a, b];
}
// 全部 XOR 得到 a ^ b，用最低位的 1 把數字分成兩組，各組再 XOR
// 時間複雜度: O(n)，空間複雜度: O(1)
int* singleNumber(int* nums, int numsSize, int* returnSize) {
    unsigned int xor = 0;
    for (int i = 0; i < numsSize; i++) xor ^= (unsigned int)nums[i];
    unsigned int lowbit = xor & (~xor + 1);  // 用無號數避免 INT_MIN 取負溢位
    int a = 0, b = 0;
    for (int i = 0; i < numsSize; i++) {
        if ((unsigned int)nums[i] & lowbit) a ^= nums[i];
        else b ^= nums[i];
    }
    int* ans = malloc(sizeof(int) * 2);
    ans[0] = a;
    ans[1] = b;
    *returnSize = 2;
    return ans;
}

複雜度分析

時間複雜度：O(n)
  • 兩次線性掃描：一次求 XOR、一次分組
空間複雜度：O(1)
  • 只用了 xorAll、lowbit、a、b 四個變數

重點提示

💡 關鍵技巧 1：lowbit = x & (-x)

取出最低位的 1，是位元題的核心工具，也是樹狀陣列（Fenwick Tree）的基礎。

💡 關鍵技巧 2：「分組」的思維

當一個技巧（XOR）只能處理「一個特殊元素」時，就想辦法把問題切成兩個子問題，各自套用同一個技巧。這是很通用的解題思路。

⚠️ 常見錯誤：
  • C++ 直接對 INT_MIN 取負號是 UB，建議用 long long 中轉
  • 分組條件要寫 (num & lowbit) != 0，寫成 == 1 是錯的（lowbit 不一定是 1）
  • 誤以為要取最高位的 1；任何一個為 1 的位都可以，但 lowbit 最好算

補充說明

XOR 性質總整理（面試必背）

📝 XOR 的六大性質
1. x ^ 0 = x            （0 是單位元素）
2. x ^ x = 0            （自反性 → 消除重複）
3. x ^ y = y ^ x        （交換律）
4. (x^y)^z = x^(y^z)    （結合律）
5. x ^ y ^ y = x        （可逆 → 加解密、交換兩數）
6. XOR 等於「不進位加法」

應用：
- 找唯一出現一次的數
- 不用暫存變數交換兩數
- 找出缺失的數字
- 簡易加解密與 checksum（parity bit）

韌體應用：Parity Bit（同位檢查）

// UART 通訊的偶同位：把所有位元 XOR 起來
int parity(uint32_t x) {
    x ^= x >> 16;
    x ^= x >> 8;
    x ^= x >> 4;
    x ^= x >> 2;
    x ^= x >> 1;
    return x & 1;   // 1 表示有奇數個 1
}
