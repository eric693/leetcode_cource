412. Fizz Buzz
Easy

題目描述

給定一個整數 n，返回一個長度為 n 的字串陣列 answer（索引從 1 開始），其中：

answer[i] == "FizzBuzz" 如果 i 同時是 3 和 5 的倍數；answer[i] == "Fizz" 如果 i 是 3 的倍數；answer[i] == "Buzz" 如果 i 是 5 的倍數；否則 answer[i] == i 的字串形式。

範例 1:
輸入: n = 3
輸出: ["1","2","Fizz"]
範例 2:
輸入: n = 5
輸出: ["1","2","Fizz","4","Buzz"]
範例 3:
輸入: n = 15
輸出: ["1","2","Fizz","4","Buzz","Fizz","7","8","Fizz","Buzz","11","Fizz","13","14","FizzBuzz"]

解題思路

方法一：條件判斷（推薦）

從 1 走到 n，對每個數字依序判斷：先判斷「同時被 3 和 5 整除」，再判斷 3，最後判斷 5。

順序很重要：如果先判斷 3 的倍數，15 會被錯誤地輸出成 Fizz。

方法二：字串拼接

先建立空字串，能被 3 整除就接上 "Fizz"，能被 5 整除就接上 "Buzz"，最後若字串仍為空則放入數字本身。

這種寫法在需要擴充規則（例如再加一個 7 → "Jazz"）時最容易維護，不會產生指數成長的 if 分支。

程式碼實現

class Solution:
    def fizzBuzz(self, n: int) -> List[str]:
        answer = []
        for i in range(1, n + 1):
            s = ""
            if i % 3 == 0:
                s += "Fizz"
            if i % 5 == 0:
                s += "Buzz"
            answer.append(s if s else str(i))
        return answer
class Solution {
    public List<String> fizzBuzz(int n) {
        List<String> answer = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            StringBuilder sb = new StringBuilder();
            if (i % 3 == 0) sb.append("Fizz");
            if (i % 5 == 0) sb.append("Buzz");
            answer.add(sb.length() > 0 ? sb.toString() : String.valueOf(i));
        }
        return answer;
    }
}
// 直接模擬
// 時間複雜度: O(n)，空間複雜度: O(1)（不含輸出）
function fizzBuzz(n: number): string[] {
    const ans: string[] = [];
    for (let i = 1; i <= n; i++) {
        if (i % 15 === 0) ans.push('FizzBuzz');
        else if (i % 3 === 0) ans.push('Fizz');
        else if (i % 5 === 0) ans.push('Buzz');
        else ans.push(String(i));
    }
    return ans;
}
// 直接模擬（每個字串都要自己配置記憶體）
// 時間複雜度: O(n)，空間複雜度: O(1)（不含輸出）
char** fizzBuzz(int n, int* returnSize) {
    char** ans = malloc(sizeof(char*) * n);
    for (int i = 1; i <= n; i++) {
        char* s = malloc(9);                 // "FizzBuzz" + '\0'
        if (i % 15 == 0) strcpy(s, "FizzBuzz");
        else if (i % 3 == 0) strcpy(s, "Fizz");
        else if (i % 5 == 0) strcpy(s, "Buzz");
        else sprintf(s, "%d", i);
        ans[i - 1] = s;
    }
    *returnSize = n;
    return ans;
}
class Solution {
public:
    vector<string> fizzBuzz(int n) {
        vector<string> answer;
        for (int i = 1; i <= n; i++) {
            string s;
            if (i % 3 == 0) s += "Fizz";
            if (i % 5 == 0) s += "Buzz";
            answer.push_back(s.empty() ? to_string(i) : s);
        }
        return answer;
    }
};

複雜度分析

時間複雜度: O(n)

需要走訪 1 到 n 每個數字，每次做常數次取餘運算。

空間複雜度: O(1)

除了必須回傳的答案陣列之外，只用了固定大小的暫存字串。

重點提示

  • 判斷順序：若使用 if / else if 寫法，必須把 15 的倍數放在最前面，否則會被 3 的分支攔截
  • 用累加取代分支：字串拼接寫法讓規則彼此獨立，新增規則不需要重寫既有判斷
  • 索引從 1 開始：題目的 answer 是 1-based，迴圈要寫 1..n 而不是 0..n-1
  • Java 字串拼接：迴圈內用 StringBuilder 而非 += 串接，避免產生多餘的字串物件
