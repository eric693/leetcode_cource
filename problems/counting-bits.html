#338 Counting Bits

Easy
Bit Manipulation Dynamic Programming

題目描述

給你一個整數 n，對於 0 <= i <= n 中的每個 i，計算其二進位表示中 1 的個數，返回一個長度為 n + 1 的陣列 ans 作為答案。

進階：能否只用一次遍歷（O(n) 時間）完成？能否不使用任何內建函數？

範例

範例 1：
輸入：n = 2
輸出：[0,1,1]
解釋：0 → 0（0 個 1）、1 → 1（1 個）、2 → 10（1 個）
範例 2：
輸入：n = 5
輸出：[0,1,1,2,1,2]
解釋：0→0, 1→1, 2→10, 3→11, 4→100, 5→101

解題思路

💡 核心：用 DP 重複利用已算過的結果

如果對每個數都跑一次 popcount，是 O(n log n)。但相鄰的數字之間有遞推關係，可以做到 O(n)。

遞推式一：dp[i] = dp[i >> 1] + (i & 1)（最好記）

🎯 右移一位 = 去掉最低位
i 的 1 的個數 = (i 去掉最低位後的 1 的個數) + (最低位是不是 1)

i = 5 = 101
i >> 1 = 2 = 10   → dp[2] = 1
i & 1  = 1
dp[5] = 1 + 1 = 2 ✓

完整推導 n = 7：
dp[0] = 0                        0
dp[1] = dp[0] + 1 = 1            1
dp[2] = dp[1] + 0 = 1           10
dp[3] = dp[1] + 1 = 2           11
dp[4] = dp[2] + 0 = 1          100
dp[5] = dp[2] + 1 = 2          101
dp[6] = dp[3] + 0 = 2          110
dp[7] = dp[3] + 1 = 3          111

遞推式二：dp[i] = dp[i & (i-1)] + 1

🎯 消掉一個 1，個數就少 1
i & (i-1) 會消掉最右邊的 1，且結果一定小於 i（已算過）

i = 6 = 110
i & (i-1) = 110 & 101 = 100 = 4
dp[6] = dp[4] + 1 = 1 + 1 = 2 ✓

遞推式三：最高有效位法

🎯 dp[i] = dp[i - highBit] + 1
當 i 是 2 的冪時更新 highBit = i
dp[i] = dp[i - highBit] + 1

i=4 → highBit=4, dp[4]=dp[0]+1=1
i=5 → dp[5]=dp[1]+1=2
i=6 → dp[6]=dp[2]+1=2
i=7 → dp[7]=dp[3]+1=3

// DP：i 的 1 個數 = (i >> 1) 的 1 個數 + 最低位
// 時間複雜度: O(n)，空間複雜度: O(1)（不含輸出）
function countBits(n: number): number[] {
    const ans = new Array(n + 1).fill(0);
    for (let i = 1; i <= n; i++) {
        ans[i] = ans[i >> 1] + (i & 1);
    }
    return ans;
}
// DP：i 的 1 個數 = (i >> 1) 的 1 個數 + 最低位
// 時間複雜度: O(n)，空間複雜度: O(1)（不含輸出）
int* countBits(int n, int* returnSize) {
    int* ans = malloc(sizeof(int) * (n + 1));
    ans[0] = 0;
    for (int i = 1; i <= n; i++) {
        ans[i] = ans[i >> 1] + (i & 1);
    }
    *returnSize = n + 1;
    return ans;
}

複雜度分析

時間複雜度：O(n)
  • 每個數字只做 O(1) 的運算
  • 若對每個數獨立做 popcount 則是 O(n log n)
空間複雜度：O(1)（不含輸出陣列），輸出佔 O(n)

重點提示

💡 關鍵技巧：位元題也能用 DP

看到「對 0~n 每個數都要算」就要想到能不能用小的結果推大的結果，而不是每個都重算。

💡 三個遞推式選哪個？

面試建議用 dp[i] = dp[i>>1] + (i&1)，因為推導過程最直覺（右移就是去掉最低位），也最不容易寫錯。

⚠️ 常見錯誤：
  • 陣列大小要開 n + 1，不是 n
  • C++/Java 中 i & (i-1) == 0 因運算優先級要加括號寫成 (i & (i-1)) == 0
  • 直接用 Integer.bitCount() 雖然會過，但面試官通常要你自己推遞推式

補充說明

為什麼 dp[i >> 1] 一定已經算過？

🔍 DP 的無後效性

對 i >= 1，i >> 1 < i 恆成立；同理 i & (i-1) < i。所以由小到大遍歷時，需要的子問題必定已經計算完成。這就是 DP 遞推順序正確性的來源。

韌體應用：預先建表

// 用同樣的遞推在編譯期/開機時建 256 大小的 popcount 表
static uint8_t popcnt_table[256];
void init_popcnt_table(void) {
    popcnt_table[0] = 0;
    for (int i = 1; i < 256; i++)
        popcnt_table[i] = popcnt_table[i >> 1] + (i & 1);
}
// 之後任何 byte 的 popcount 都是 O(1) 查表
