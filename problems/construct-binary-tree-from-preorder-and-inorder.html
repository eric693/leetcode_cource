#105 Construct Binary Tree from Preorder and Inorder Traversal

Medium
Tree Array Hash Table Divide and Conquer Recursion

題目描述

給定兩個整數陣列 preorder 和 inorder，其中 preorder 是二元樹的前序遍歷，inorder 是同一棵樹的中序遍歷，請建構二元樹並返回其根節點。

題目保證 preorder 和 inorder 中沒有重複元素。

範例

範例 1：
輸入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
輸出：[3,9,20,null,null,15,7]

      3
     / \
    9   20
        / \
      15   7
範例 2：
輸入：preorder = [-1], inorder = [-1]
輸出：[-1]

解題思路

💡 核心：前序給「根」，中序給「左右分界」
前序 = [根][左子樹的前序][右子樹的前序]
中序 = [左子樹的中序][根][右子樹的中序]

preorder = [3, 9, 20, 15, 7]
             ↑ 第一個一定是根！

inorder  = [9, 3, 15, 20, 7]
               ↑ 在中序中找到 3 的位置 = 1

  → 左子樹有 1 個節點：[9]
  → 右子樹有 3 個節點：[15, 20, 7]

回頭切分前序：
preorder = [3 | 9 | 20, 15, 7]
            根  左   右（長度由中序決定）

遞迴處理：
  左子樹：preorder=[9],        inorder=[9]
  右子樹：preorder=[20,15,7],  inorder=[15,20,7]

索引推導（最容易出錯的地方）

🎯 用長度來推算切割點
設當前處理的範圍：
  preorder[preLeft .. preRight]
  inorder[inLeft .. inRight]

1. 根節點值 = preorder[preLeft]
2. 在中序中找到根的位置 rootIdx（用 HashMap 加速）
3. 左子樹大小 leftSize = rootIdx - inLeft

左子樹：
  preorder: [preLeft + 1, preLeft + leftSize]
  inorder:  [inLeft, rootIdx - 1]

右子樹：
  preorder: [preLeft + leftSize + 1, preRight]
  inorder:  [rootIdx + 1, inRight]

⭐ 記憶要訣：所有切割點都由 leftSize 推導，
   把 leftSize 算對，其餘索引就水到渠成。

優化：用 HashMap 加速查找

⚡ 從 O(n²) 降到 O(n)
每次都線性搜尋中序找根的位置 → O(n) × n 次 = O(n²)

預先建立 {值: 中序索引} 的對照表 → 查找變成 O(1)
總複雜度降為 O(n) ✓

（題目保證沒有重複元素，所以值可以直接當 key）

程式碼實現

class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        # 預先建立 值 -> 中序索引 的對照表，把查找降到 O(1)
        idx_map = {val: i for i, val in enumerate(inorder)}

        def build(pre_left, pre_right, in_left, in_right):
            if pre_left > pre_right:
                return None

            # 前序的第一個就是根
            root_val = preorder[pre_left]
            root = TreeNode(root_val)

            # 在中序中定位根，算出左子樹大小
            root_idx = idx_map[root_val]
            left_size = root_idx - in_left

            # 遞迴建立左右子樹
            root.left = build(pre_left + 1, pre_left + left_size,
                              in_left, root_idx - 1)
            root.right = build(pre_left + left_size + 1, pre_right,
                               root_idx + 1, in_right)
            return root

        return build(0, len(preorder) - 1, 0, len(inorder) - 1)
class Solution {
    unordered_map<int, int> idxMap;   // 值 -> 中序索引
    vector<int> pre;

    TreeNode* build(int preLeft, int preRight, int inLeft, int inRight) {
        if (preLeft > preRight) return nullptr;

        // 前序的第一個就是根
        int rootVal = pre[preLeft];
        TreeNode* root = new TreeNode(rootVal);

        // 在中序中定位根，算出左子樹大小
        int rootIdx = idxMap[rootVal];
        int leftSize = rootIdx - inLeft;

        root->left  = build(preLeft + 1, preLeft + leftSize,
                            inLeft, rootIdx - 1);
        root->right = build(preLeft + leftSize + 1, preRight,
                            rootIdx + 1, inRight);
        return root;
    }

public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        pre = preorder;
        for (int i = 0; i < inorder.size(); i++) {
            idxMap[inorder[i]] = i;
        }
        return build(0, preorder.size() - 1, 0, inorder.size() - 1);
    }
};
class Solution {
    private Map<Integer, Integer> idxMap = new HashMap<>();
    private int[] preorder;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        this.preorder = preorder;
        // 預先建立 值 -> 中序索引 的對照表
        for (int i = 0; i < inorder.length; i++) {
            idxMap.put(inorder[i], i);
        }
        return build(0, preorder.length - 1, 0, inorder.length - 1);
    }

    private TreeNode build(int preLeft, int preRight, int inLeft, int inRight) {
        if (preLeft > preRight) return null;

        int rootVal = preorder[preLeft];
        TreeNode root = new TreeNode(rootVal);

        int rootIdx = idxMap.get(rootVal);
        int leftSize = rootIdx - inLeft;

        root.left  = build(preLeft + 1, preLeft + leftSize,
                           inLeft, rootIdx - 1);
        root.right = build(preLeft + leftSize + 1, preRight,
                           rootIdx + 1, inRight);
        return root;
    }
}
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 * }
 */
// 前序第一個是根，在中序中找到根的位置即可切出左右子樹
// 時間複雜度: O(n)，空間複雜度: O(n)
function buildTree(preorder: number[], inorder: number[]): TreeNode | null {
    const idx = new Map<number, number>();
    inorder.forEach((v, i) => idx.set(v, i));
    let pre = 0;                                  // 目前要用的前序位置

    const build = (inLeft: number, inRight: number): TreeNode | null => {
        if (inLeft > inRight) return null;
        const rootVal = preorder[pre++];
        const root = new TreeNode(rootVal);
        const mid = idx.get(rootVal)!;
        root.left = build(inLeft, mid - 1);       // 先建左子樹（前序順序）
        root.right = build(mid + 1, inRight);
        return root;
    };

    return build(0, inorder.length - 1);
}
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */
// 前序第一個是根，在中序中找到根的位置即可切出左右子樹
// 值域 -3000 ~ 3000，用位移陣列當雜湊表
// 時間複雜度: O(n)，空間複雜度: O(n)
static int idx[6001];
static int pre;

static struct TreeNode* build(int* preorder, int inLeft, int inRight) {
    if (inLeft > inRight) return NULL;
    int rootVal = preorder[pre++];
    struct TreeNode* root = malloc(sizeof(struct TreeNode));
    root->val = rootVal;
    int mid = idx[rootVal + 3000];
    root->left = build(preorder, inLeft, mid - 1);
    root->right = build(preorder, mid + 1, inRight);
    return root;
}

struct TreeNode* buildTree(int* preorder, int preorderSize, int* inorder, int inorderSize) {
    for (int i = 0; i < inorderSize; i++) idx[inorder[i] + 3000] = i;
    pre = 0;
    return build(preorder, 0, inorderSize - 1);
}

複雜度分析

時間複雜度：O(n)
  • 每個節點建立一次，HashMap 查找 O(1)
  • 若不用 HashMap，每次線性搜尋會退化成 O(n²)
空間複雜度：O(n)
  • HashMap 佔 O(n)
  • 遞迴堆疊 O(h)，最壞 O(n)

重點提示

💡 關鍵技巧 1：先算 leftSize

四個索引邊界全部由 leftSize = rootIdx - inLeft 推導出來。與其硬背索引公式，不如每次現場用一個小例子推導一遍，更不容易出錯。

💡 關鍵技巧 2：哪些遍歷組合能唯一還原樹？
  • 前序 + 中序 → ✓ 可以（本題）
  • 後序 + 中序 → ✓ 可以（#106）
  • 前序 + 後序 → ✗ 不唯一（無法區分只有一個子節點時是左還是右）
  • 層序 + 中序 → ✓ 可以

中序是關鍵，因為只有中序能提供「左右子樹的分界」。這是面試很愛問的觀念題。

⚠️ 常見錯誤：
  • 索引邊界算錯（尤其是右子樹前序的起點 preLeft + leftSize + 1）
  • 沒有用 HashMap，導致 O(n²) 超時
  • 終止條件寫成 preLeft >= preRight，會漏掉單節點的情況
  • 值有重複時 HashMap 會覆蓋（本題保證不重複，但要知道這個限制）

補充說明

#106：後序 + 中序

🔄 從後往前取根
後序 = [左子樹][右子樹][根]
       → 根在【最後一個】

所以從 postorder 的尾端開始取根，
且要【先建右子樹，再建左子樹】
（因為從後往前取的話，先遇到的是右子樹的根）

TreeNode* build(int postLeft, int postRight, int inLeft, int inRight) {
    if (postLeft > postRight) return nullptr;
    int rootVal = post[postRight];        // 最後一個是根
    TreeNode* root = new TreeNode(rootVal);
    int rootIdx = idxMap[rootVal];
    int leftSize = rootIdx - inLeft;
    root->left  = build(postLeft, postLeft + leftSize - 1,
                        inLeft, rootIdx - 1);
    root->right = build(postLeft + leftSize, postRight - 1,
                        rootIdx + 1, inRight);
    return root;
}

為什麼「前序 + 後序」無法唯一決定？

    1           1
   /               2               2

前序都是 [1, 2]
後序都是 [2, 1]

兩棵不同的樹產生完全相同的前序與後序！
因為沒有中序，我們無法知道 2 是左孩子還是右孩子。

只有當每個節點都有 0 或 2 個孩子（滿二元樹）時，
前序 + 後序才能唯一決定一棵樹。

迭代解法（進階）

本題也有 O(n) 的迭代解法：用堆疊維護當前路徑，前序指標一路往下建左子樹；當 stack.top().val == inorder[inIdx] 時，代表左子樹走完了，開始回退並轉向右子樹。程式碼較難理解但空間常數更小，面試中若時間充裕可以提及，一般寫遞迴版本即可。
