#560 Subarray Sum Equals K

Medium
Array Hash Table Prefix Sum

題目描述

給你一個整數陣列 nums 和一個整數 k，請你統計並返回該陣列中和為 k 的連續子陣列的個數。

子陣列是陣列中元素的連續非空序列。注意 nums 中可能包含負數。

範例

範例 1：
輸入：nums = [1,1,1], k = 2
輸出：2
解釋：[1,1]（索引 0-1）和 [1,1]（索引 1-2）
範例 2：
輸入：nums = [1,2,3], k = 3
輸出：2
解釋：[3] 和 [1,2]
範例 3：
輸入：nums = [1,-1,0], k = 0
輸出：3
解釋：[1,-1]、[0]、[1,-1,0]

解題思路

⚠️ 為什麼不能用滑動視窗？

滑動視窗要求「擴大視窗時和單調遞增」，才能靠移動左右邊界收斂。但本題有負數，加入元素可能讓和變小，視窗無法單調收縮 —— 這是本題最重要的觀念。

核心：前綴和 + HashMap

💡 把「找子陣列」轉成「找兩個前綴和的差」
定義 prefix[i] = nums[0] + nums[1] + ... + nums[i-1]

子陣列 (i, j] 的和 = prefix[j] - prefix[i]

要找和為 k 的子陣列，就是要找：
    prefix[j] - prefix[i] = k
即  prefix[i] = prefix[j] - k

所以掃描到位置 j 時，只要問：
「之前出現過幾次值為 prefix[j] - k 的前綴和？」
把次數累加進答案即可。

用 HashMap 記錄「每個前綴和出現的次數」，
一趟掃描就能完成 → O(n)

完整追蹤：nums = [1,2,3], k = 3

🔄 逐步計算
初始 count = {0: 1}   ← 關鍵！代表「空前綴和 0」出現一次
prefixSum = 0, result = 0

i=0, num=1:
  prefixSum = 1
  找 1 - 3 = -2 → count 中沒有，加 0
  count = {0:1, 1:1}

i=1, num=2:
  prefixSum = 3
  找 3 - 3 = 0 → count[0] = 1，result += 1 → result = 1
  （對應子陣列 [1,2]）
  count = {0:1, 1:1, 3:1}

i=2, num=3:
  prefixSum = 6
  找 6 - 3 = 3 → count[3] = 1，result += 1 → result = 2
  （對應子陣列 [3]）
  count = {0:1, 1:1, 3:1, 6:1}

答案 = 2 ✓

為什麼要初始化 count[0] = 1？

🎯 處理「從索引 0 開始」的子陣列
nums = [3], k = 3

沒有初始化 count[0] = 1：
  prefixSum = 3，找 3-3 = 0 → 找不到 → result = 0 ✗

有初始化：
  找到 count[0] = 1 → result = 1 ✓

意義：prefix[0] = 0 代表「什麼都不取」的空前綴，
      它讓「整段從頭開始的子陣列」也能被正確計數。

這是本題最容易漏掉的一行，務必記住。

程式碼實現

# 前綴和 + HashMap（推薦，O(n)）
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        from collections import defaultdict

        count = defaultdict(int)
        count[0] = 1              # 關鍵：空前綴和出現一次

        prefix_sum = 0
        result = 0
        for num in nums:
            prefix_sum += num
            # 有幾個舊前綴和滿足 prefix_sum - old = k
            result += count[prefix_sum - k]
            count[prefix_sum] += 1
        return result


# 暴力解（O(n²)，小資料可用，面試可先講再優化）
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        result = 0
        for i in range(n):
            total = 0
            for j in range(i, n):
                total += nums[j]
                if total == k:
                    result += 1
        return result
// 前綴和 + HashMap（推薦，O(n)）
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> count;
        count[0] = 1;                 // 關鍵：空前綴和出現一次

        int prefixSum = 0, result = 0;
        for (int num : nums) {
            prefixSum += num;
            // 查詢是否存在 prefixSum - k
            auto it = count.find(prefixSum - k);
            if (it != count.end()) result += it->second;
            count[prefixSum]++;
        }
        return result;
    }
};
// 前綴和 + HashMap（推薦，O(n)）
class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1);              // 關鍵：空前綴和出現一次

        int prefixSum = 0, result = 0;
        for (int num : nums) {
            prefixSum += num;
            // 有幾個舊前綴和滿足 prefixSum - old = k
            result += count.getOrDefault(prefixSum - k, 0);
            count.put(prefixSum, count.getOrDefault(prefixSum, 0) + 1);
        }
        return result;
    }
}

複雜度分析

時間複雜度：O(n)
  • 單趟掃描，HashMap 平均 O(1) 查詢與插入
  • 暴力解為 O(n²)
空間複雜度：O(n)
  • 最壞情況所有前綴和都不同，HashMap 存 n 個鍵

重點提示

💡 關鍵技巧 1：count[0] = 1 的初始化

沒有這行，所有「從索引 0 開始」的子陣列都會被漏算。這是本題唯一但最致命的陷阱。

💡 關鍵技巧 2：先查詢，再更新

必須先 result += count[prefixSum - k]，之後才 count[prefixSum]++。順序寫反的話，當 k = 0 時會把「自己」算進去，答案偏大。

💡 關鍵技巧 3：有負數 → 排除滑動視窗

面試時主動說明「因為有負數，視窗和不單調，所以滑動視窗不適用，改用前綴和 + 雜湊」，是展現思考深度的好機會。

⚠️ 常見錯誤：
  • 忘記 count[0] = 1
  • 查詢與更新的順序顛倒
  • 誤用滑動視窗（在有負數時會得到錯誤答案）
  • 前綴和可能溢位（本題範圍內 int 足夠，但大資料要用 long）

補充說明

前綴和 + HashMap 的四種變形

📝 記住這張表就能解一整類題
題型                   HashMap 存什麼        查詢什麼
--------------------------------------------------------------
#560 和為 k 的個數      前綴和 → 出現次數     prefix - k
#325 和為 k 的最長長度  前綴和 → 最早索引     prefix - k，取 i - idx
#523 和為 k 的倍數      前綴和%k → 最早索引   相同餘數
#974 可被 k 整除的個數  前綴和%k → 出現次數   相同餘數

【核心公式】
  sum(i..j) = prefix[j+1] - prefix[i]

【求個數】存次數；【求長度】存最早出現的索引

注意 #523/#974 取餘數時，負數要修正：
  ((sum % k) + k) % k

#974 範例：和可被 K 整除的子陣列

int subarraysDivByK(vector<int>& nums, int k) {
    unordered_map<int,int> count;
    count[0] = 1;
    int prefix = 0, result = 0;
    for (int num : nums) {
        prefix += num;
        int mod = ((prefix % k) + k) % k;   // 處理負數餘數
        result += count[mod];               // 相同餘數 → 差值可被 k 整除
        count[mod]++;
    }
    return result;
}

原理：若 prefix[j] ≡ prefix[i] (mod k)，
      則 (prefix[j] - prefix[i]) % k == 0

什麼時候用滑動視窗、什麼時候用前綴和？

  • 全為正數 + 求最短/最長 → 滑動視窗（#209），O(n) 且 O(1) 空間
  • 含負數 或 求「個數」 → 前綴和 + HashMap（本題），O(n) 但需 O(n) 空間
  • 多次區間查詢、陣列不變 → 純前綴和陣列（#303）
  • 多次區間查詢、陣列會變 → 樹狀陣列 / 線段樹
