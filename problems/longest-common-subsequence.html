#1143 Longest Common Subsequence

Medium
Dynamic Programming String

題目描述

給定兩個字串 text1 和 text2，返回這兩個字串的最長公共子序列的長度。如果不存在公共子序列，返回 0。

子序列是指這樣一個新字串：它是由原字串在不改變字元相對順序的情況下刪除某些字元（也可以不刪除任何字元）後組成的新字串。

例如 "ace" 是 "abcde" 的子序列，但 "aec" 不是。兩個字串的公共子序列是這兩個字串所共同擁有的子序列。

這是二維字串 DP 的模板題，掌握它就能解一整類題目。

範例

範例 1：
輸入：text1 = "abcde", text2 = "ace"
輸出：3
解釋：最長公共子序列是 "ace"，長度為 3。
範例 2：
輸入：text1 = "abc", text2 = "abc"
輸出：3
範例 3：
輸入：text1 = "abc", text2 = "def"
輸出：0

解題思路

💡 狀態定義（DP 最重要的一步）
dp[i][j] = text1 的【前 i 個字元】與 text2 的【前 j 個字元】
           的最長公共子序列長度

⭐ 用「前 i 個」而不是「以 i 結尾」，
   好處是 dp[0][*] 和 dp[*][0] 天然代表空字串，邊界為 0，
   不需要特別初始化第一行第一列。
   （代價是 dp 的索引 i 對應字串的 i-1 位置，要小心）

狀態轉移方程

🎯 兩種情況
情況 1：text1[i-1] == text2[j-1]（最後一個字元相同）
    dp[i][j] = dp[i-1][j-1] + 1

    這個共同字元一定可以放進 LCS，
    剩下的問題是前面 i-1 和 j-1 的 LCS。

情況 2：text1[i-1] != text2[j-1]（最後一個字元不同）
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    這兩個字元不可能同時出現在 LCS 的結尾，
    所以至少要「放棄其中一個」，取兩種放棄方式中較好的。

    dp[i-1][j] = 放棄 text1 的第 i 個字元
    dp[i][j-1] = 放棄 text2 的第 j 個字元

完整 DP 表格：text1 = "abcde", text2 = "ace"

📊 手推一次就懂了
        ""   a    c    e
   ""   0    0    0    0
   a    0    1    1    1
   b    0    1    1    1
   c    0    1    2    2
   d    0    1    2    2
   e    0    1    2    3   ← 答案

逐格說明幾個關鍵：

dp[1][1]: 'a' == 'a' → dp[0][0] + 1 = 1
dp[2][1]: 'b' != 'a' → max(dp[1][1], dp[2][0]) = max(1, 0) = 1
dp[3][2]: 'c' == 'c' → dp[2][1] + 1 = 1 + 1 = 2
dp[5][3]: 'e' == 'e' → dp[4][2] + 1 = 2 + 1 = 3 ✓

答案 dp[5][3] = 3（"ace"）

空間優化：滾動陣列

⚡ O(mn) → O(min(m,n))
觀察轉移方程，dp[i][j] 只依賴：
  dp[i-1][j-1]（左上）
  dp[i-1][j]  （正上）
  dp[i][j-1]  （左邊）

也就是只需要「上一行」和「當前行左邊」的資料，
可以壓成一維陣列，用一個變數暫存左上角的值。

for i in 1..m:
    prev = 0                    # 代表 dp[i-1][j-1]
    for j in 1..n:
        temp = dp[j]            # 先存下舊值（將成為下一輪的左上）
        if 字元相同: dp[j] = prev + 1
        else:        dp[j] = max(dp[j], dp[j-1])
        prev = temp

程式碼實現

# 方法一：二維 DP（推薦，最清晰）
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        # dp[i][j] = text1 前 i 個 與 text2 前 j 個 的 LCS 長度
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1        # 字元相同
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])  # 放棄其一

        return dp[m][n]


# 方法二：一維滾動陣列（空間 O(n)）
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        dp = [0] * (n + 1)

        for i in range(1, m + 1):
            prev = 0                       # 代表 dp[i-1][j-1]（左上）
            for j in range(1, n + 1):
                temp = dp[j]               # 保存舊的 dp[i-1][j]
                if text1[i - 1] == text2[j - 1]:
                    dp[j] = prev + 1
                else:
                    dp[j] = max(dp[j], dp[j - 1])
                prev = temp

        return dp[n]

class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;          // 字元相同
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]); // 放棄其一
                }
            }
        }
        return dp[m][n];
    }
};

// 方法一：二維 DP（推薦）
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;              // 相同
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]); // 不同
                }
            }
        }
        return dp[m][n];
    }
}

複雜度分析

時間複雜度：O(m × n)
  • 填滿整個 DP 表格，每格 O(1)
  • 這是本問題的已知最佳複雜度（在一般情況下）
空間複雜度：
  • 二維 DP：O(m × n)
  • 滾動陣列：O(min(m, n)) ★（把較短的字串放在內層）

重點提示

💡 關鍵技巧 1：「前 i 個」的狀態定義

用 dp[i][j] = 前 i 個 vs 前 j 個（而非「以 i 結尾」），可以讓 dp[0][j] = dp[i][0] = 0 自然成立，省去繁瑣的邊界初始化。代價是索引要記得 text1[i-1]，這是最容易寫錯的地方。

💡 關鍵技巧 2：子序列 vs 子串的 DP 差異
  • 子序列（本題，可不連續）：不匹配時 dp[i][j] = max(dp[i-1][j], dp[i][j-1])，資訊可以「繼承」
  • 子串（#718，必須連續）：不匹配時 dp[i][j] = 0，必須「歸零重來」，答案要在過程中取最大值

這是這兩類題目最核心的差別。

💡 如何印出 LCS 本身而不只是長度？

從 dp[m][n] 往回走：若字元相同就把它加入結果並往左上；否則往「值較大」的那一邊走。最後把結果反轉。這叫 DP 路徑回溯，是很常見的追問。

⚠️ 常見錯誤：
  • 索引寫成 text1[i] 而非 text1[i-1]（差一錯誤）
  • 陣列大小開成 [m][n] 而非 [m+1][n+1]
  • 迴圈從 0 開始（應該從 1 開始，0 是邊界）
  • 把子序列問題誤當成子串問題（不匹配時錯誤地歸零）

題目           dp 定義                 相同時          不同時

⭐ 掌握 #1143 和 #72 這兩題，
   整個二維字串 DP 家族就通了。

回溯出 LCS 字串本身

string getLCS(string& s1, string& s2, vector<vector<int>>& dp) {
    string lcs;
    int i = s1.size(), j = s2.size();
    while (i > 0 && j > 0) {
        if (s1[i-1] == s2[j-1]) {
            lcs += s1[i-1];       // 這個字元在 LCS 中
            i--; j--;             // 往左上走
        } else if (dp[i-1][j] >= dp[i][j-1]) {
            i--;                  // 往上走
        } else {
            j--;                  // 往左走
        }
    }
    reverse(lcs.begin(), lcs.end());
    return lcs;
}

複雜度 O(m + n)，因為每步至少讓 i 或 j 減 1。

實務應用：diff 工具

🔧 git diff 的核心演算法
把「每一行」當成一個字元，對兩個檔案求 LCS：
  - 在 LCS 中的行 = 沒有變動（context）
  - 只在舊檔案中的行 = 被刪除（-）
  - 只在新檔案中的行 = 新增（+）

舊檔案：A B C D E
新檔案：A C E F
LCS：   A C E

diff 輸出：
   A
  -B
   C
  -D
   E
  +F

實務上 git 用的是 Myers diff 演算法，
它是 LCS 的優化版，複雜度 O((m+n)D)，
D 是編輯距離 —— 對「改動不多」的常見情況特別快。

其他應用：DNA 序列比對、抄襲偵測、拼字檢查、版本合併。
