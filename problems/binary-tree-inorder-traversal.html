#94 Binary Tree Inorder Traversal

Easy
Tree Stack DFS Binary Tree

題目描述

給定一個二元樹的根節點 root，返回它的中序遍歷結果。

中序遍歷的順序是：左子樹 → 根節點 → 右子樹。

進階：遞迴演算法很簡單，你可以用迭代演算法完成嗎？更進一步，能否用 O(1) 空間（Morris 遍歷）？

範例

範例 1：
輸入：root = [1,null,2,3]

    1
     \
      2
     /
    3

輸出：[1,3,2]
範例 2：
輸入：root = []
輸出：[]
範例 3：
輸入：root = [1]
輸出：[1]

解題思路

💡 三種遍歷的差別只在「處理根節點的時機」
        1
       / \
      2   3
     / \
    4   5

前序（Pre-order）  根 → 左 → 右   [1, 2, 4, 5, 3]
中序（In-order）   左 → 根 → 右   [4, 2, 5, 1, 3]
後序（Post-order） 左 → 右 → 根   [4, 5, 2, 3, 1]

遞迴寫法幾乎一模一樣，只是 visit(root) 那行的位置不同：

void inorder(node) {
    if (!node) return;
    inorder(node->left);
    visit(node);              ← 中序：放中間
    inorder(node->right);
}

迭代法：用堆疊模擬遞迴

一路向左壓入堆疊，彈出時處理，再轉向右
        1
       / \
      2   3
     /
    4

cur = 1, stack = []

步驟 1：一路向左壓入
  push 1, cur = 2
  push 2, cur = 4
  push 4, cur = null
  stack = [1, 2, 4]

步驟 2：cur 為 null，彈出並處理
  pop 4 → 輸出 4，cur = 4.right = null
  pop 2 → 輸出 2，cur = 2.right = null
  pop 1 → 輸出 1，cur = 1.right = 3

步驟 3：cur = 3，重複步驟 1
  push 3, cur = null
  pop 3 → 輸出 3

結果 [4, 2, 1, 3] ✓

Morris 遍歷：O(1) 空間的黑魔法

🪄 用「線索」暫時改造樹的結構
核心想法：把每個節點的「中序前驅」的右指標，
          暫時指向該節點，走完再還原。

對當前節點 cur：
  1. 若 cur 沒有左子樹 → 輸出 cur，往右走
  2. 若 cur 有左子樹：
     找到左子樹中最右邊的節點（= cur 的中序前驅 pred）
     - 若 pred.right == null：
         建立線索 pred.right = cur，往左走
     - 若 pred.right == cur（第二次遇到，代表左子樹走完了）：
         拆除線索 pred.right = null，輸出 cur，往右走

    1
   /
  2
 /
3

cur=1，左子樹最右 = 3，建線索 3.right = 1，cur = 2
cur=2，左子樹最右 = 3，建線索 3.right = 2，cur = 3
cur=3，無左子樹 → 輸出 3，沿線索回到 2
cur=2，pred=3 且 3.right==2 → 拆線索，輸出 2，往右（線索）到 1
cur=1，...輸出 1

空間 O(1)，但會暫時修改樹的結構，
在多執行緒環境下不安全。

程式碼實現

# 方法一：遞迴（最簡潔）
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []

        def dfs(node):
            if not node:
                return
            dfs(node.left)          # 左
            result.append(node.val)  # 根
            dfs(node.right)         # 右

        dfs(root)
        return result


# 方法二：迭代 + 堆疊（面試常考）
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result, stack = [], []
        cur = root

        while cur or stack:
            # 一路向左壓入堆疊
            while cur:
                stack.append(cur)
                cur = cur.left
            # 彈出並處理，然後轉向右子樹
            cur = stack.pop()
            result.append(cur.val)
            cur = cur.right

        return result


# 方法三：Morris 遍歷（O(1) 空間）
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []
        cur = root

        while cur:
            if not cur.left:
                result.append(cur.val)      # 沒有左子樹，直接輸出
                cur = cur.right
            else:
                # 找中序前驅：左子樹中最右邊的節點
                pred = cur.left
                while pred.right and pred.right is not cur:
                    pred = pred.right

                if not pred.right:
                    pred.right = cur        # 建立線索
                    cur = cur.left
                else:
                    pred.right = None       # 拆除線索
                    result.append(cur.val)
                    cur = cur.right

        return result
// 方法一：遞迴
class Solution {
    void dfs(TreeNode* node, vector<int>& result) {
        if (!node) return;
        dfs(node->left, result);        // 左
        result.push_back(node->val);    // 根
        dfs(node->right, result);       // 右
    }
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        dfs(root, result);
        return result;
    }
};

// 方法二：迭代 + 堆疊（推薦）
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> stk;
        TreeNode* cur = root;

        while (cur || !stk.empty()) {
            while (cur) {               // 一路向左
                stk.push(cur);
                cur = cur->left;
            }
            cur = stk.top(); stk.pop();
            result.push_back(cur->val); // 處理根
            cur = cur->right;           // 轉向右
        }
        return result;
    }
};

// 方法三：Morris 遍歷（O(1) 空間）
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        TreeNode* cur = root;
        while (cur) {
            if (!cur->left) {
                result.push_back(cur->val);
                cur = cur->right;
            } else {
                TreeNode* pred = cur->left;
                while (pred->right && pred->right != cur) pred = pred->right;
                if (!pred->right) {
                    pred->right = cur;          // 建立線索
                    cur = cur->left;
                } else {
                    pred->right = nullptr;      // 拆除線索
                    result.push_back(cur->val);
                    cur = cur->right;
                }
            }
        }
        return result;
    }
};
// 方法一：遞迴
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        dfs(root, result);
        return result;
    }

    private void dfs(TreeNode node, List<Integer> result) {
        if (node == null) return;
        dfs(node.left, result);      // 左
        result.add(node.val);        // 根
        dfs(node.right, result);     // 右
    }
}

// 方法二：迭代 + 堆疊（推薦）
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;

        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {        // 一路向左
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();
            result.add(cur.val);         // 處理根
            cur = cur.right;             // 轉向右
        }
        return result;
    }
}
/**
 * Definition for a binary tree node.
 * class TreeNode {
 *     val: number
 *     left: TreeNode | null
 *     right: TreeNode | null
 * }
 */
// 迭代：用堆疊模擬遞迴（左 → 根 → 右）
// 時間複雜度: O(n)，空間複雜度: O(h)
function inorderTraversal(root: TreeNode | null): number[] {
    const result: number[] = [];
    const stack: TreeNode[] = [];
    let cur = root;

    while (cur || stack.length) {
        while (cur) {            // 一路往左走到底
            stack.push(cur);
            cur = cur.left;
        }
        const node = stack.pop()!;
        result.push(node.val);   // 訪問根
        cur = node.right;        // 轉向右子樹
    }
    return result;
}
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */
// 迭代：用堆疊模擬遞迴（左 → 根 → 右）
// 時間複雜度: O(n)，空間複雜度: O(h)
int* inorderTraversal(struct TreeNode* root, int* returnSize) {
    int* result = malloc(sizeof(int) * 100);       // 題目限制節點數 ≤ 100
    struct TreeNode* stack[100];
    int top = 0;
    *returnSize = 0;
    struct TreeNode* cur = root;

    while (cur || top > 0) {
        while (cur) {                              // 一路往左走到底
            stack[top++] = cur;
            cur = cur->left;
        }
        struct TreeNode* node = stack[--top];
        result[(*returnSize)++] = node->val;       // 訪問根
        cur = node->right;                         // 轉向右子樹
    }
    return result;
}

複雜度分析

時間複雜度：O(n)
  • 每個節點恰好被訪問一次
  • Morris 遍歷雖然會走一些節點兩次，但總計仍是 O(n)
空間複雜度：
  • 遞迴：O(h)，h 為樹高；最壞（退化成鏈）O(n)
  • 迭代：O(h)，堆疊最多存一條路徑
  • Morris：O(1) ★

重點提示

💡 關鍵技巧 1：BST 的中序遍歷是遞增序列

這是二元搜尋樹最重要的性質！#98 驗證 BST、#230 第 k 小元素、#530 最小絕對差、#173 BST 迭代器全都建立在這個性質上。看到 BST 就先想中序遍歷。

💡 關鍵技巧 2：迭代版的兩層迴圈

外層 while (cur || !stack.empty())、內層 while (cur) 一路向左。這個雙層結構是中序迭代的標準模板，寫熟了前序、後序也能舉一反三。

💡 面試回答策略

先寫遞迴（30 秒），主動說「但如果樹很深會 stack overflow，我改寫迭代版」，再寫堆疊版。若還有時間可以提 Morris 遍歷達到 O(1) 空間。這個層層遞進的回答方式非常加分。

⚠️ 常見錯誤：
  • 迭代版忘記在彈出後轉向 cur = cur.right，導致無限迴圈
  • 外層迴圈條件只寫 !stack.empty()，一開始堆疊是空的會直接跳出
  • Morris 遍歷忘記拆除線索，導致樹的結構被永久破壞
  • Morris 找前驅時的條件 pred.right != cur 漏掉，會無限迴圈

補充說明

三種遍歷的迭代寫法對照

📝 前序最簡單，後序最麻煩
【前序 - 最簡單】根 → 左 → 右
  push(root)
  while (!stack.empty()) {
      node = pop();  visit(node);
      push(node.right);   // 先壓右
      push(node.left);    // 後壓左（後進先出，左先出）
  }

【中序 - 標準模板】左 → 根 → 右
  while (cur || !stack.empty()) {
      while (cur) { push(cur); cur = cur.left; }
      cur = pop();  visit(cur);
      cur = cur.right;
  }

【後序 - 取巧解法】左 → 右 → 根
  用前序的變形：根 → 右 → 左，最後把結果反轉
  = 左 → 右 → 根 ✓
  （只要把前序的左右壓入順序對調，再 reverse 結果）

統一模板：用標記法處理三種遍歷

# 用 (節點, 是否已展開) 的標記，三種遍歷只要調整壓入順序
def traversal(root):
    result, stack = [], [(root, False)]
    while stack:
        node, visited = stack.pop()
        if not node:
            continue
        if visited:
            result.append(node.val)     # 真正處理節點
        else:
            # 中序：右 → 根 → 左（因為堆疊後進先出，順序要反著壓）
            stack.append((node.right, False))
            stack.append((node, True))
            stack.append((node.left, False))
            # 前序：改成 右, 左, (node,True)
            # 後序：改成 (node,True), 右, 左
    return result

優點：三種遍歷只需要改三行的順序，不用記三套模板。

應用：BST 迭代器（#173）

把中序迭代的堆疊「凍結」在類別成員中，每次呼叫 next() 就往前走一步。這樣可以達到攤銷 O(1) 的 next() 和 O(h) 的空間，而不需要一次把整棵樹展開成陣列。這在處理超大型 BST 或需要惰性求值（lazy evaluation）時非常實用。
