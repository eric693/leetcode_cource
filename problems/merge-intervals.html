#56 Merge Intervals

Medium
Array Sorting Interval

題目描述

以陣列 intervals 表示若干個區間的集合，其中單個區間為 intervals[i] = [starti, endi]。請你合併所有重疊的區間，並返回一個不重疊的區間陣列，該陣列需恰好覆蓋輸入中的所有區間。

範例

範例 1：
輸入：intervals = [[1,3],[2,6],[8,10],[15,18]]
輸出：[[1,6],[8,10],[15,18]]
解釋：[1,3] 和 [2,6] 重疊，合併為 [1,6]。
範例 2：
輸入：intervals = [[1,4],[4,5]]
輸出：[[1,5]]
解釋：端點接觸也算重疊。

解題思路

💡 核心：先按起點排序，再貪心合併
排序後，只需要和「結果中的最後一個區間」比較即可，
因為起點已經遞增，不可能和更早的區間重疊。

intervals = [[1,3],[2,6],[8,10],[15,18]]（已按起點排序）

result = [[1,3]]

看 [2,6]：2 <= 3（重疊）→ 合併，end 取 max(3,6)=6
result = [[1,6]]

看 [8,10]：8 > 6（不重疊）→ 直接加入
result = [[1,6],[8,10]]

看 [15,18]：15 > 10（不重疊）→ 直接加入
result = [[1,6],[8,10],[15,18]] ✓

判斷重疊的條件

🎯 排序後只需一個條件
排序後 cur.start >= last.start 恆成立，
所以重疊 ⟺ cur.start <= last.end

情況一：包含      last [1......10]
                  cur     [3, 5]
                  合併後 [1, 10]  ← end 要取 max！

情況二：部分重疊  last [1, 5]
                  cur     [3, 8]
                  合併後 [1, 8]

情況三：不重疊    last [1, 3]
                  cur        [5, 8]
                  各自保留

💡 情況一就是為什麼一定要寫 max(last.end, cur.end)，
   直接寫 cur.end 會把 [1,10] 錯誤縮成 [1,5]。

為什麼排序是必要的？

不排序的話，一個新區間可能和任何已存在的區間重疊，需要 O(n²) 兩兩比較。排序後有了單調性，只要比較最後一個，降為 O(n log n)。

程式碼實現

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        # 1. 按起點排序
        intervals.sort(key=lambda x: x[0])

        result = []
        for start, end in intervals:
            # 不重疊：直接加入
            if not result or start > result[-1][1]:
                result.append([start, end])
            else:
                # 重疊：延伸結尾（一定要取 max，處理包含關係）
                result[-1][1] = max(result[-1][1], end)
        return result
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        // 1. 按起點排序
        sort(intervals.begin(), intervals.end());

        vector<vector<int>> result;
        for (const auto& iv : intervals) {
            // 不重疊：直接加入
            if (result.empty() || iv[0] > result.back()[1]) {
                result.push_back(iv);
            } else {
                // 重疊：延伸結尾（取 max 處理包含關係）
                result.back()[1] = max(result.back()[1], iv[1]);
            }
        }
        return result;
    }
};
class Solution {
    public int[][] merge(int[][] intervals) {
        // 1. 按起點排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> result = new ArrayList<>();
        for (int[] iv : intervals) {
            // 不重疊：直接加入
            if (result.isEmpty() || iv[0] > result.get(result.size() - 1)[1]) {
                result.add(iv);
            } else {
                // 重疊：延伸結尾
                int[] last = result.get(result.size() - 1);
                last[1] = Math.max(last[1], iv[1]);
            }
        }
        return result.toArray(new int[result.size()][]);
    }
}
// 依起點排序，與結果中最後一個區間比較是否重疊
// 時間複雜度: O(n log n)，空間複雜度: O(n)
function merge(intervals: number[][]): number[][] {
    intervals.sort((a, b) => a[0] - b[0]);
    const result: number[][] = [];
    for (const [start, end] of intervals) {
        const last = result[result.length - 1];
        if (last && start <= last[1]) last[1] = Math.max(last[1], end);
        else result.push([start, end]);
    }
    return result;
}
// 依起點排序，與結果中最後一個區間比較是否重疊
// 時間複雜度: O(n log n)，空間複雜度: O(n)
static int cmp(const void* a, const void* b) {
    int x = (*(int* const*)a)[0], y = (*(int* const*)b)[0];
    return (x > y) - (x < y);
}

int** merge(int** intervals, int intervalsSize, int* intervalsColSize,
            int* returnSize, int** returnColumnSizes) {
    qsort(intervals, intervalsSize, sizeof(int*), cmp);
    int** result = malloc(sizeof(int*) * intervalsSize);
    *returnColumnSizes = malloc(sizeof(int) * intervalsSize);
    int cnt = 0;

    for (int i = 0; i < intervalsSize; i++) {
        int start = intervals[i][0], end = intervals[i][1];
        if (cnt > 0 && start <= result[cnt - 1][1]) {
            if (end > result[cnt - 1][1]) result[cnt - 1][1] = end;
        } else {
            result[cnt] = malloc(sizeof(int) * 2);
            result[cnt][0] = start;
            result[cnt][1] = end;
            (*returnColumnSizes)[cnt++] = 2;
        }
    }
    *returnSize = cnt;
    return result;
}

複雜度分析

時間複雜度：O(n log n)
  • 排序 O(n log n) 為主要成本
  • 單趟合併只需 O(n)
空間複雜度：O(log n) ~ O(n)
  • 排序所需的堆疊空間
  • 不計算輸出陣列的話為 O(log n)

重點提示

💡 關鍵技巧 1：一定要用 max 更新結尾

[[1,10],[2,3]] 排序後若直接寫 result[-1][1] = end，會把 [1,10] 縮成 [1,3]，答案就錯了。這是本題最常見的 bug。

💡 關鍵技巧 2：端點接觸算不算重疊？

本題 [1,4] 和 [4,5] 要合併，所以條件是 start > last.end 才算不重疊。但有些題目（如會議室安排）端點接觸不算衝突，要用 start >= last.end。務必先問清楚題目定義。

⚠️ 常見錯誤：
  • 忘記先排序
  • 更新結尾時沒取 max
  • 邊界條件 > 和 >= 用錯
  • Java 用 (a,b) -> a[0] - b[0] 在極端值時會整數溢位，建議用 Integer.compare

區間題型四大套路

📝 看到區間題先想這四招
1【按起點排序 + 貪心合併】→ #56 合併區間
   排序後只需比較最後一個

2【按終點排序 + 貪心選擇】→ #435 最少刪除、活動選擇問題
   每次選結束最早的，能留下最多區間

3【差分陣列 / 掃描線】→ #253 會議室 II、#1094 拼車
   進入 +1、離開 -1，掃描過程中的最大值就是答案
   events = [(s, +1), (e, -1)]，排序後累加

4【最小堆積】→ #253 另一種解法
   堆積存放每間會議室的結束時間，
   新會議來時看最早結束的房間是否已空出

判斷兩區間 [a,b] 與 [c,d] 是否重疊的通用式：
   重疊 ⟺ a <= d && c <= b
   （等價於 NOT (b < c || d < a)）

#253 會議室 II 的掃描線解法

int minMeetingRooms(vector<vector<int>>& intervals) {
    vector<pair<int,int>> events;
    for (auto& iv : intervals) {
        events.push_back({iv[0], 1});    // 會議開始，佔用 +1
        events.push_back({iv[1], -1});   // 會議結束，釋放 -1
    }
    sort(events.begin(), events.end());  // 同時間點時 -1 排在 +1 前（結束優先）
    int cur = 0, maxRooms = 0;
    for (auto& [t, delta] : events) {
        cur += delta;
        maxRooms = max(maxRooms, cur);
    }
    return maxRooms;
}
