#137 Single Number II

Medium
Bit Manipulation Array

題目描述

給你一個整數陣列 nums，除某個元素僅出現一次外，其餘每個元素都恰好出現三次。請你找出並返回那個只出現了一次的元素。

你必須設計並實現線性時間複雜度 O(n) 的演算法，且使用常數級 O(1) 的額外空間來解決此問題。

範例

範例 1：
輸入：nums = [2,2,3,2]
輸出：3
範例 2：
輸入：nums = [0,1,0,1,0,1,99]
輸出：99

解題思路

⚠️ 為什麼不能用 XOR？

#136 Single Number 出現兩次，XOR 剛好互相抵消。但這題出現三次，XOR 三次等於自己（a^a^a = a），無法抵消，所以要換方法。

方法一：位元計數（最好理解，面試首選）

💡 每一位的 1 的總數 % 3
出現 3 次的數字，在每一個位元上都貢獻 3 個（或 0 個）1
所以把所有數字的第 i 位加總後 % 3，剩下的就是答案的第 i 位！

nums = [2, 2, 3, 2]
       2 = 010
       2 = 010
       3 = 011
       2 = 010

第 0 位：0+0+1+0 = 1, 1 % 3 = 1  → 答案第 0 位 = 1
第 1 位：1+1+1+1 = 4, 4 % 3 = 1  → 答案第 1 位 = 1
第 2 位：0             0 % 3 = 0  → 答案第 2 位 = 0

答案 = 011 = 3 ✓

方法二：狀態機 / 兩個變數（O(1) 空間最優解）

用 ones、twos 模擬「模 3 計數器」
我們要一個「每一位獨立的三進位計數器」，
用兩個變數就能表示 3 種狀態：

(twos, ones)
(0, 0) → 該位出現 0 次
(0, 1) → 該位出現 1 次
(1, 0) → 該位出現 2 次
出現第 3 次時回到 (0, 0)

轉移公式：
ones = (ones ^ num) & ~twos
twos = (twos ^ num) & ~ones

跑完後 ones 就是只出現一次的數字。

追蹤 nums = [2,2,3,2]，只看第 1 位（值都是 1,1,1,1）：
初始 ones=0 twos=0
num第1位=1: ones=(0^1)&~0=1, twos=(0^1)&~1=0  → (0,1) 出現1次
num第1位=1: ones=(1^1)&~0=0, twos=(0^1)&~0=1  → (1,0) 出現2次
num第1位=1: ones=(0^1)&~1=0, twos=(1^1)&~0=0  → (0,0) 歸零 ✓
num第1位=1: ones=1                            → (0,1)
最終 ones 第 1 位 = 1 ✓

程式碼實現

# 方法一：位元計數（好理解）
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        result = 0
        for i in range(32):
            bit_sum = 0
            for num in nums:
                # 取第 i 位（用 & 0xFFFFFFFF 處理 Python 負數）
                bit_sum += (num >> i) & 1
            if bit_sum % 3:
                result |= (1 << i)
        # 處理負數：第 31 位是符號位
        if result >= (1 << 31):
            result -= (1 << 32)
        return result


# 方法二：狀態機（O(1) 空間最優）
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        ones = twos = 0
        for num in nums:
            ones = (ones ^ num) & ~twos
            twos = (twos ^ num) & ~ones
        # Python 無限位元，需手動處理負數
        return ones if ones < (1 << 31) else ones - (1 << 32)


# 方法三：用 Counter（不符合 O(1) 空間，但面試可先講）
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        from collections import Counter
        for num, cnt in Counter(nums).items():
            if cnt == 1:
                return num

// 方法二：狀態機（推薦）
class Solution {
    public int singleNumber(int[] nums) {
        int ones = 0, twos = 0;
        for (int num : nums) {
            ones = (ones ^ num) & ~twos;
            twos = (twos ^ num) & ~ones;
        }
        return ones;
    }
}
// 逐位統計：每一位 1 出現的次數 mod 3，餘下的就是只出現一次的數
// 時間複雜度: O(32n)，空間複雜度: O(1)
function singleNumber(nums: number[]): number {
    let result = 0;
    for (let bit = 0; bit < 32; bit++) {
        let count = 0;
        for (const x of nums) count += (x >> bit) & 1;
        if (count % 3) result |= 1 << bit;
    }
    return result;                          // 位元運算結果本身就是有號 32 位元
}
// 狀態機：ones / twos 記錄每一位出現 1 次 / 2 次（出現 3 次就歸零）
// 時間複雜度: O(n)，空間複雜度: O(1)
int singleNumber(int* nums, int numsSize) {
    int ones = 0, twos = 0;
    for (int i = 0; i < numsSize; i++) {
        ones = (ones ^ nums[i]) & ~twos;
        twos = (twos ^ nums[i]) & ~ones;
    }
    return ones;
}

複雜度分析

時間複雜度：
  • 方法一（位元計數）：O(32n) = O(n)
  • 方法二（狀態機）：O(n)，只跑一次陣列
空間複雜度：O(1)，只用固定數量的變數

重點提示

💡 關鍵技巧 1：位元計數是萬用解

「其他數字出現 k 次，找出現一次的」→ 每一位加總後 % k。k 換成任何數都通用，這是最容易在面試現場推導出來的方法。

💡 關鍵技巧 2：狀態機轉移的順序不能換

ones 必須先更新，因為 twos 的公式用到了「新的 ones」。順序寫反答案就錯。

⚠️ 常見錯誤：
  • Python 的整數是無限位元，~twos 對負數會出問題，最後要手動轉回 32 位元有號數
  • 方法一忘記處理負數（第 31 位是符號位）
  • 誤以為可以像 #136 那樣直接 XOR
