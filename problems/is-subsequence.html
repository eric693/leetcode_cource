#392 Is Subsequence

Easy
Two Pointers String Dynamic Programming

題目描述

給定字串 s 和 t，判斷 s 是否為 t 的子序列。

字串的子序列是原始字串刪除一些（也可以不刪除）字元而不改變剩餘字元相對位置形成的新字串。例如 "ace" 是 "abcde" 的子序列，而 "aec" 不是。

進階：如果有大量輸入的 S（稱作 S₁, S₂, ..., Sk，其中 k ≥ 10 億），你需要依次檢查它們是否為 T 的子序列。在這種情況下，你會怎樣改變程式碼？

範例

範例 1：
輸入：s = "abc", t = "ahbgdc"
輸出：true
範例 2：
輸入：s = "axc", t = "ahbgdc"
輸出：false

解題思路

💡 方法一：雙指標貪心（O(n)）
i 指向 s，j 指向 t。
j 一路往前掃，只要遇到 s[i] 就讓 i 前進。
若 i 走完 s 就代表匹配成功。

s = "abc", t = "ahbgdc"

j=0: t[0]='a' == s[0]='a' ✓ → i=1
j=1: t[1]='h' != s[1]='b'   → i 不動
j=2: t[2]='b' == s[1]='b' ✓ → i=2
j=3: t[3]='g' != s[2]='c'   → i 不動
j=4: t[4]='d' != 'c'        → i 不動
j=5: t[5]='c' == s[2]='c' ✓ → i=3

i == len(s) → true ✓

【為什麼貪心是對的？】
遇到能匹配的字元就立刻匹配，一定不會比「跳過它、
等後面再匹配」更差 —— 因為越早匹配，留給後續字元
的選擇空間越大。這是典型的交換論證（exchange argument）。

方法二：預處理 + 二分搜尋（回答進階題）

🎯 大量查詢時的標準答案
如果有 10 億個 s 要對同一個 t 查詢，
每次都掃一遍 t 就是 O(k × n)，太慢。

【預處理】對 t 建立索引表：
  pos[c] = t 中所有字元 c 出現的位置（遞增）

t = "ahbgdc"
  pos['a'] = [0]
  pos['b'] = [2]
  pos['c'] = [5]
  pos['d'] = [4]
  pos['g'] = [3]
  pos['h'] = [1]

【查詢】s = "abc"，維護當前位置 cur = -1
  'a': 在 pos['a'] 中二分找 > -1 的最小值 → 0，cur = 0
  'b': 在 pos['b'] 中二分找 > 0 的最小值  → 2，cur = 2
  'c': 在 pos['c'] 中二分找 > 2 的最小值  → 5，cur = 5
  全部找到 → true ✓

複雜度：預處理 O(n)，每次查詢 O(|s| × log n)
        總計 O(n + k × |s| × log n)，遠優於 O(k × n)

方法三：DP 狀態機（更快的查詢）

⚡ 每次查詢降到 O(|s|)
預處理一張表：
  nxt[i][c] = 從 t 的位置 i 開始，字元 c 第一次出現的位置
              （不存在則為 n）

從後往前遞推：
  nxt[i][c] = i     if t[i] == c
            = nxt[i+1][c]  otherwise

查詢時直接跳轉，每個字元 O(1)：
  cur = nxt[cur][s[i]] + 1

預處理 O(n × 26) 空間與時間，
換來每次查詢 O(|s|)，這是最快的做法。

程式碼實現

# 方法一：雙指標（推薦，單次查詢最佳）
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        i = 0
        for ch in t:
            if i < len(s) and s[i] == ch:
                i += 1
        return i == len(s)


# 方法二：預處理 + 二分（大量查詢用）
class Solution:
    def __init__(self):
        self.pos = None

    def isSubsequence(self, s: str, t: str) -> bool:
        import bisect
        from collections import defaultdict

        # 預處理：記錄每個字元出現的所有位置
        if self.pos is None:
            self.pos = defaultdict(list)
            for i, ch in enumerate(t):
                self.pos[ch].append(i)

        cur = -1
        for ch in s:
            lst = self.pos.get(ch)
            if not lst:
                return False
            # 找第一個 > cur 的位置
            idx = bisect.bisect_right(lst, cur)
            if idx == len(lst):
                return False
            cur = lst[idx]
        return True
// 方法一：雙指標（推薦）
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int i = 0;
        for (char c : t) {
            if (i < s.size() && s[i] == c) i++;
        }
        return i == s.size();
    }
};

// 方法三：DP 狀態機（大量查詢，每次 O(|s|)）
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int n = t.size();
        // nxt[i][c]：從位置 i 起字元 c 第一次出現的位置
        vector<vector<int>> nxt(n + 1, vector<int>(26, n));
        for (int i = n - 1; i >= 0; i--) {
            for (int c = 0; c < 26; c++) nxt[i][c] = nxt[i + 1][c];
            nxt[i][t[i] - 'a'] = i;
        }

        int cur = 0;
        for (char c : s) {
            if (nxt[cur][c - 'a'] == n) return false;   // 找不到
            cur = nxt[cur][c - 'a'] + 1;                // 跳到下一個位置
        }
        return true;
    }
};
// 方法一：雙指標（推薦）
class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0;
        for (int j = 0; j < t.length(); j++) {
            if (i < s.length() && s.charAt(i) == t.charAt(j)) {
                i++;
            }
        }
        return i == s.length();
    }
}

// 方法三：DP 狀態機
class Solution {
    public boolean isSubsequence(String s, String t) {
        int n = t.length();
        int[][] nxt = new int[n + 1][26];
        Arrays.fill(nxt[n], n);
        for (int i = n - 1; i >= 0; i--) {
            nxt[i] = nxt[i + 1].clone();
            nxt[i][t.charAt(i) - 'a'] = i;
        }

        int cur = 0;
        for (char c : s.toCharArray()) {
            if (nxt[cur][c - 'a'] == n) return false;
            cur = nxt[cur][c - 'a'] + 1;
        }
        return true;
    }
}
// 雙指標：t 一路往前走，遇到相同字元時 s 的指標前進
// 時間複雜度: O(|t|)，空間複雜度: O(1)
function isSubsequence(s: string, t: string): boolean {
    let i = 0;
    for (let j = 0; j < t.length && i < s.length; j++) {
        if (s[i] === t[j]) i++;
    }
    return i === s.length;
}
// 雙指標：t 一路往前走，遇到相同字元時 s 的指標前進
// 時間複雜度: O(|t|)，空間複雜度: O(1)
bool isSubsequence(char* s, char* t) {
    while (*s && *t) {
        if (*s == *t) s++;
        t++;
    }
    return *s == '\0';
}

複雜度分析

時間複雜度：
  • 雙指標：O(n)，n 為 t 的長度
  • 二分法：預處理 O(n)，每次查詢 O(|s| log n)
  • DP 狀態機：預處理 O(26n)，每次查詢 O(|s|)
空間複雜度：
  • 雙指標：O(1) ★
  • 二分法：O(n)
  • DP 狀態機：O(26n)

重點提示

💡 關鍵技巧 1：子序列 vs 子字串

子序列可以不連續但要保持順序（本題）；子字串必須連續。看題目時務必分清楚，兩者的解法完全不同。

💡 關鍵技巧 2：進階題才是重點

單看主題目非常簡單，面試官真正想考的是進階問題：「大量查詢怎麼優化？」答案是「預處理 t 建索引」。這體現了一個重要的系統設計思維：當查詢遠多於更新時，就用空間換時間做預處理（就像資料庫建索引）。

⚠️ 常見錯誤：
  • 雙指標時忘記檢查 i < len(s) 而越界
  • 把子序列誤解成子字串
  • 沒注意到空字串 s 是任何字串的子序列（本解法自然返回 true）

補充說明

DP 解法（雖然不需要，但理解它有助於解相關題）

📐 dp[i][j] = s 前 i 個字元是否為 t 前 j 個的子序列
狀態轉移：
  若 s[i-1] == t[j-1]：dp[i][j] = dp[i-1][j-1]
  否則：               dp[i][j] = dp[i][j-1]   （跳過 t 的這個字元）

邊界：dp[0][j] = true（空字串是任何字串的子序列）
      dp[i][0] = false（非空字串不可能是空字串的子序列）

答案：dp[m][n]

複雜度 O(mn)，比雙指標差很多，
但這個框架可以直接改成 #1143（最長公共子序列）
和 #115（子序列計數），值得掌握。

#792 Number of Matching Subsequences 的巧解

給一堆 words，問有幾個是 s 的子序列。

【桶排序法】把每個 word 依「當前待匹配的字元」分桶，
掃描 s 一次，每個字元把對應桶裡的所有 word 往前推一格：

buckets[26]  // buckets[c] 存放「下一個要匹配 c」的所有 word

for (char c : s) {
    auto old = buckets[c - 'a'];
    buckets[c - 'a'].clear();
    for (auto& it : old) {
        it.advance();                    // 指標前進
        if (it.done()) count++;          // 完全匹配
        else buckets[it.current()].push_back(it);
    }
}

複雜度 O(|s| + 所有 word 的總長度)，非常漂亮。

面試思維：預處理的取捨

  • 單次查詢 → 雙指標，O(n) 時間 O(1) 空間，最簡潔
  • 少量查詢 → 仍用雙指標，預處理成本不划算
  • 大量查詢 → 二分或 DP 狀態機，預處理成本被攤平
  • t 會頻繁變動 → 預處理反而是負擔，回到雙指標

能講出這個取捨分析，比單純寫出程式碼更能展現工程判斷力。
