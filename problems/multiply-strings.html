#43 Multiply Strings

Medium
String Math Simulation

題目描述

給定兩個以字串形式表示的非負整數 num1 和 num2，返回 num1 和 num2 的乘積，它們的乘積也表示為字串形式。

注意：不能使用任何內建的 BigInteger 函式庫或直接將輸入轉換為整數。

字串長度可達 200，遠遠超過 64 位元整數的範圍，所以這題本質上是在手動實作大數乘法。

範例

範例 1：
輸入：num1 = "2", num2 = "3"
輸出："6"
範例 2：
輸入：num1 = "123", num2 = "456"
輸出："56088"
範例 3：
輸入：num1 = "0", num2 = "12345"
輸出："0"

解題思路

💡 核心：優化過的直式乘法
【關鍵觀察】
num1[i] × num2[j] 的結果，
一定落在答案的第 (i + j) 和 (i + j + 1) 這兩個位置！

  m 位數 × n 位數 → 最多 m + n 位數

    1 2 3        索引 i: 0 1 2
  × 4 5 6        索引 j: 0 1 2
  ---------
  結果陣列索引:  0 1 2 3 4    （長度 3 + 3 = 5）

例：i=2 (數字3), j=2 (數字6)
    3 × 6 = 18
    放在 result[4]（個位）和 result[3]（進位）

這個「i + j 定位法」讓我們不用逐行計算再相加，
可以一次把所有乘積累加到對應位置，最後統一處理進位。

完整推導：123 × 456

🔢 兩階段：先全部累加，再統一進位
result = [0, 0, 0, 0, 0]  （長度 3+3 = 5）

【階段 1】所有兩兩乘積累加到 result[i+j+1]

i=2(3) × j=2(6) = 18 → result[4] += 18  → [0,0,0,0,18]
i=2(3) × j=1(5) = 15 → result[3] += 15  → [0,0,0,15,18]
i=2(3) × j=0(4) = 12 → result[2] += 12  → [0,0,12,15,18]
i=1(2) × j=2(6) = 12 → result[3] += 12  → [0,0,12,27,18]
i=1(2) × j=1(5) = 10 → result[2] += 10  → [0,0,22,27,18]
i=1(2) × j=0(4) = 8  → result[1] += 8   → [0,8,22,27,18]
i=0(1) × j=2(6) = 6  → result[2] += 6   → [0,8,28,27,18]
i=0(1) × j=1(5) = 5  → result[1] += 5   → [0,13,28,27,18]
i=0(1) × j=0(4) = 4  → result[0] += 4   → [4,13,28,27,18]

【階段 2】從最低位往前統一處理進位

result[4] = 18 → 留 8，進位 1 給 result[3]
result[3] = 27 + 1 = 28 → 留 8，進位 2
result[2] = 28 + 2 = 30 → 留 0，進位 3
result[1] = 13 + 3 = 16 → 留 6，進位 1
result[0] = 4 + 1 = 5

result = [5, 6, 0, 8, 8] → "56088" ✓

【為什麼可以先累加再統一進位？】
因為每個位置最大值是 9×9×200 = 16200，
遠小於 int 範圍，不會溢位。這讓程式碼簡潔很多。

邊界處理：前置零

若 result 開頭是 0（例如 [0, 6] 代表 6），要把前置零去掉。特例是結果本身為 0（"0" × "12345"），此時要保留一個 "0"。

程式碼實現

class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == "0" or num2 == "0":
            return "0"

        m, n = len(num1), len(num2)
        result = [0] * (m + n)          # 最多 m + n 位

        # 階段 1：所有兩兩乘積累加到 result[i+j+1]
        for i in range(m - 1, -1, -1):
            d1 = int(num1[i])
            for j in range(n - 1, -1, -1):
                d2 = int(num2[j])
                result[i + j + 1] += d1 * d2

        # 階段 2：從最低位開始統一處理進位
        for k in range(m + n - 1, 0, -1):
            result[k - 1] += result[k] // 10
            result[k] %= 10

        # 去除前置零
        start = 0
        while start < len(result) - 1 and result[start] == 0:
            start += 1

        return ''.join(map(str, result[start:]))
class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") return "0";

        int m = num1.size(), n = num2.size();
        vector<int> result(m + n, 0);         // 最多 m + n 位

        // 階段 1：所有兩兩乘積累加到 result[i+j+1]
        for (int i = m - 1; i >= 0; i--) {
            int d1 = num1[i] - '0';
            for (int j = n - 1; j >= 0; j--) {
                int d2 = num2[j] - '0';
                result[i + j + 1] += d1 * d2;
            }
        }

        // 階段 2：統一處理進位
        for (int k = m + n - 1; k > 0; k--) {
            result[k - 1] += result[k] / 10;
            result[k] %= 10;
        }

        // 去除前置零並組成字串
        string ans;
        int start = (result[0] == 0) ? 1 : 0;
        for (int i = start; i < m + n; i++) {
            ans += ('0' + result[i]);
        }
        return ans;
    }
};
class Solution {
    public String multiply(String num1, String num2) {
        if (num1.equals("0") || num2.equals("0")) return "0";

        int m = num1.length(), n = num2.length();
        int[] result = new int[m + n];        // 最多 m + n 位

        // 階段 1：所有兩兩乘積累加到 result[i+j+1]
        for (int i = m - 1; i >= 0; i--) {
            int d1 = num1.charAt(i) - '0';
            for (int j = n - 1; j >= 0; j--) {
                int d2 = num2.charAt(j) - '0';
                result[i + j + 1] += d1 * d2;
            }
        }

        // 階段 2：統一處理進位
        for (int k = m + n - 1; k > 0; k--) {
            result[k - 1] += result[k] / 10;
            result[k] %= 10;
        }

        // 去除前置零
        StringBuilder sb = new StringBuilder();
        int start = (result[0] == 0) ? 1 : 0;
        for (int i = start; i < m + n; i++) {
            sb.append(result[i]);
        }
        return sb.toString();
    }
}

複雜度分析

時間複雜度：O(m × n)
  • 雙層迴圈計算所有位數的兩兩乘積
  • 進位處理只需 O(m + n)
  • 這是「小學直式乘法」的複雜度；更快的演算法見補充說明
空間複雜度：O(m + n)，存放結果的陣列

重點提示

💡 關鍵技巧 1：i + j 定位法

num1[i] × num2[j] 落在 result[i+j] 和 result[i+j+1]。記住這個定位公式，本題就解決了一大半。

💡 關鍵技巧 2：先全部累加，最後統一進位

不需要每一步都處理進位（那樣程式碼會很亂）。因為單一位置最大只到約 16200，int 完全裝得下，最後統一處理反而更簡潔、更不容易出錯。

💡 關鍵技巧 3：長度必為 m + n 或 m + n - 1

99 × 99 = 9801（4 位 = 2+2），9 × 9 = 81（2 位 = 1+1），1 × 1 = 1（1 位 = 1+1-1）。所以開 m+n 的陣列一定夠，最多只會有一個前置零。

⚠️ 常見錯誤：
  • 忘記處理任一數為 "0" 的情況，會輸出 "0000..."
  • 去除前置零時把結果 "0" 也刪光了（要保留至少一位）
  • 索引寫成 result[i+j] 而非 result[i+j+1]，整體偏移一位
  • 試圖用 long long 直接轉換 —— 200 位數遠遠超出範圍

補充說明

大數加法（#415，本題的基礎）

string addStrings(string num1, string num2) {
    int i = num1.size() - 1, j = num2.size() - 1, carry = 0;
    string result;
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += num1[i--] - '0';
        if (j >= 0) sum += num2[j--] - '0';
        result += ('0' + sum % 10);
        carry = sum / 10;
    }
    reverse(result.begin(), result.end());
    return result;
}

⭐ 迴圈條件 `i >= 0 || j >= 0 || carry` 一次處理三種情況：
   長度不同、最後還有進位，非常值得記住的模板。

更快的乘法演算法

⚡ 從 O(n²) 到 O(n log n)
演算法              複雜度          說明
----------------------------------------------------------
直式乘法（本題）    O(n²)          小數字最快（常數小）
Karatsuba          O(n^1.585)      分治，把 4 次乘法減為 3 次
Toom-Cook          O(n^1.465)      Karatsuba 的推廣
Schönhage-Strassen O(n log n loglog n)  基於 FFT
Harvey-van der Hoeven O(n log n)   2019 年的理論最優解

【Karatsuba 的核心】
  x = a·10^m + b,  y = c·10^m + d
  x·y = ac·10^2m + (ad + bc)·10^m + bd

  樸素做法需要 4 次乘法（ac, ad, bc, bd）
  但 ad + bc = (a+b)(c+d) - ac - bd
  → 只需要 3 次乘法：ac、bd、(a+b)(c+d) ✓

實務上（GMP、Python 的 int）會根據數字大小
自動切換演算法：小數用直式，大數用 Karatsuba 或 FFT。

面試延伸問題

  • 「如果要支援負數怎麼辦？」→ 先取出符號，用絕對值相乘，最後再套符號
  • 「如果要支援小數？」→ 記錄小數點位置，當成整數相乘後再插回小數點
  • 「為什麼不能先轉成 long long？」→ 200 位數約等於 10²⁰⁰，而 int64 上限只有約 9.2×10¹⁸
  • 「能不能用更大的進位基底？」→ 可以。實務的大數函式庫用 2³² 或 10⁹ 為一個「位」，大幅減少迴圈次數
