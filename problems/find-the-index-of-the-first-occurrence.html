28. Find the Index of the First Occurrence in a String
Easy

題目描述

給定兩個字串 haystack 和 needle，請在 haystack 字串中找出 needle 字串第一次出現的下標（從 0 開始）。

如果 needle 不是 haystack 的一部分，則返回 -1。

範例 1:
輸入: haystack = "sadbutsad", needle = "sad"
輸出: 0
解釋: "sad" 在下標 0 和 6 處出現，第一次出現在下標 0
範例 2:
輸入: haystack = "leetcode", needle = "leeto"
輸出: -1
解釋: "leeto" 沒有在 "leetcode" 中出現

解題思路

方法一：逐位比對（適合面試起手）

以 haystack 的每個可能起點 i（0 到 n - m）為開頭，逐字元比對長度為 m 的子字串是否等於 needle。

一旦有字元不同就換下一個起點，全部相同即回傳 i。實作簡單，最壞時間為 O(n × m)。

方法二：KMP 演算法（最佳解）

先對 needle 建立前綴函數 next 陣列，next[i] 代表 needle[0..i] 中最長的「相同前綴與後綴」長度。

比對主字串時，一旦失配就利用 next 陣列把模式往右滑動到已知匹配的位置，主字串指標永不回退，因此時間為 O(n + m)。

程式碼實現

class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n, m = len(haystack), len(needle)
        if m == 0:
            return 0
        if m > n:
            return -1

        # 建立 KMP 前綴函數
        nxt = [0] * m
        k = 0
        for i in range(1, m):
            while k > 0 and needle[i] != needle[k]:
                k = nxt[k - 1]
            if needle[i] == needle[k]:
                k += 1
            nxt[i] = k

        # 比對主字串，指標不回退
        k = 0
        for i in range(n):
            while k > 0 and haystack[i] != needle[k]:
                k = nxt[k - 1]
            if haystack[i] == needle[k]:
                k += 1
            if k == m:
                return i - m + 1
        return -1

    public int strStr(String haystack, String needle) {
        int n = haystack.length(), m = needle.length();
        if (m == 0) return 0;
        if (m > n) return -1;

        int[] next = new int[m];
        for (int i = 1, k = 0; i < m; i++) {
            while (k > 0 && needle.charAt(i) != needle.charAt(k)) k = next[k - 1];
            if (needle.charAt(i) == needle.charAt(k)) k++;
            next[i] = k;
        }

        for (int i = 0, k = 0; i < n; i++) {
            while (k > 0 && haystack.charAt(i) != needle.charAt(k)) k = next[k - 1];
            if (haystack.charAt(i) == needle.charAt(k)) k++;
            if (k == m) return i - m + 1;

        return -1;

}
// KMP：先建立 next（最長相等前後綴）表，再線性比對
// 時間複雜度: O(m + n)，空間複雜度: O(n)
function strStr(haystack: string, needle: string): number {
    const n = needle.length;
    if (n === 0) return 0;

    const next = new Array(n).fill(0);
    for (let i = 1, j = 0; i < n; i++) {
        while (j > 0 && needle[i] !== needle[j]) j = next[j - 1];
        if (needle[i] === needle[j]) j++;
        next[i] = j;
    }

    for (let i = 0, j = 0; i < haystack.length; i++) {
        while (j > 0 && haystack[i] !== needle[j]) j = next[j - 1];
        if (haystack[i] === needle[j]) j++;
        if (j === n) return i - n + 1;
    }
    return -1;
}
// KMP：先建立 next（最長相等前後綴）表，再線性比對
// 時間複雜度: O(m + n)，空間複雜度: O(n)
int strStr(char* haystack, char* needle) {
    int m = strlen(haystack), n = strlen(needle);
    if (n == 0) return 0;

    int* next = malloc(sizeof(int) * n);
    next[0] = 0;
    for (int i = 1, j = 0; i < n; i++) {
        while (j > 0 && needle[i] != needle[j]) j = next[j - 1];
        if (needle[i] == needle[j]) j++;
        next[i] = j;
    }

    int ans = -1;
    for (int i = 0, j = 0; i < m; i++) {
        while (j > 0 && haystack[i] != needle[j]) j = next[j - 1];
        if (haystack[i] == needle[j]) j++;
        if (j == n) { ans = i - n + 1; break; }
    }
    free(next);
    return ans;
}

複雜度分析

時間複雜度: O(n + m)

KMP 建表為 O(m)，主迴圈中 i 只前進不回退、k 的總減少量不超過總增加量，因此比對為 O(n)。

空間複雜度: O(m)

額外空間只有長度為 m 的前綴函數陣列。

重點提示

  • next 陣列的意義：next[i] 是 needle[0..i] 最長相同前後綴的長度，失配時直接跳到該長度繼續比
  • 主指標不回退：KMP 相對暴力解的關鍵優勢：haystack 的每個字元最多被檢查常數次
  • while 而非 if：失配時可能需要連續回退多層，必須用 while 迴圈
  • 先處理邊界：needle 為空回傳 0、needle 比 haystack 長回傳 -1，可省去後續判斷
