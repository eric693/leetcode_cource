#150 Evaluate Reverse Polish Notation

Medium
Stack Array Math

題目描述

給你一個字串陣列 tokens，表示一個根據逆波蘭表示法（Reverse Polish Notation, 後綴表達式）表示的算術運算式。請你計算該運算式，返回一個表示運算式值的整數。

注意：

  • 有效的運算子為 +、-、*、/
  • 每個運算元（運算對象）都可以是整數或另一個運算式
  • 兩個整數之間的除法總是向零截斷（例如 -7/2 = -3，不是 -4）
  • 該運算式中不含除零運算，輸入保證是有效的

範例

範例 1：
輸入：tokens = ["2","1","+","3","*"]
輸出：9
解釋：該算式轉化為常見的中綴算術運算式為 ((2 + 1) * 3) = 9
範例 2：
輸入：tokens = ["4","13","5","/","+"]
輸出：6
解釋：該算式轉化為 (4 + (13 / 5)) = 4 + 2 = 6
範例 3：
輸入：tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
輸出：22

解題思路

💡 什麼是逆波蘭表示法？
中綴（我們習慣的寫法）： (2 + 1) * 3
後綴（逆波蘭）：          2 1 + 3 *

運算子寫在兩個運算元【之後】。

【逆波蘭的三大優點】
1. 不需要括號 —— 運算順序由位置唯一決定
2. 不需要運算子優先級規則
3. 用一個堆疊就能求值，實作極簡

這正是編譯器、計算機、虛擬機內部使用的表示法。

核心：一個堆疊搞定

🎯 遇到數字就推入，遇到運算子就彈出兩個
for (token : tokens) {
    if (是數字) {
        stack.push(數字);
    } else {
        b = stack.pop();      // 注意順序！先彈出的是【右】運算元
        a = stack.pop();      // 後彈出的是【左】運算元
        stack.push(a 運算 b);
    }
}
return stack.top();

⚠️ 順序極重要：
   對於加法和乘法沒差，
   但減法和除法會完全不同！
   "5 3 -" 應該是 5 - 3 = 2，不是 3 - 5 = -2

完整追蹤：["4","13","5","/","+"]

🔄 堆疊的變化
token = "4"  → 數字，推入      stack = [4]
token = "13" → 數字，推入      stack = [4, 13]
token = "5"  → 數字，推入      stack = [4, 13, 5]
token = "/"  → 運算子
               b = pop() = 5   （右運算元）
               a = pop() = 13  （左運算元）
               push(13 / 5 = 2)
                               stack = [4, 2]
token = "+"  → 運算子
               b = pop() = 2
               a = pop() = 4
               push(4 + 2 = 6)
                               stack = [6]

答案 = 6 ✓

陷阱：除法的截斷方向

⚠️ 「向零截斷」vs「向下取整」
題目要求【向零截斷】（truncate toward zero）：
  7 / 2  = 3      -7 / 2  = -3   （不是 -4！）

各語言的行為：
  C/C++ 的 /      → 向零截斷 ✓ 直接用
  Java 的 /       → 向零截斷 ✓ 直接用
  Python 的 //    → 向下取整 ✗ -7 // 2 = -4，會出錯！

Python 的正確寫法：
  int(a / b)                     # 浮點除法後截斷（小數字安全）
  或
  abs(a) // abs(b) * (1 if a*b >= 0 else -1)   # 純整數運算

本題數值範圍小，用 int(a / b) 即可。

程式碼實現

class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []
        operators = {'+', '-', '*', '/'}

        for token in tokens:
            if token in operators:
                b = stack.pop()      # 先彈出的是【右】運算元
                a = stack.pop()      # 後彈出的是【左】運算元

                if token == '+':
                    stack.append(a + b)
                elif token == '-':
                    stack.append(a - b)
                elif token == '*':
                    stack.append(a * b)
                else:
                    # Python 的 // 是向下取整，這裡要向零截斷
                    stack.append(int(a / b))
            else:
                stack.append(int(token))   # 注意：可能是負數如 "-11"

        return stack[0]


# 用字典 + lambda 讓程式碼更簡潔
class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        ops = {
            '+': lambda a, b: a + b,
            '-': lambda a, b: a - b,
            '*': lambda a, b: a * b,
            '/': lambda a, b: int(a / b),    # 向零截斷
        }
        stack = []
        for token in tokens:
            if token in ops:
                b, a = stack.pop(), stack.pop()
                stack.append(ops[token](a, b))
            else:
                stack.append(int(token))
        return stack[0]

class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (String token : tokens) {
            switch (token) {
                case "+": case "-": case "*": case "/": {
                    int b = stack.pop();      // 右運算元
                    int a = stack.pop();      // 左運算元
                    int result;
                    switch (token) {
                        case "+": result = a + b; break;
                        case "-": result = a - b; break;
                        case "*": result = a * b; break;
                        default:  result = a / b; break;  // Java 向零截斷
                    }
                    stack.push(result);
                    break;
                }
                default:
                    stack.push(Integer.parseInt(token));  // 可處理負號
            }
        }
        return stack.pop();
    }
}
// 堆疊：遇到數字入棧，遇到運算子彈出兩個運算
// 時間複雜度: O(n)，空間複雜度: O(n)
function evalRPN(tokens: string[]): number {
    const stack: number[] = [];
    for (const t of tokens) {
        if (t === '+' || t === '-' || t === '*' || t === '/') {
            const b = stack.pop()!;    // 注意順序：先彈出的是右運算元
            const a = stack.pop()!;
            if (t === '+') stack.push(a + b);
            else if (t === '-') stack.push(a - b);
            else if (t === '*') stack.push(a * b);
            else stack.push(Math.trunc(a / b));  // 向零取整
        } else {
            stack.push(Number(t));
        }
    }
    return stack[0];
}
// 堆疊：遇到數字入棧，遇到運算子彈出兩個運算
// 時間複雜度: O(n)，空間複雜度: O(n)
int evalRPN(char** tokens, int tokensSize) {
    long* stack = malloc(sizeof(long) * tokensSize);
    int top = 0;
    for (int i = 0; i < tokensSize; i++) {
        char* t = tokens[i];
        // 運算子是長度為 1 的非數字字元（"-3" 是負數不是運算子）
        if (t[1] == '\0' && (t[0] == '+' || t[0] == '-' || t[0] == '*' || t[0] == '/')) {
            long b = stack[--top];
            long a = stack[--top];
            switch (t[0]) {
                case '+': stack[top++] = a + b; break;
                case '-': stack[top++] = a - b; break;
                case '*': stack[top++] = a * b; break;
                case '/': stack[top++] = a / b; break;   // C 的整數除法本來就向零取整
            }
        } else {
            stack[top++] = atol(t);
        }
    }
    int ans = (int)stack[0];
    free(stack);
    return ans;
}

複雜度分析

時間複雜度：O(n)
  • 每個 token 只處理一次，堆疊操作都是 O(1)
空間複雜度：O(n)
  • 最壞情況（所有數字連續出現）堆疊會存 n/2 + 1 個元素

重點提示

💡 關鍵技巧 1：彈出順序不能反

先彈出的是右運算元，因為堆疊是後進先出。減法和除法對順序敏感，寫反了 ["5","3","-"] 會得到 -2 而不是 2。這是本題最常見的錯誤。

💡 關鍵技巧 2：判斷數字不能只看第一個字元

token 可能是 "-11"（負數）。用「第一個字元是不是數字」來判斷會把負數誤判成減法運算子。正確做法是先檢查是不是那四個運算子，其餘一律當數字。

💡 Python 特別注意除法

-7 // 2 = -4（向下取整）但題目要 -3（向零截斷）。必須用 int(a / b)。這個差異在很多題目中都會踩到，值得記住。

⚠️ 常見錯誤：
  • 運算元順序顛倒
  • 用 isdigit() 判斷導致負數被當成運算子
  • Python 用 // 導致負數除法結果錯誤
  • C++ 用 stoi 遇到超大數字溢位（本題範圍內安全，但用 long long 更保險）

補充說明

三種表達式表示法

📝 前綴、中綴、後綴
                    運算子位置    範例（(2+1)*3）  求值方式
------------------------------------------------------------------
中綴（infix）       在中間        (2 + 1) * 3      需要括號與優先級
前綴（prefix）      在前面        * + 2 1 3        從右往左掃 + 堆疊
                    = 波蘭表示法                   （Lisp 的形式）
後綴（postfix）     在後面        2 1 + 3 *        從左往右掃 + 堆疊
                    = 逆波蘭 ★                     最容易實作

⭐ 前綴和後綴都不需要括號，
   因為運算順序已經由結構唯一決定了。

樹的觀點：這三種其實就是【表達式樹】的三種遍歷！
        *
       / \
      +   3
     / \
    2   1
  前序遍歷 → * + 2 1 3  （前綴）
  中序遍歷 → 2 + 1 * 3  （中綴，會遺失括號資訊）
  後序遍歷 → 2 1 + 3 *  （後綴）✓

中綴轉後綴：Shunting-yard 演算法

Dijkstra 提出的經典演算法，用一個運算子堆疊：

for (token : 中綴表達式) {
    if (是數字)    直接輸出;
    if (是 '(')    推入堆疊;
    if (是 ')')    不斷彈出並輸出，直到遇到 '('，然後丟棄 '(';
    if (是運算子)  while (堆疊頂端運算子的優先級 >= 當前運算子)
                       彈出並輸出;
                   推入當前運算子;
}
最後把堆疊中剩餘的運算子全部彈出輸出。

範例："3 + 4 * 2"
  3 → 輸出      output: 3
  + → 推入      stack: [+]
  4 → 輸出      output: 3 4
  * → 優先級高於 +，直接推入   stack: [+, *]
  2 → 輸出      output: 3 4 2
  結束 → 彈出全部   output: 3 4 2 * +

結果 "3 4 2 * +" = 3 + (4*2) = 11 ✓

實務應用：堆疊機（Stack Machine）

🔧 虛擬機的運作原理
JVM、Python VM、WebAssembly 都是【堆疊式虛擬機】，
它們的位元組碼本質上就是逆波蘭表示法。

Java 原始碼： int c = a + b;

JVM 位元組碼：
  iload_1      // 把 a 推入運算元堆疊
  iload_2      // 把 b 推入運算元堆疊
  iadd         // 彈出兩個，相加，結果推回
  istore_3     // 彈出結果存入 c

完全就是本題的邏輯！

【為什麼虛擬機用堆疊而不是暫存器？】
  ✓ 指令編碼短（不需要指定運算元的位置）
  ✓ 與底層硬體無關，可攜性高
  ✗ 執行效率較低（記憶體存取較多）
  → 所以 JIT 編譯器會把堆疊碼再轉成暫存器機器碼

相對地，真實 CPU（x86、ARM）和 Lua VM、Dalvik
則是【暫存器式】，指令較少但編碼較長。
