287. Find the Duplicate Number
Medium

題目描述

給定一個包含 n + 1 個整數的陣列 nums，其數字都在 [1, n] 範圍內（包括 1 和 n），可知至少存在一個重複的整數。

假設 nums 只有一個重複的整數，請找出這個重複的數。

限制：不能修改陣列 nums，且只能使用常數級 O(1) 的額外空間。

範例 1:
輸入: nums = [1,3,4,2,2]
輸出: 2
範例 2:
輸入: nums = [3,1,3,4,2]
輸出: 3
範例 3:
輸入: nums = [3,3,3,3,3]
輸出: 3

解題思路

方法一：快慢指標找環入口（推薦）

把陣列看成一張函數圖：從索引 i 連一條邊到索引 nums[i]。因為值域是 [1, n] 而索引有 n + 1 個，這張圖一定存在環，而環的入口就是重複的數字。

第一階段從索引 0 出發，slow 走一步、fast 走兩步，直到相遇。

第二階段把其中一個指標放回起點 0，兩個指標各走一步，再次相遇的位置即為環入口，也就是答案。

方法二：對值域二分搜尋

在 [1, n] 的數值範圍上二分，對每個候選中點 mid 統計陣列中「小於等於 mid 的元素個數」count。

若 count > mid，代表重複的數字落在 [1, mid]，否則落在 [mid + 1, n]。

時間 O(n log n)、空間 O(1)，同樣不修改原陣列，是很好的備選答案。

程式碼實現

class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        # 第一階段：找到快慢指標的相遇點
        slow = nums[0]
        fast = nums[nums[0]]
        while slow != fast:
            slow = nums[slow]
            fast = nums[nums[fast]]

        # 第二階段：從起點與相遇點同速前進，交會處即為環入口
        slow = 0
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = nums[0];
        int fast = nums[nums[0]];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[nums[fast]];
        }

        slow = 0;
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }
        return slow;
    }
}

function findDuplicate(nums: number[]): number {
    let slow = nums[0], fast = nums[nums[0]];
    while (slow !== fast) {
        slow = nums[slow];
        fast = nums[nums[fast]];
    }
    slow = 0;                     // 一個從起點出發，一個從相遇點出發
    while (slow !== fast) {
        slow = nums[slow];
        fast = nums[fast];
    }
    return slow;
}

複雜度分析

時間複雜度: O(n)

快慢指標兩個階段各最多走訪 O(n) 步；二分解法為 O(n log n)。

空間複雜度: O(1)

只使用兩個索引變數，未使用額外陣列，也沒有修改輸入。

重點提示

  • 為何一定有環：值域 [1, n] 對應 n + 1 個索引，依鴿籠原理必有兩個索引指向同一位置，形成入環
  • 環入口即答案：重複的數字是唯一被兩條邊指向的節點，正好是 Floyd 判圈法找出的環入口
  • 起點必須是 0：索引 0 不會是任何節點的後繼（值域從 1 開始），所以從 0 出發保證不在環內
  • 別用排序或標記：排序會修改陣列、雜湊集合需要 O(n) 空間，都違反題目限制
