#231 Power of Two

Easy
Bit Manipulation Math Recursion

題目描述

給定一個整數 n，判斷它是否為 2 的冪次方。若是則返回 true，否則返回 false。

若存在整數 x 使得 n == 2x，則認為 n 是 2 的冪次方。

進階：你能不使用迴圈或遞迴來完成嗎？

範例

範例 1：
輸入：n = 1
輸出：true
解釋：20 = 1
範例 2：
輸入：n = 16
輸出：true
解釋：24 = 16
範例 3：
輸入：n = 3
輸出：false

解題思路

💡 核心觀察：2 的冪次方在二進位中只有一個 1
1  = 0001    ✓ 只有一個 1
2  = 0010    ✓
4  = 0100    ✓
8  = 1000    ✓
16 = 10000   ✓

3  = 0011    ✗ 兩個 1
6  = 0110    ✗

方法一：n & (n - 1) == 0（最經典）

🎯 一行解法
n     = 1000  (8)
n - 1 = 0111  (7)
n & (n-1) = 0000  → 是 2 的冪 ✓

n     = 0110  (6)
n - 1 = 0101  (5)
n & (n-1) = 0100 ≠ 0  → 不是 ✗

⚠️ 必須先判斷 n > 0
   n = 0 時：0 & -1 = 0 會誤判為 true

方法二：n & (-n) == n

🎯 lowbit 等於自己
-n 是二補數 = ~n + 1
n & (-n) 會取出最右邊的 1（lowbit）

如果 n 只有一個 1，那 lowbit 就等於 n 本身

n = 1000 (8),  -n = 1000...1000 → n & -n = 1000 = n ✓
n = 0110 (6),  n & -n = 0010 ≠ n ✗

方法三：數學法（不用迴圈也不用遞迴）

🧮 用最大的 2 的冪來整除

32 位元 int 中最大的 2 的冪是 230 = 1073741824。如果 n 是 2 的冪，它必定能整除 230。

複雜度分析

時間複雜度：
  • 方法一、二、三：O(1)，只做一次位元運算
  • 方法四（迴圈除法）：O(log n)
空間複雜度：O(1)

重點提示

💡 關鍵技巧：n > 0 的判斷不能少

n = 0 時 0 & -1 = 0 會誤判為 true；負數也會出錯。這是本題最常見的扣分點。

💡 韌體應用：對齊與遮罩

只有當 size 是 2 的冪時，x % size 才能用 x & (size-1) 取代。這就是為什麼記憶體分頁、cache line、ring buffer 大小都設計成 2 的冪。

⚠️ 常見錯誤：
  • 忘記處理 n <= 0
  • C++ 中對 INT_MIN 取負號會溢位（UB），要轉成 long long
  • 用 log2(n) % 1 == 0 會有浮點誤差，不建議

補充說明

延伸：Power of Four（#342）

🎯 多一個遮罩判斷
4 的冪 = 是 2 的冪，而且那個 1 落在偶數位（第 0, 2, 4... 位）

1   = 0000 0001  ✓ 第 0 位
4   = 0000 0100  ✓ 第 2 位
16  = 0001 0000  ✓ 第 4 位
8   = 0000 1000  ✗ 第 3 位（奇數位）

遮罩 0x55555555 = 0101 0101...（只保留偶數位）

bool isPowerOfFour(int n) {
    return n > 0 && (n & (n-1)) == 0 && (n & 0x55555555) != 0;
}

韌體實務：向上對齊到 2 的冪

// 把 x 向上取整到 align 的倍數（align 必須是 2 的冪）
#define ALIGN_UP(x, align)   (((x) + (align) - 1) & ~((align) - 1))

// 取得大於等於 n 的最小 2 的冪
uint32_t next_pow2(uint32_t n) {
    n--;
    n |= n >> 1;  n |= n >> 2;  n |= n >> 4;
    n |= n >> 8;  n |= n >> 16;
    return n + 1;
}
