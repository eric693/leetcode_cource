#22 Generate Parentheses

Medium
Backtracking String Dynamic Programming Recursion

題目描述

數字 n 代表生成括號的對數，請你設計一個函數，用於能夠生成所有可能的並且有效的括號組合。

「有效」指的是括號必須正確配對且閉合，例如 "(())" 有效，")(" 無效。

範例

範例 1：
輸入：n = 3
輸出：["((()))","(()())","(())()","()(())","()()()"]
解釋：共 5 種，正是第 3 個卡塔蘭數。
範例 2：
輸入：n = 1
輸出：["()"]

解題思路

💡 核心：邊生成邊剪枝，只走合法的路
❌ 笨方法：生成所有 2^(2n) 種字串，再逐一檢查是否合法
✓ 好方法：在生成過程中就保證合法，永遠不走無效分支

【兩個規則】維護已使用的左括號數 open、右括號數 close

規則 1：open < n           才能放左括號
        （左括號總數不能超過 n）

規則 2：close < open       才能放右括號
        （右括號數量永遠不能超過左括號，
          否則會出現 ")(" 這種未配對就閉合的情況）

只要遵守這兩條，生成的字串必定合法 ✓

決策樹：n = 2

🌲 灰色分支被剪掉
                    ""  (open=0, close=0)
                   /  \
              "("      ✗ 不能放 ')' （close < open 不成立）
           (1,0)
            /    \
       "(("       "()"
      (2,0)      (1,1)
         |          |
      "(()"      "()("   （"()" 後不能再放 ')'，因為 close==open）
      (2,1)      (2,1)
         |          |
     "(())" ✓   "()()" ✓
     (2,2)      (2,2)

答案：["(())", "()()"] ✓

終止條件：字串長度達到 2n（也等價於 open == n 且 close == n）

為什麼「close < open」就能保證合法？

🔍 合法括號序列的充要條件
一個括號序列合法 ⟺ 同時滿足：
  1. 左右括號總數相等
  2. 任何一個前綴中，右括號數量 <= 左括號數量

條件 2 正是我們的規則 2。
如果某個前綴的 ')' 比 '(' 多，
就代表出現了「沒有對應左括號的右括號」，
之後不管怎麼補都救不回來。

驗證 "())(" ：
  前綴 "(" → 0 <= 1 ✓
  前綴 "()" → 1 <= 1 ✓
  前綴 "())" → 2 > 1 ✗ 在這裡就已經不合法了

答案的數量：卡塔蘭數（Catalan Number）

n 對括號的合法組合數 = 第 n 個卡塔蘭數

C(n) = (2n)! / ((n+1)! × n!) = C(2n, n) / (n + 1)

n:      1   2   3   4   5    6    7     8
C(n):   1   2   5   14  42   132  429   1430

遞推式：C(n) = Σ C(i) × C(n-1-i)  for i = 0..n-1
        （對應「第一個左括號的配對位置」的分割）

程式碼實現

# 回溯 + 剪枝（推薦）
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        result = []
        path = []

        def backtrack(open_count, close_count):
            # 終止條件：用完所有括號
            if len(path) == 2 * n:
                result.append(''.join(path))
                return

            # 規則 1：左括號還沒用完就可以放
            if open_count < n:
                path.append('(')
                backtrack(open_count + 1, close_count)
                path.pop()

            # 規則 2：右括號數量不能超過左括號
            if close_count < open_count:
                path.append(')')
                backtrack(open_count, close_count + 1)
                path.pop()

        backtrack(0, 0)
        return result


# 方法二：動態規劃（按「第一個括號配對的位置」分割）
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        # dp[i] = i 對括號的所有合法組合
        dp = [[] for _ in range(n + 1)]
        dp[0] = ['']

        for i in range(1, n + 1):
            for j in range(i):
                # 形式：( 內部 j 對 ) 外部 i-1-j 對
                for inner in dp[j]:
                    for outer in dp[i - 1 - j]:
                        dp[i].append('(' + inner + ')' + outer)
        return dp[n]

class Solution {
    vector<string> result;
    string path;

    void backtrack(int n, int openCount, int closeCount) {
        if (path.size() == 2 * n) {
            result.push_back(path);
            return;
        }

        // 規則 1：左括號還沒用完
        if (openCount < n) {
            path.push_back('(');
            backtrack(n, openCount + 1, closeCount);
            path.pop_back();
        }

        // 規則 2：右括號不能超過左括號
        if (closeCount < openCount) {
            path.push_back(')');
            backtrack(n, openCount, closeCount + 1);
            path.pop_back();
        }
    }

public:

// 回溯 + 剪枝（推薦）
class Solution {
    private List<String> result = new ArrayList<>();
    private StringBuilder path = new StringBuilder();

    public List<String> generateParenthesis(int n) {
        backtrack(n, 0, 0);
        return result;
    }

    private void backtrack(int n, int openCount, int closeCount) {
        if (path.length() == 2 * n) {
            result.add(path.toString());
            return;
        }

        // 規則 1：左括號還沒用完
        if (openCount < n) {
            path.append('(');
            backtrack(n, openCount + 1, closeCount);
            path.deleteCharAt(path.length() - 1);
        }

        // 規則 2：右括號不能超過左括號
        if (closeCount < openCount) {
            path.append(')');
            backtrack(n, openCount, closeCount + 1);
            path.deleteCharAt(path.length() - 1);
        }
    }
}

複雜度分析

時間複雜度：O(4ⁿ / √n)
  • 答案數量是第 n 個卡塔蘭數，漸近為 4ⁿ / (n^1.5 √π)
  • 每個答案需要 O(n) 的建構成本
  • 由於剪枝完全，不會走任何無效分支，所以複雜度就等於輸出規模
空間複雜度：O(n)
  • 遞迴深度 2n，path 長度 2n

重點提示

💡 關鍵技巧 1：「生成時剪枝」勝過「生成後過濾」

先生成 2^(2n) 種再驗證是 O(2^(2n) × n)，而邊生成邊剪枝只有 O(4ⁿ/√n)。把約束條件融入搜尋過程是回溯優化的核心思想，在 N-Queens、數獨等題目中都是同樣的道理。

💡 關鍵技巧 2：這題沒有 for 迴圈

與大多數回溯題不同，本題每層只有兩個固定選擇（放 '(' 或放 ')'），所以直接寫兩個 if 而不是 for 迴圈。這是「二元決策樹」型回溯的典型寫法。

💡 面試延伸：驗證括號合法性

用一個計數器：遇 '(' 加 1、遇 ')' 減 1，過程中不能為負，結束時必須為 0。若有多種括號（[]{}）則要用堆疊（#20）。

⚠️ 常見錯誤：
  • 剪枝條件寫成 close <= open，會產生 "()）" 這類非法字串
  • 忘記撤銷選擇（Java 的 deleteCharAt）
  • 終止條件只檢查 open == n，漏掉右括號還沒補完
  • 先生成全部再過濾，n 稍大就超時

補充說明

卡塔蘭數的其他化身

🔢 同一個數列，多種問題
第 n 個卡塔蘭數 C(n) 同時是以下問題的答案：

1. n 對括號的合法組合數（本題）
2. n 個節點能組成多少種不同的【二元搜尋樹】（#96）
3. n+1 個矩陣連乘有多少種加括號方式
4. 凸 n+2 邊形有多少種三角剖分方式
5. n × n 網格中從左下走到右上、不越過對角線的路徑數
6. n 個元素的合法出堆疊序列數

這些問題「長得完全不同」卻有相同答案，
是因為它們都可以雙射到「合法括號序列」。

C(n) = C(2n, n) / (n+1)
     = 1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, ...

#96 Unique BST 的 DP（同樣的遞推）

int numTrees(int n) {
    vector<int> dp(n + 1, 0);
    dp[0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = 0; j < i; j++)
            dp[i] += dp[j] * dp[i - 1 - j];   // 左子樹 j 個、右子樹 i-1-j 個
    return dp[n];
}

和本題方法二的 DP 結構完全一樣：
  括號版：( 內部 j 對 ) 外部 i-1-j 對
  BST 版：左子樹 j 個節點，根，右子樹 i-1-j 個節點

#20 驗證括號的標準做法

bool isValid(string s) {
    stack<char> stk;
    unordered_map<char, char> pairs = {{')','('}, {']','['}, {'}','{'}};
    for (char c : s) {
        if (pairs.count(c)) {                  // 是右括號
            if (stk.empty() || stk.top() != pairs[c]) return false;
            stk.pop();
        } else {
            stk.push(c);                       // 是左括號
        }
    }
    return stk.empty();                        // 全部配對完才合法
}

若只有一種括號，可以用計數器取代堆疊，空間降到 O(1)。
