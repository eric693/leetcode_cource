#151 Reverse Words in a String

Medium
String Two Pointers

題目描述

給你一個字串 s，請你反轉字串中單詞的順序。

單詞是由非空格字元組成的字串。s 中使用至少一個空格將字串中的單詞分隔開。

返回單詞順序顛倒且單詞之間用單個空格連接的結果字串。注意：s 中可能會存在前置空格、尾隨空格或者單詞間的多個空格，返回的結果字串中不應包含這些多餘的空格。

進階：如果字串在你使用的語言中是可變的（如 C++ 的 char[]），能否使用 O(1) 額外空間就地解決？

範例

範例 1：
輸入：s = "the sky is blue"
輸出："blue is sky the"
範例 2：
輸入：s = " hello world "
輸出："world hello"
解釋：反轉後的字串不能包含前置或尾隨空格。
範例 3：
輸入：s = "a good example"
輸出："example good a"
解釋：單詞間的多餘空格要縮減成一個。

解題思路

💡 方法一：分割 + 反轉 + 拼接（最簡潔）
s = "  the   sky is blue  "

1. 用空白分割（自動忽略多餘空格）
   → ["the", "sky", "is", "blue"]
2. 反轉陣列
   → ["blue", "is", "sky", "the"]
3. 用單一空格拼接
   → "blue is sky the" ✓

Python 一行：' '.join(s.split()[::-1])

方法二：整體反轉 + 逐詞反轉（O(1) 空間，面試重點）

「反轉兩次」的經典技巧
核心觀察：把整個字串反轉後，單詞的「順序」對了，
          但每個單詞「內部」也被反轉了 —— 再反轉回來即可。

原始： "the sky is blue"

【步驟 1】整體反轉
       "eulb si yks eht"
       單詞順序 ✓，但每個字反了 ✗

【步驟 2】逐個單詞內部反轉
       "blue is sky the" ✓

這個「反轉兩次」的技巧非常通用：
  - 陣列旋轉（#189 Rotate Array）
  - 循環移位
  - 字串旋轉判斷

方法三：就地處理（C 風格，最完整）

🔧 三步驟，真正的 O(1) 空間
【步驟 1】清理空格（雙指標就地壓縮）
  "  the   sky  " → "the sky"
  用讀寫雙指標：讀指標跳過多餘空格，寫指標依序寫入

【步驟 2】整體反轉
  "the sky" → "yks eht"

【步驟 3】逐詞反轉
  "yks eht" → "sky the"

全程只用固定數量的變數，符合進階要求。

程式碼實現

# 方法一：內建函數（最簡潔）
class Solution:
    def reverseWords(self, s: str) -> str:
        # split() 不帶參數會自動忽略連續空白與前後空白
        return ' '.join(s.split()[::-1])


# 方法二：手動雙指標（不依賴內建 split，展現基本功）
class Solution:
    def reverseWords(self, s: str) -> str:
        words = []
        i, n = 0, len(s)
        while i < n:
            # 跳過空格
            while i < n and s[i] == ' ':
                i += 1
            if i >= n:
                break
            # 讀取一個完整單詞
            start = i
            while i < n and s[i] != ' ':
                i += 1
            words.append(s[start:i])

        # 反轉單詞順序
        return ' '.join(reversed(words))
// 方法三：就地處理（O(1) 額外空間，推薦，回答進階題）
class Solution {
public:
    string reverseWords(string s) {
        // 步驟 1：清理多餘空格（讀寫雙指標就地壓縮）
        int write = 0, n = s.size();
        for (int read = 0; read < n; ) {
            if (s[read] == ' ') { read++; continue; }
            if (write != 0) s[write++] = ' ';        // 單詞之間補一個空格
            while (read < n && s[read] != ' ') {
                s[write++] = s[read++];
            }
        }
        s.resize(write);

        // 步驟 2：整體反轉
        reverse(s.begin(), s.end());

        // 步驟 3：逐個單詞內部反轉
        int start = 0;
        for (int i = 0; i <= s.size(); i++) {
            if (i == s.size() || s[i] == ' ') {
                reverse(s.begin() + start, s.begin() + i);
                start = i + 1;
            }
        }
        return s;
    }
};

// 方法一：用 stringstream（簡潔版）
class Solution {
public:
    string reverseWords(string s) {
        istringstream iss(s);
        string word, result;
        while (iss >> word) {              // >> 自動跳過空白
            if (!result.empty()) result = " " + result;
            result = word + result;        // 反序拼接
        }
        return result;
    }
};
// 方法一：內建 split + StringBuilder
class Solution {
    public String reverseWords(String s) {
        String[] words = s.trim().split("\\s+");   // \s+ 匹配一或多個空白
        StringBuilder sb = new StringBuilder();
        for (int i = words.length - 1; i >= 0; i--) {
            sb.append(words[i]);
            if (i > 0) sb.append(' ');
        }
        return sb.toString();
    }
}

// 方法二：手動雙指標（不依賴正規表達式）
class Solution {
    public String reverseWords(String s) {
        StringBuilder sb = new StringBuilder();
        int i = s.length() - 1;
        while (i >= 0) {
            while (i >= 0 && s.charAt(i) == ' ') i--;      // 跳過空格
            if (i < 0) break;
            int end = i;
            while (i >= 0 && s.charAt(i) != ' ') i--;      // 找到單詞開頭
            if (sb.length() > 0) sb.append(' ');
            sb.append(s, i + 1, end + 1);
        }
        return sb.toString();
    }
}
// 切割單字（自動去除多餘空白）後反轉
// 時間複雜度: O(n)，空間複雜度: O(n)
function reverseWords(s: string): string {
    return s.trim().split(/\s+/).reverse().join(' ');
}
// 原地演算法：整個字串反轉 → 每個單字再反轉 → 同時壓縮多餘空白
// 時間複雜度: O(n)，空間複雜度: O(1)
static void reverse(char* s, int l, int r) {
    while (l < r) {
        char t = s[l];
        s[l++] = s[r];
        s[r--] = t;
    }
}

char* reverseWords(char* s) {
    int n = strlen(s);
    reverse(s, 0, n - 1);                         // 1. 整體反轉

    int write = 0;
    for (int i = 0; i < n; ) {
        if (s[i] == ' ') { i++; continue; }       // 跳過空白
        if (write > 0) s[write++] = ' ';          // 單字之間只留一個空白
        int start = write;
        while (i < n && s[i] != ' ') s[write++] = s[i++];
        reverse(s, start, write - 1);             // 2. 單字各自反轉回來
    }
    s[write] = '\0';
    return s;
}

複雜度分析

時間複雜度：O(n)
  • 清理空格 O(n) + 整體反轉 O(n) + 逐詞反轉合計 O(n)
空間複雜度：
  • C++ 就地版本：O(1) ★ 符合進階要求
  • Java / Python：O(n)，因為字串不可變，必須建新字串

重點提示

💡 關鍵技巧：反轉兩次

「整體反轉 + 局部反轉」是字串與陣列題的萬用技巧。看到「順序顛倒但要保持某種局部結構」就要想到它。#189 Rotate Array 用的是完全一樣的思路。

💡 面試注意：不要只寫一行

用 ' '.join(s.split()[::-1]) 一行過關，面試官通常會追問「不用內建函數怎麼寫」。準備好手寫雙指標版本，並主動說明如何處理多餘空格。

⚠️ 常見錯誤：
  • 用 split(" ")（帶參數）會產生空字串元素，必須用 split()（Python）或 split("\\s+") + trim()（Java）
  • 忘記 trim，導致開頭的空白產生一個空元素
  • 拼接時多加了尾隨空格
  • Java 用 String += 在迴圈中拼接，變成 O(n²)，應該用 StringBuilder

補充說明

「反轉技巧」的三大應用

🔄 一招通吃
【#151 反轉單詞順序】
  整體反轉 → 逐詞反轉

【#189 陣列右旋 k 位】
  [1,2,3,4,5,6,7], k = 3 → [5,6,7,1,2,3,4]

  1. 整體反轉：      [7,6,5,4,3,2,1]
  2. 反轉前 k 個：   [5,6,7,4,3,2,1]
  3. 反轉後 n-k 個： [5,6,7,1,2,3,4] ✓

  O(n) 時間，O(1) 空間，比用額外陣列漂亮得多。
  ⚠️ 記得先做 k %= n，否則 k > n 時會出錯。

【#557 只反轉每個單詞】
  "Let's take LeetCode" → "s'teL ekat edoCteeL"
  只做「逐詞反轉」這一步。

C 語言的就地版本（韌體面試常考）

void reverse(char *s, int left, int right) {
    while (left < right) {
        char tmp = s[left];
        s[left++] = s[right];
        s[right--] = tmp;
    }
}

void reverseWords(char *s) {
    int n = strlen(s);
    reverse(s, 0, n - 1);              // 整體反轉

    int start = 0;
    for (int i = 0; i <= n; i++) {     // 逐詞反轉
        if (i == n || s[i] == ' ') {
            reverse(s, start, i - 1);
            start = i + 1;
        }
    }
}

邊界情況檢查清單

  • " " 全是空格 → 返回空字串
  • "a" 單一字元 → 返回 "a"
  • " hello " 前後有空格 → "hello"
  • "a b" 中間多空格 → "b a"
  • 整個字串只有一個單詞 → 原樣返回（去除空白後）
