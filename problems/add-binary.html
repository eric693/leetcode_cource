67. Add Binary
Easy

題目描述

給定兩個二進位字串 a 和 b，以二進位字串的形式返回它們的和。

字串僅由字元 0 或 1 組成，且除了 "0" 本身外不含前導零。

範例 1:
輸入: a = "11", b = "1"
輸出: "100"
範例 2:
輸入: a = "1010", b = "1011"
輸出: "10101"

解題思路

方法一：模擬直式加法（推薦）

從兩個字串的最低位（最右端）開始，逐位相加並維護進位 carry。

每一位的和 sum = carry + a 的當前位 + b 的當前位；輸出位為 sum % 2，新的進位為 sum / 2。

較短的字串走完後補 0 繼續，迴圈結束時若 carry 仍為 1 要再補上一位，最後把結果反轉。

方法二：轉成整數相加（不推薦）

把兩個字串轉成整數相加再轉回二進位，寫法很短。

但題目字串長度可達 10^4，遠超過 64 位元整數範圍；除了 Python 的大整數之外，其他語言會直接溢位，因此實務上仍應使用逐位模擬。

程式碼實現

class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j = len(a) - 1, len(b) - 1
        carry = 0
        result = []
        while i >= 0 or j >= 0 or carry:
            total = carry
            if i >= 0:
                total += int(a[i])
                i -= 1
            if j >= 0:
                total += int(b[j])
                j -= 1
            result.append(str(total % 2))
            carry = total // 2
        return ''.join(reversed(result))
class Solution {
    public String addBinary(String a, String b) {
        int i = a.length() - 1, j = b.length() - 1, carry = 0;
        StringBuilder sb = new StringBuilder();
        while (i >= 0 || j >= 0 || carry != 0) {
            int total = carry;
            if (i >= 0) total += a.charAt(i--) - '0';
            if (j >= 0) total += b.charAt(j--) - '0';
            sb.append(total % 2);
            carry = total / 2;
        }
        return sb.reverse().toString();
    }
}
// 從尾端逐位相加，維護進位
// 時間複雜度: O(max(m, n))，空間複雜度: O(max(m, n))
function addBinary(a: string, b: string): string {
    let i = a.length - 1, j = b.length - 1, carry = 0;
    const digits: number[] = [];

    while (i >= 0 || j >= 0 || carry) {
        let sum = carry;
        if (i >= 0) sum += a.charCodeAt(i--) - 48;  // '0' 的字元碼是 48
        if (j >= 0) sum += b.charCodeAt(j--) - 48;
        digits.push(sum % 2);
        carry = sum >> 1;
    }
    return digits.reverse().join('');
}
// 從尾端逐位相加，結果從字串尾端往前填
// 時間複雜度: O(max(m, n))，空間複雜度: O(max(m, n))
char* addBinary(char* a, char* b) {
    int i = strlen(a) - 1, j = strlen(b) - 1;
    int len = (i > j ? i : j) + 2;           // 最多比較長的字串多一位
    char* res = malloc(len + 1);
    res[len] = '\0';
    int k = len - 1, carry = 0;

    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        res[k--] = '0' + sum % 2;
        carry = sum / 2;
    }
    // 若最高位沒有進位，k 會停在 0，回傳從 k+1 開始的部分
    if (k == 0) memmove(res, res + 1, len);
    return res;
}
class Solution {
public:
    string addBinary(string a, string b) {
        int i = (int)a.size() - 1, j = (int)b.size() - 1, carry = 0;
        string result;
        while (i >= 0 || j >= 0 || carry) {
            int total = carry;
            if (i >= 0) total += a[i--] - '0';
            if (j >= 0) total += b[j--] - '0';
            result += char('0' + total % 2);
            carry = total / 2;
        }
        reverse(result.begin(), result.end());
        return result;
    }
};

複雜度分析

時間複雜度: O(max(m, n))

m、n 為兩個字串的長度，迴圈次數為較長字串的長度（最多再多一位進位）。

空間複雜度: O(max(m, n))

結果字串的長度最多為較長輸入加一位。

重點提示

  • 迴圈條件要含 carry：寫成 while (i >= 0 || j >= 0 || carry) 才能自然處理最高位進位，不必事後補判斷
  • 字元轉數字：Java / C++ 用 c 減去字元 0 取得數值，比呼叫轉換函式更直接
  • 別用整數轉換：輸入長度可達 10^4 位，遠超過 long long 的範圍
  • 記得反轉：結果是從低位往高位產生的，回傳前必須反轉
